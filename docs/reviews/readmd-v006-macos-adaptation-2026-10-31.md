# V0.0.6 Mac 适配阶段记录 · 2026-10-31

V0.0.6 仍是候选，正式发布未更新。此批先处理不调用模型的适配；OCR、转写和 AI 的原生消费者验收继续待验。完整账本仍为 63 项进行中、12 项待办、0 项整项认证。具体候选摘要与分层结果见同名 JSON。

## 本批实现

- 普通启动／模块状态查询不再自动运行 OCR、转写探测。界面显示等待状态，明确使用相关功能时才加载。Vision 的真实识别用例保留为可执行测试，本次本机及常规 CI 明确过滤它，没有增加既有忽略项。
- Mac 菜单栏驻留、Dock 重开、文件 URL 打开、原生文件／编辑菜单接入现有业务路径。⌘Q、菜单退出及 `NSApplication.terminate` 共用关闭保护；未保存正文取消退出后仍保留。原生菜单复用现有翻译，撤销／重做复用协作及审阅历史服务。
- 修复原生标题栏下关闭偏好未同步的问题。此前判断仅接受自绘标题栏，Mac 因此忽略了“不驻留”选项及原生菜单翻译同步。保留已确认的最上方镜像排列：窗口控制在左，其他项向右排列，LOGO 最右。
- 桌宠使用真正的透明、不激活 `NSPanel`，复用现有 Tao 循环、WKWebView、渲染器、状态协议与 Rust 监督。实现鼠标命中／穿透、拖动和锁定、位置持久化、隐藏／唤醒、主程序退出联动；右键通过原有持久命令唤醒阅读窗口并打开现有菜单。
- Mac 剪贴板后端读取有界 Unicode、文件 URL 及有界图片，检测读取期间的内容变化。测试使用独立命名粘贴板，没有读取或覆盖用户的通用剪贴板。全局键盘仅在现有 Input Monitoring 授权允许时查询，未自动申请或修改系统权限。
- 桌宠运行时升至 1.0.1。安装和可用性共用完整 manifest 验证。修复 ZIP 解压丢失 Unix 执行权限；仅在验证过的暂存树中按角色设置权限，不信任 ZIP 的特殊权限位。应用自带新运行时可刷新旧版；升级使用独占目录、持久意图和 `RENAME_EXCL`，保留旧运行时与恢复材料。未知文件／损坏安装不会在自动启动时被清除。
- 原生文件面板在主线程呈现；HTTP 工作线程等待实际结果。取消与不可用分开，失败不再冒充取消。应用包声明 Markdown 类型及编辑器角色，默认应用仍由用户选择。打包器增加显式 ZIP 选项，默认发布仍生成 ZIP 和 DMG，签名及隐私检查均保留。

Vision 文件字节工作进程已准备，保留预算、取消、语言、图像尺寸及输出限制；暂停前的探测不等于本批原生 OCR 流程验收。语音受管引擎及完整消费者仍未完成。Live2D／BongoCat 验证使用的是既有图形资源，没有调用识别、生成或语言模型服务。

## 首败与修复记录

1. 普通 Tao NSWindow 改 style mask 不等于真正的不激活 NSPanel。首批宿主检查失败后改为实际 NSPanel；独立宿主的真实绘制、命中、拖动及停止检查通过。
2. 真实 release 桌宠首次安装失败，程序为 `644`，主程序返回启动失败；预装调试副本未覆盖这一缺口。暂存安装恢复执行位后，真实包安装／升级／重开通过，并补充 ZIP 与目录安装权限回归。
3. 新增 Mac 菜单栏驻留后，红色按钮检查暴露关闭偏好未生效。修正标题栏平台判断后，前一候选 27 项通过；后续激活问题继续单独追踪。
4. 一次样式修改触发既有受保护字节测试。恢复该文件的原始字节，将新增规则放入既有 shell 样式体系，完整前端回归通过。
5. 文件面板的跨进程代理不能由客户端的 `ok:`／默认 NSButton 代替真实用户确认。相关失败保留，驱动明确拒绝伪造确认。后续真实打开选择已取得一次通过；另存提交和重开仍待验。
6. 合成 Shift 快捷键没有得到预期重做结果。保留失败，改用实际 NSMenu 项动作并核对 Rust 历史及正文；不将此记为 WindowServer 物理快捷键验收。
7. 本机 DMG 创建返回“目录非空”，复现诊断保留，根因尚未确认。完整性验证通过的 ZIP 单独交付，不将失败的 DMG 目录标成完整发布包。
8. 首次当前提交 CI 的两个浏览器准备步骤失败：托管 `ubuntu-latest` 已为 26.04，锁定的 Playwright 1.54.0 报不支持 `ubuntu26.04-x64`。保留原始日志，将两个浏览器作业固定到其依赖表已有的 Ubuntu 24.04，并隔离该镜像的 Rust 缓存；没有升级浏览器、跳过测试或改变预期。Linux 发布原有的 Ubuntu 22.04 基线不变。上述 `3d22b7ba` 的全部 CI 已通过。
9. 正常系统启动的首次辅助工具编译在 Swift 缓存中重复加载同一 Foundation 模块，日志显示同一目录的规范路径与 `../` 写法。为 Swift QA 使用单一规范化缓存，并将编译临时目录定向到工作区，复验通过；没有为每个测试新建 Rust target。
10. 系统窗口的首次退出检查在全部 27 项 UI 操作完成后，因立即查询 LaunchServices 登记仍存在而失败。保留首败；新检查同时确认实际 PID 对应专用可执行文件、自然消失以及系统登记最终清空。复验中捕获确认后 106 ms 时已检测不到该进程，227 ms 时系统登记已清空，未用强杀制造成功；这是单次观测，不是通用性能认证。
11. 人工确认驱动初次把 NSOpenPanel 当成含保存文件名输入框的 NSSavePanel，等待名称匹配超时；保留日志与原件。打开面板改为只预定位目录，文件列表由真人选择；保存面板才预设新文件名，两类窗口均由真实回调决定结果。
12. 首次真实打开成功后的另存调用返回 `false`，未创建输出。当前记录尚不能区分取消、传输或提交错误；保留首次结果和原件摘要，未把准备好诊断驱动当成保存问题已修复。
