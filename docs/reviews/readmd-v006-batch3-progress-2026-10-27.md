# V0.0.6 第三批：本轮实现与未完成项

本轮按 V6-31–36 推进，以下是有明确边界的增量，不代表第三批整体验收。只使用 Windows 本机、隔离测试资料及离线构建；后续经用户授权进行了真实 AI 请求，连接配置只在测试进程内使用，没有写入源码或证据。

## 公共验证与隐私

- 本轮前一候选的 Rust 完整库回归 4,102 通过、0 失败、3 项既有忽略；Node 回归 109 个文件共 1,497 项通过、0 失败、0 跳过。Node 首次因表格源码保护摘要仍为旧值而失败，首败保留，检查真实界面及源码差异后仅更新对应摘要。重命名后续候选的最新回归结果见[增量记录](readmd-v006-batch3-rename-2026-10-27.md)。全部构建使用 `--locked --offline` 和共享目标目录。
- 最新候选完整 Rust 库回归为 4,208 通过、0 失败、7 忽略；Node 107 个文件共 1,565 通过、0 失败、0 跳过。最新候选已重新验证重命名、多进程会话、真实 AI 及转写页面，具体范围分别见两份增量记录。
- 正式 CSP 下发现 OpenAPI 冲突提示显示内部键；已复用现有本地化提示，英文、中文及阿拉伯语界面实测，并检查所用提示在 46 个语言文件中均有非英文占位的本地文案。导出同类提示改用现有本地化文案。
- 语言清单的结构完整不等于语义合格：`kg` 配置为 Kikongo，但既有 `plugin.unsupportedBuild` 文案为吉尔吉斯语；该文件共 71 项含西里尔文字，属于待审查信号，不能把每项都直接判作翻译错误。46 语言母语审校仍未完成。
- 早先私人 AI 连接请求的 HTTP 403 首败仍保留，原因未定。用户修复连接后，以最新 Windows 候选、隔离资料和进程内转发，先后用现有默认模型和用户指定模型分别完成真实流式对话、5 轮工具任务及重启恢复；指定模型的 6 次上游请求均为 HTTP 200。报告不包含连接地址、模型名或凭据；这不代表所有模型、图片、多平台或所有失败场景均已验收。
- 隐私复核发现历史源码和旧账本曾包含本机路径及个人联系信息；本轮检查点已对所改账本进行路径脱敏。对 92 个已修改或未跟踪的源码、文档和测试文件按当前私有连接及模型值复核时，发现既有录屏脚本包含模型名称，该名称在当前 HEAD 中已存在；本次扫描范围内未发现匹配的连接地址或密钥。该扫描排除了依赖目录及缓存，也不能替代仓库全历史审查。录屏脚本保留原样，发布前必须排除或处理相关内容并审查旧提交；当前没有提交或推送。
- 本轮没有发布版本，宣传片工作继续暂停。各功能对应的首败和测试报告保留在本机忽略目录；源码提交不包含配置、个人文件或录屏资产。
