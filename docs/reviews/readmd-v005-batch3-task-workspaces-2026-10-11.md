# V0.0.5 第三批：任务暂存归属与重启回收

日期：2026-10-11。B3-52 的限定增量，完整第三批仍未完成。没有替换用户安装、发布或添加依赖；单一 target、锁定离线、关闭增量编译。

## 实际变更

Rust 内核新增共用 task_workspace 模块。持久记录位于配置目录 worker-tasks-v1/<任务身份>/，工作内容位于系统暂存的配置摘要命名空间中。记录只包含归属、创建时文件身份、相对路径、短目录引用目标和恢复引用，不包含正文或密钥。现有任务状态主要在内存；本模块不是已经完成全部 TaskRecord、正文审阅和 Harness。

仅登记显式创建的句柄，不按路径前缀认领文件。Windows 通过卷、文件索引及创建时间核对身份，通过原生句柄删除精确对象；回收时持有祖先目录句柄，拒绝重解析父目录和替换目录。未知文件、已替换文件及未知子树保留，不递归清空。恢复引用有修订保护；未释放时不能回收，不能按普通缓存期限淘汰。

MCP 单文件导出移入集中暂存区；原文档目录只参与最终原子发布。HTML 输出使用共用原子写入。暂存目标创建一次，拒绝覆盖后来出现的外来文件；最终发布前完成内部收尾，避免实际输出成功却因随后的记录写入失败返回错误。

真实 Typst/OCR 操作及安装探测使用上述工作目录，工作进程继承 OS 文件租约。Typst 通过 Rust 预先创建的句柄输出 PDF，诊断单独捕获；依据固定版本的[官方 CLI 源码](https://github.com/typst/typst/blob/v0.15.1/crates/typst-cli/src/compile.rs)，并完成实际运行验证。OCR 的输入、输出、诊断及超长资源目录的短引用均登记。旧的无归属暂存不会被自动删除。
