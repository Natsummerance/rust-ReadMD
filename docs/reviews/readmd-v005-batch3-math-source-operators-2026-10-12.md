# 第三批：公式运算符、括号与下标的精确编辑

自然 DSL 的 AST 现在保留运算符词法 token 及精确位置。单独的加减号、乘除与关系别名都能映射到渲染节点；注释、空白、Unicode 和重复运算符不会靠字符串搜索定位。简单下标的基底、下标槽及其字符分别保留源码范围。前端用一次节点映射表查询，避免新增运算符后反复扫描整个源码节点列表。

检查中修复了两处数学语义问题。原来的括号只影响解析优先级，没有进入显示树，`(a+b)*c` 可能显示为 `a+b*c`；现在普通表达式保留真实定界符节点，属性数值的括号仍只作数值分组。另一个问题是把运算符改成注释可能吞掉后续操作数而仍能解析；共享 Rust 修改接口现在只接受单个合法运算符，普通内容槽继续允许完整表达式。Unicode `−` 支持一元和二元减法，`÷` 是可见除号，`/` 继续生成分式。
