# B3-55：括号、大算子与真实预览检查

第三批仍在实施。本增量修复了部分公式语义和编辑操作，同时实际视觉检查发现尚未解决的预览缺陷。不能用属性存在、回归通过或文件生成成功认证视觉一致性。

## 已实现并验证的范围

- 括号的伸展开关、数学轴对称和贴合内容分别进入 MathML 与 Rust 矢量排版；固定高度不再被当作自动伸展。
- 缺省字符与显式空字符分开处理。省略采用 Office 默认，空字符隐藏对应括号、分隔符或算子。分隔符缺省采用 U+2502。
- 大算子的伸展缺省为关闭，显式启用时 Rust 矢量排版按自身被积式高度布局；显式空算子且无上下限不再留下多余脚本间距。
- 高级字符输入清空表示隐藏；已有属性旁的 44px 恢复按钮删除覆盖并继承默认。复用现有本地化键，不新增常驻界面。
- 1024×680 深色插件面板中，能力项各占完整一行，避免字体和 TeX 项横向挤在一起。实际截图与矩形检查通过。

默认行为依据 [Office GrowOperators](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.math.growoperators?view=openxml-3.0.1)、[Delimiter Shape](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.math.shape?view=openxml-3.0.1) 和 [SeparatorChar](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.math.separatorchar?view=openxml-3.0.1)。固定 schema 对字符属性要求显式 `m:val`；缺该属性的旧输入在容错渲染与严格编译中分别处理，保留原载荷或失配恢复记录，不放松新公式输出校验。
