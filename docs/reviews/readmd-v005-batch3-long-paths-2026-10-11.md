# 第三批：真实引擎的超长中文路径

接续[历史恢复与 OCR 修复](readmd-v005-batch3-history-2026-10-11.md)，本次收口 B3-52 中已实际失败的 Windows 模型工作目录边界。第三批仍进行中，全部操作使用自有隔离资料，没有替换用户安装或发布。

## 修复与资源保护

Windows 进程工作目录超过 MAX_PATH 时，即使规范化路径也会启动失败。受管理 OCR 现在为超长模型目录创建任务内的短目录引用，由工作进程持有其生命周期；模型仍在原目录，图像通过显式只读句柄输入，临时文件和缓存仍在任务目录。没有复制模型或新增持久系统盘符映射。

任务结束、取消或启动失败时只移除自己创建的目录引用及空父目录，不递归进入资源目标。两个任务的引用相互独立；旁边的未知文件和原始模型保留。创建期 Job Object、资源使用租约、两名额预算及取消逻辑继续生效。只启用既有固定版本 `windows` crate 的 `Win32_System_IO` 特性，没有新增依赖版本或改变 Cargo.lock。
