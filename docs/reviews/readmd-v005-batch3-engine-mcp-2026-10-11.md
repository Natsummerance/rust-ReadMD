# 第三批：真实引擎、MCP 与长配置启动

接续[超长路径记录](readmd-v005-batch3-long-paths-2026-10-11.md)。本次补充 B3-52 的实际 Typst/OCR 进程故障矩阵，修复真实 CLI 启动及导出错误传播；第三批仍进行中，没有替换用户安装或发布。

## 修复内容

1. **超长配置目录无法启动。** 原先 Windows CLI 归一化后的普通长路径交给 SQLite，会报无法打开数据库。只在 SQLite 原生边界将已存在的父目录规范化为原生路径；公开路径格式不变。新回归用两个连接及重开验证同一 WAL 和文档记录，真实主程序也在 383 个 UTF-16 单元的隔离配置中启动。
2. **繁忙导出迟报且 MCP 丢失错误类型。** 共用导出入口在字体摘要、资源解析和公式转换前只读检查名额；真实引擎仍在执行时取得权威名额，避免观察竞态突破预算。MCP 保留 `typst_busy`、超时和取消等已知错误，未知错误继续使用通用导出失败。忙或取消时保留旧文件。
3. **重试测试误用墙钟推断次数。** 首次完整回归为 2169 通过、1 失败、3 项既有忽略；失败测试把三次尝试限定在 400ms 内，本次实际耗时 1.506s。重试策略改为同一私有循环接收操作与等待函数，生产仍使用真实重命名和睡眠；测试直接检查准确尝试次数、等待序列、仅权限错误重试，并保留真实 Windows 权限错误及原文件保护。没有放宽生产停止目标、添加忽略或重试失败业务请求来过关。
