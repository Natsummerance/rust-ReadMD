# 第三批增量：能力包完整读取的 Windows 优化

日期：2026-10-10。对应 R029、R030、R075 和 B3-50。继续 V0.0.5 开发，不代表第三批完成、正式 TeX 分发或主程序发布。

## 实现与边界

能力包校验仍读取每个文件的全部字节并核对摘要。Windows 从同一个资源句柄取得类型和长度，读取期间禁止并发写入及重命名；在此条件下按已知长度读取，结束时不再额外向系统读取 EOF。合法短读继续读完，字节不足、读取故障及取消均失败。空文件正确计算空摘要，无需额外读取文件内容。

其他平台的普通文件打开不具有 Windows 的共享限制，因此仍实际读取 EOF 并检查总长度，不以 Windows 的前提省略增长检查。没有增加可信结果缓存、跳过文件或降低完整性门槛；当前进程内资源租约的边界不变。

新增测试覆盖空文件、1 字节、64 KiB 前后边界及两个完整缓冲区；计数确认 Windows 不产生多余底层读取。另检查每次仅返回 3 字节的合法短读、截断、权限错误及中途取消。现有并行校验、相同长度损坏、祖先目录变化、写入／重命名拒绝和取消线程收回继续回归。

完整离线锁定 Rust 库：2,097 通过、0 失败、3 项既有忽略，139.61 秒。桌面及故障程序随后重新离线构建，前端代码未改，boot 一致性检查通过。

- Windows 正式 CSP 的 11 条流程通过：完整 34,822 文件 QA 包安装、两个实际引擎、中文／Unicode 公式／科研表格／CSL 预览、预览与导出字节一致、真正的 stdio MCP、保存重开、输入目录无污染、卸载与旧预览失效。安装及探测 175,391ms，开始等待中文预览后 32,891ms；和先前运行不构成受控性能对照。
- 9 项实际进程故障检查通过：两个编译工作进程进入运行，第三请求拒绝 0ms，取消后两进程退出 55ms；活动租约阻止卸载、就绪探测公平性、期限、损坏资源、目录外读取及未知文件保留均验证。
- 故障检查先执行一次真实就绪探测；其首次全树校验为 139,449ms，超过 120 秒普通任务预算，继续明确记录为未通过的冷态性能要求。热态后续功能通过不能覆盖这一缺口。
- 三份实际 PDF 共三页经 PyMuPDF 独立检查并全部目检，字体嵌入、无栅格图像，中文、引用和 `σ` 保留；两份原生界面截图同时目检。布局证据使用 1024×680、1160×820 CSS 视口，不代替完整系统 DPI 矩阵。
- 资源、接线、46 语言 2,582 键集合及无 Python 运行依赖静态检查通过；不代替全语言语义审校、全部宿主依赖或全平台认证。

## 尚未完成

减少 EOF 读取次数不是完整运行库的冷态时限证明。此前冷态全树校验超时仍然有效，不能用安装后、就绪探测后或热缓存结果抹掉；继续需要精简实际运行闭包并独立验证。对应二进制源码、历史宏包材料、许可证及公开 TeX 包也仍待完成。

跨进程租约、崩溃暂存回收、正式包修复／升级／回退、干净环境及完整故障矩阵仍未验收。媒体、无界面 Vega／PlantUML、代码块语言运行环境及 GUI 宿主尚有待去除的宿主依赖。`speech.rs`、`diagrams.rs` 和 `code_chunk_runner.rs` 的系统工具路径不能计作软件自带；这些已加入离线能力指南和 R075 余项。

其他平台原生、全语言语义审校、Word 往返、全部数学／出版语义和八小时压力仍保留各自验收，不能凭本增量标记全部完成。
