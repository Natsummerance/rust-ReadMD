## 实现结果

公式内已有 `m:r`、`m:ctrlPr` 的 `b/i/sz/literal RGB`，以及已选段落和显式字符 `basedOn` 链，可以在获准的正文宿主中输出真实 Word 样式引用。缺省、空开关与显式关闭分别保留；style true 使用 toggle，style false 不等同于 direct off。目标默认与宿主上的四个有效轴必须逐项证明一致，包括 Missing，才启用稀疏原生投影；不把全部继承值补成 direct 来遮住后续样式修改。

段落和字符样式使用同一冲突域与确定别名。只发布实际使用的定义，重复投影不会使引用计数下溢；独立段落引用和物化回退仍保留所需定义。普通正文、模板、全局默认及节属性不因新增公式样式而改写。

现有公式高级属性面板增加已有四轴叶的编辑，继续使用原 `richPatch`、源节点、文档上下文、修订和撤销。输入显示作者原声明，不从渲染有效值反填属性；只修改 `w:val`，本单元不新增／删除叶节点。清空 b/i 的 val 是保留节点的隐式开启；字号与颜色不可清空。错误输入保留供修正，恢复原值可以重新验证，切换节点不复用上一个 ID 或值。新增四项提示与物化警告均有46语言显式翻译。

Rust 编辑接口现在接通这些叶的实际修改路径，限制真实 namespace、位置、唯一 rPr、标准值、样式类型和继承链。不会通过覆盖坏值修复非法原来源。DSL 修改沿局部 token 事务，保留注释、UTF-16 范围、CRLF、astral 字符和其它声明；OMML 沿原序列化合同保留语义与命名空间，不宣称 XML 源码全字节编辑。命名空间别名仅在临时校验副本中规范，作者树不变，重复 expanded 属性和 foreign canonical 属性仍拒绝。
