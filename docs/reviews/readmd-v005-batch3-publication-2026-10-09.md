# ReadMD V0.0.5 第三批：数学与学术出版进展

日期：2026-10-09。本次继续第三批，已集成到 V0.0.5 工作版本，完成以下可操作增量。第三批完整合同没有缩减；完整 OMML/Word 认证、旧文档迁移和出版模型仍未结项，当前没有发布安装包。

## 用户可用行为

| 操作 | 当前结果 |
| --- | --- |
| 修改公式结构、增加矩阵行、转换上下标 | 按精确源范围改写最小可映射结构，重新编译比较完整 XML 语义，保留外层注释及未修改表达；无法安全回写时保留草稿并报错。 |
| 空槽、连续内容及复杂结构往返 | 新增 `empty()` 和 `row(...)`；矩阵、方程组、定界符和大型算符优先输出可读函数；显式空属性容器不丢失。 |
| 打开不支持的 Math DSL 版本 | 阅读/预览显示本地化提示并保留源码；仍能编辑其他公式及保存。正式导出停止，已有输出不被覆盖。代码中的语法示例保持原样。 |
| 公式应用后立即按 Ctrl+Z | 正文事务完成即恢复焦点，无需等待恢复记录清理；后续迟到请求不会抢走其他控件或文档的焦点。 |
| 标记和移动图、表、公式 | `:label[...]` 关联稳定 ID，按当前正文重编号；`:ref[...]` 精确跳转。编辑补全使用未保存正文，Tab 复用已有闭括号；保存后不增加内部投影或旁文件。 |
| 导出引用 | Word 包含原生 SEQ/REF 字段、书签及字段更新设置；PDF 实际目的地由独立 PDFium 解析；EPUB 保留 MathML 与跨章节链接；TeX 保留精确 ID。实际 Word 刷新与往返仍待验收。 |
| 使用 Chicago 注释型文献 | 接受官方样式 ID；生成真实 Word 脚注，保留作者脚注和定位符。PDF 的真正分页脚注及完整 CSL 格式仍待完成，不能把追加注释当作分页脚注认证。 |
| 设置 Word 首行缩进 | 参数实际写入并应用到正文样式；标题、公式、图片和题注不误用正文缩进。8mm→454 twips 有包内容证据；不冒充实际 Word 排版。 |
| 导出 SVG 图片 | 锁定的离线 Rust 工作进程输出最长边至多 2400px 的等比 PNG，保留透明度，供 Word/PDF 使用；原图、其他引用和输入目录不变，EPUB 保留 SVG。 |

使用说明见 [编号、引用与脚注](../guides/publication-references.md)、[Math DSL v1](../design/math-dsl-v1.md)。没有新增常驻工具栏或场景工作台。

## 架构与资源

`cross_references.rs` 负责统一、只读的源投影和诊断，`md_ast.rs` 提供类型化题注；各输出器消费同一 AST。引用代码、转义、重复 ID、标题冲突及不存在目标有明确保护，编号结果不写回 Markdown。公式结构回写仍通过 `MathDocument` 的修订和 UTF-16 范围。

静态 SVG 使用独立的 resvg 0.48.1 工作进程，不增加主 Cargo 依赖。Windows 程序约 3.98 MiB，源码摘要、二进制摘要、60 个 normal/build 依赖的许可声明和通知均已保存。构建离线锁定，资源验证、调用预算及缓存有界。详情见 [SVG 引擎审查与重建](../design/svg-renderer.md)。此输出是高分辨率兼容 PNG，不能称为 Word/PDF 原生矢量 SVG；只有 Windows x64 有本次实际证据。

## 回归中发现的问题

立即撤销失败是应用逻辑问题：公式移出临时编辑器后仍等待集中恢复删除，焦点尚未交回正文；原有原生测试直接调用撤销函数，没有覆盖等待期间真实快捷键。现已提前恢复焦点，并增加可控的恢复清理延迟测试和原生 Ctrl+Z/Ctrl+Y 检查。

其余修正属于测试合同：分子编辑只替换分子；代码示例在 EPUB 必须保留；PDFium 目的地为零基页号；覆盖已有 EPUB 的测试必须明确传入 `overwrite`；Chromium 延迟布局下要先滚动到代码示例再读取可见文字。测试截图曾滚错 PDF 容器，现已滚动实际视口并检查非零滚动。前期失败保留摘要，不以自动重试掩盖，最终结果必须对应修正后的测试和当前资源。
