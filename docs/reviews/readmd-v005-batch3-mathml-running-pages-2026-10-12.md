# 第三批：数学样式与双面出版参数实测

完成 B3-55／B3-56 的第二个限定增量；完整第三批仍未完成，未发布或替换用户安装程序。

## 已实现

MathML 导入支持作用域内字体变体、颜色和可准确表示为 Word 半磅的物理字号；内层覆盖外层，兄弟节点独立。单字符变量缺省斜体，多字符标识、数字与运算符缺省正体。文字粗斜体使用原生 Word 字体属性，结构控制样式与子槽位分开。已支持结构的缺省属性按适用范围继承，超长继承属性在展开前拒绝，避免小输入放大内存。不能准确表示的值保留正文并返回投影诊断。

真实原生流程发现并修复两处顺序问题：数学 run 必须先有数学属性再有 Word 属性；生成的括号、矩阵属性必须遵守固定 schema 次序，否则可读 DSL 往返会被正确拦截为有损。只规范引擎生成的数学属性，不重排导入的原始 Office 内容。

现有高级出版设置增加奇偶页不同、偶数页页眉与页脚文字。DOCX 生成原生设置、独立部件及节关系，明确空值不会继承奇数页。Typst PDF 按物理页奇偶切换，与自定义显示页码起始值无关；首页隐藏可独立组合。用户预设实际重启后保留。页眉页脚对齐选项的既有英文漏译一并修复，复用 46 语言已有译文。

标准依据：[MathML 样式](https://www.w3.org/TR/MathML3/chapter3.html#presm.mstyle)、[Office 奇偶页页眉页脚](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.wordprocessing.evenandoddheaders?view=openxml-3.0.1)。
