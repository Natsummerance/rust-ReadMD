# 第三批：流式能力安装和使用生命周期

本增量将上一轮流式包基础接入实际能力安装服务，继续落实“核心随本体、重型按功能安装”。已有 PDFium、Typst、OCR、中文出版字体的目录、功能入口和安装器选择保持兼容。没有新增常驻面板，没有发布主程序、改变已发布包或覆盖用户安装；第三批和 V0.0.5 仍未完成。

## 实现范围

原生离线导入使用文件流，下载结束后也直接从暂存文件进入解包，避免将整个大包重新载入内存。压缩段校验、逐文件 SHA、应用固定身份、真实引擎探测及原子切换共用一条链路。新 v2 主清单还检查固定目录中的整包摘要；已交付 v1 清单可接受完全相同资源的流式重编码，不能借编码变化引入新文件、版本或审查内容。

解包、探测和下载可以取消，取消成功后不能再进入提交。原子提交开始后取消返回忙碌，界面等待明确结果。原生导入与下载共用任务事件；相同配置下重复启动同一引擎返回原任务。现有小包浏览器导入可处理实际 v2 编码，但单请求仍限 128 MiB，尚未提供大型包分块传输。

PDF 会话、Typst 排版和 OCR 识别取得资源使用租约，取得租约与安装／修复／卸载共用互斥规则。修复不能在工作进程取得路径后、启动前抢先移除资源。PDF 忙碌检查不等待会话锁，避免安装锁和会话锁相互等待。状态明确区分安装存在、可使用及正在使用；功能入口不会把忙碌资源误当缺失，再弹出下载卡片。

卸载先完成路径与已知文件计划检查，再将已知文件移入本次独立暂存，遇到文件锁恢复已移动内容。目录准备全部发生在移动前，避免准备失败时丢失恢复依据。未知嵌套文件保留原位置，安装父目录的 junction／符号链接会被拒绝。原子修复若回滚失败保留恢复目录，并报告阶段，不覆盖新出现的目标文件。

## 真实验证

源码、程序身份、日志摘要及验收范围见[证据索引](../evidence/capability-upgrade/2026-10-10/batch3-stream-install-manifest.json)。

- Windows 原生正式 CSP 的 **10 条完整流程通过**。使用真实 23,523,775 字节流式 Typst 包和三个既有 v1 包，不模拟安装、引擎或导出 API；进程 PATH 限制为 Windows System32。
- 实际功能安装提示内选择离线文件，安装完成后等待动作继续，并生成真实 PDF。原生异步导入验证取消不会晚提交，重复启动返回原任务。
- 尾部损坏及错误引擎包被拒绝；损坏运行库使实际输出停止且不覆盖已完成 PDF，从正确包修复后恢复导出。
- 三个既有 v1 包仍通过真实 PDFium、OCR、字体探测；四包在实际程序重启后可使用。输入 Markdown／PDF 原字节保持不变，文档目录没有新建资源文件夹。
- 真实 PDF 会话阻止卸载；在用且有效的引擎仍可打开另一 PDF，不会因为忙碌永久阻断功能或弹重复安装提示。真实 Windows junction 被拒绝，单独目标目录及 canary 未被改动。
- 完整 Rust 内核 **2062 通过、0 失败、3 项既有忽略**；既有 v1 PDF 安装、编辑、保存、重启、修复和安全卸载的 **6 条原生回归通过**。忽略项及来源在证据中单列。
- 专项 Rust **16 通过、0 失败／忽略**，包括本轮新增的资源身份、碎片头读取、卸载未知嵌套文件、Windows 独占文件锁回滚、租约引用计数、验证取消、取消／提交原子边界和大包目录预算检查。
- 维护工具 **11 通过、0 失败／跳过**，覆盖流式包和已有分发锁／发布保护。专项 Rust 16 是完整内核的子集，不重复相加。
- 新生成 PDF 经独立 Poppler 渲染并视觉检查：标题、正文、数学符号及表格可读，无重叠裁切。这是短功能材料，不是完整论文、科研表格或宣传样张认证。

未新增可见文案；进度、取消、忙碌和验证状态复用已有国际化键。前端已重新离线打包。资源、接线、无应用 Python 和验收账本检查结果均随证据保存；没有据此宣称 46 语言语义审校全部完成。
