# V0.0.5 社区能力落实与丰富演示资料

本轮按[社区对照](readmd-community-research-2026-10-07.md)检查共同能力，修补实际链路，不增加常驻按钮、面板、依赖或专属文档格式。对照过的项目不等于完整复刻过的项目；下表只把可指向代码、测试或操作记录的能力写成已提供。

## 本轮完成的操作链路

| 操作 | 实际行为 | 实现及验证 |
| --- | --- | --- |
| 输入 `[[` | 在现有 CodeMirror 菜单中建议真实笔记，跨目录插入相对路径；普通文字不弹菜单 | [编辑器](../../assets/js/editor/editor.js)、[Rust 工作区服务](../../rust/readmd-kernel/src/document_knowledge.rs) |
| 输入 `[[笔记#` 或 `[文字](笔记.md#` | 建议另一篇笔记的真实标题；本篇 `#` 使用未保存草稿；忽略代码块中的伪标题 | 同一 Rust AST 标题提取器，支持重复标题 ID；真实 HTTP 端到端测试 |
| 输入 `![说明](` | 建议本地图片；路径中空格及保留字符编码；外部 URL 不触发本地扫描 | 同上；不下载、不上传图片 |
| 输入 `[^` 或 `[@` | 从当前草稿建议脚注定义；从 front matter 显式指定的本地 BibTeX 建议文献键 | 共用已有 BibTeX 解析器，无全盘文献扫描 |
| 原生桌面阅读引用 | 修复桥接优先读取空旧数组而丢弃有效引用的问题；保留旧格式兼容，正文显示引用标记与参考文献 | [实际桥接测试](../../tools/test/native-bibliography.test.mjs)与原生资料验收；同时检查公式 SVG、Mermaid、脚注 |
| Tab / Enter / 撤销 | 已显示的菜单优先接受一次；保留已有闭合括号；一次撤销还原；不插入另一标签页 | [10 项新增端到端测试](../../ui-tests/knowledge-workspace.spec.js) |
| 普通写作、AI 和斜杠菜单 | 只在明确引用语境激活语义补全；普通键入不进入“补全待响应”状态 | 修复完整回归发现的 AI 候选消失、IME 后不请求及斜杠菜单 Escape 受干扰问题 |
| 点击跨目录双链 | 先核实文件存在，等待真实打开，再聚焦实际标题；分页模式切换到目标页 | [阅读器](../../assets/js/reader/render.js)，原生 Windows WebView 实测 |
| 点击本篇标题双链 | `[[#标题]]` 可点击；支持目标在另一分页；同名笔记有歧义时不随意选文件 | 同上；中、繁、英、日新增提示，其他语言保留既有回退策略 |
| 代码里的双链示例 | 保护反引号、波浪线围栏、较长闭合围栏、未闭合围栏、多反引号行内代码及转义文本 | 保留原文，无替换占位符与用户内容碰撞 |
| 粘贴表格 | 表头与正文一致转义竖线；粘贴标记为一次编辑事务 | 沿用原有表格粘贴功能，无新增入口 |
| 保存 AI 连接设置 | 同时触发保存合并为一个请求；刷新目录完成前暂锁设置控件，避免迟到刷新覆盖下一步选择 | [AI 设置](../../assets/js/features/ai.js)；修复回归中发现的保存/模型列表竞争 |
| MCP 建议与跳转 | 新增 `readmd_suggest_links`、`readmd_resolve_link`，直接调用同一 Rust 服务；工具总数 30 | [MCP 实现](../../rust/readmd-kernel/src/mcp.rs)、[stdio 验证](../../packages/mcp-server/test/stdio.mjs) |

新工作区扫描上限：20,000 个目录项、5,000 个匹配文件、24 层目录；单篇读取 2 MiB，建议最多 60 项。略过隐藏与生成目录，不沿扫描中的符号链接遍历；解析的实际路径必须位于指定工作区内。同名歧义、缺失标题和截断分别处理。显式相对路径优先，避免大目录全量扫描。沿用已有编码检测，不把中文旧编码文件误当作空文件。

## 逐项社区对照

“落实”表示表中具体共同能力已经有实现；不表示该产品的全部功能、云服务、插件生态或运行平台都被复制。

| 社区项目 | 已落实到 ReadMD 的共同能力 | 本轮处理与边界 |
| --- | --- | --- |
| Obsidian | 双链、标题链接、反链、图谱、折叠提示 | 本轮补齐真实目标建议及标题跳转；未阅读闭源核心，不宣称 Sync、Canvas 或插件生态兼容 |
| Typora | 表格、任务、公式、脚注、即时预览 | 本轮统一表格粘贴转义并补脚注建议；保持明确源码/预览模式，不宣称相同的所见即所得编辑模型 |
| MarkText | 即时预览、常用格式、专注写作 | 保留 CodeMirror 源文档与预览；未引入另一套富文本状态 |
| Zettlr | 学术引用、搜索、多格式输出 | 本轮补齐本地文献键/脚注建议；不宣称完整 CSL 学术生态 |
| VS Code Markdown | 文件/标题建议、链接检查、导航、安全预览 | 本轮把桌面路径与标题建议接入 Rust；VS Code 沿用原生 Problems/Quick Pick |
| VNote | 本地笔记目录、阅读编辑分工、检索 | 本轮修补跨目录标题的最后跳转链路 |
| Joplin | 历史、草稿恢复、修改保护 | 沿用集中恢复区、版本冲突与可撤销编辑；无 Joplin 云同步 |

| HedgeDoc | Markdown 共享与预览 | 已有局域网共享；未实现多人 CRDT 同时编辑 |

## 验证与剩余范围

本轮追加两个交互要求，均沿用已有界面和 Rust 持久化服务：

| 要求 | 实际行为及实现 | 验证 |
| --- | --- | --- |
| 重启保留未关闭的页面 | 记录有序标签、当前页、主页状态和阅读位置；全部关闭后持久化空集合，不再通过 `last` 重新打开已关闭文件。显式双击文件在恢复原有页后打开；失效路径跳过，晚到的恢复请求不覆盖用户新操作。最多 100 页元数据，正文沿用中央恢复历史，不写邻接副本 | `ui-tests/session-restore.spec.js`；`ui-tests/session-native.cjs` 真实进程退出/重启及异常中断恢复 |
| 退出、升级和未保存内容 | 退出时的保存/取消/放弃与“关闭全部页面”分开；保存后保留页面集合，放弃文件修改保留原稿和可找回历史。未保存文档及转换预览复用已有受限草稿存储；原文件的修订校验保留 | 保存、撤销、冲突、恢复及退出流程回归；真实原生草稿恢复并比较原文件 |
| 统一勾选框 | AI、导出、转换、网页、更新、图谱、技能、阅读任务、编辑任务及查看菜单共用 14px、4px 圆角和主题配色；保留焦点、混合状态、禁用状态、标签点击与任务撤销。插件、桌宠的滑动开关保留其开关语义 | `ui-tests/checkbox-consistency.spec.js` 遍历实际静态及动态控件，明/暗/护眼主题与键盘操作；原生视觉抽查 |
| 轻量顶栏与输入区 | 左上角原 LOGO 成为返回主页按钮，并且与拖动区域分开；Ctrl+K 仅保留在悬停提示与键盘语义中。AI 输入区铺满底部，无圆角卡片、边框和外发光；保留焦点分隔线、自动增高和操作反馈 | `ui-tests/shell-polish.spec.js` 验证脏内容取消保护、快捷键、长输入及紧凑窗口；原生 4K 增量录制 |

部分临时录制帧和原生测试配置目录的递归清理被自动审批拒绝，原因为 `blocked by policy`；未换方式重试删除。本轮保留的测试目录合计约 394.63 MiB，逐项路径和大小见证据中的 `cleanup.retained`；此前已被拒绝的其他目录也未动。

范围仍然明确：不声称多人实时协作、完整 CSL 生态、第三方全部插件协议、所有桌面/手机/鸿蒙设备实机适配或“任何输入永不出错”。这些需要独立设计与环境验收，不能把已有按钮或本机通过解释成全部实现。上述本地共同能力尽量在既有界面中完成，扩展点由 Rust 服务和 MCP 暴露。
