- Section 支持 footnote/endnote 各自稀疏 numberFormat、numberPattern、start 和 restart；缺省继承、显式默认及显式零分别保留。每节从同一 global 独立计算，不继承上一节覆盖。

- 非 DOCX 出口先证明各节编号等价，再实际消费投影。EPUB/Typst 可兑现已支持的均一格式；HTML 和新增 section-origin TeX 只放行已有真实默认能力。差异、页重启及无法表达的属性在提交前拒绝；拒绝不计作已支持。
- 修复实际 XeLaTeX 空格丢失：作者字号 run 改用明确的 selectfont{} 命令边界，保留独立及开头空格，也不向原本相邻的文字插入空格。旧 PDF 的同基线零间隙首败、新产物真实换行与完整原文分别保留。
