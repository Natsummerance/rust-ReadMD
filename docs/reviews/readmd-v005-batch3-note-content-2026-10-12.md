# 第三批 MVP：脚注内容与局部排版

2026-10-12。遵循用户“先保证第三批功能达到 MVP，不要卡死在某个地方”。M3-01–08 的 Windows 主流程已有独立证据；本次修复会影响实际论文／书稿内容的缺陷，复用菜单和输出服务，没有增加工作台或依赖。完整 B3-51–57 保留，接下来转向第四批的持久 AI 审阅闭环。

## 用户可用的结果

- Word 脚注复用正文结构写出器，引用段落、原生编号列表、表格、代码及可编辑公式不再丢失。每条注释保留唯一标记，注释字号／行距作为基线，显式局部属性优先。
- 现有局部排版菜单可编辑脚注首段及续段。两段文字相同也只修改选中源范围，支持一次撤销、重做、重置、保存和实际进程重启。修复旧脚注解析开关丢失后续段落的问题。
- 阅读与编辑预览显示完整注释结构和公式。正文与预览采用独立锚点，源行映射正确；先解析再清理 HTML，转义定义、代码示例和代码内排版标记保持原样。
- 编辑器把实际脚注排版属性折叠为可点击控件。续段不因 CodeMirror 原有的缩进代码识别而暴露内部标记；通过共用定义扫描和源映射实现，没有按字符串寻找重复段落。
- Typst PDF 与 EPUB 使用同一注释局部参数。实际 PDF 首段标记和文字同处一行，80 段注释跨两页保留全部内容；EPUB 经固定离线验证器检查。
- Word 标准禁止脚注中再次生成 footnoteReference；此类输入现在返回46语言的可操作错误，原文及已有输出不变，不以非法 XML 或静默删内容冒充支持。EPUB 的合法注释交叉引用不受 Word 限制。[Microsoft 标准说明](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.wordprocessing.footnotereference?view=openxml-3.0.1)
