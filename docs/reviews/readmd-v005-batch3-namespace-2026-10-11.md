# 第三批：旧客户端隔离与校验迁移

接续[提交前暂存恢复](readmd-v005-batch3-staging-2026-10-11.md)，属于 B3-52。未发布、未替换用户安装；全部实测在新建的隔离资料目录中完成。

## 行为与实现

当前客户端的资源、锁、工作名额、安装传输及上传统一进入 `capabilities/managed-v2/`。这是固定存储协议，避免不遵守新锁的旧客户端修改当前运行树；应用自带的可信清单路径保持不变。桌面与 MCP 调用原服务，无新增依赖。

首次实际使用或状态检查发现旧目录时，先在独占保护与传输预算内复制当前清单的精确文件，逐文件检查长度和摘要，再验证完整树并实际探测私有副本，最后通过现有持久化替换事务提交。不使用硬链接，不执行旧目录中的引擎；旧资源、旧事务和额外文件均保留。现有私有目标不会被自动覆盖。

显式卸载先持久化退出自动迁移的记录，防止下次打开自动装回；显式重新安装仍可用。未知记录保守保留，不授予清理权限。旧文件被写占用时返回忙碌，释放后可继续；取消保留原错误。损坏旧目录返回未安装状态及既有错误码，保留正常缺包安装入口，不误报就绪。

## 保留的失败与限制

第一次探针要求旧客户端额外文件仍在活动版本目录，实际旧版修复将它完整保留在自己的备份中。已改为检查旧目录内恰好一份、内容未变；首次失败日志和清理记录保留，未据此修改生产逻辑。

随后一次在探针链接结束前启动了旧探针，导致 Windows `LNK1104` 可执行文件占用。构建/启动失败保留；进程退出后，完整内核回归、最后构建及对应实测分别完成。失败不是通过重复运行同一个功能来掩盖，最后探针对应修正后的源码和实际二进制身份。

PDF 正文静态字体嵌入，数学为带 Unicode 映射的真实矢量；标准 PDF14 Helvetica 仍用于未嵌入的数字页码及公式间空白。不能据此认证全部字体嵌入、完整科研版式或全部数学语义。

旧客户端不遵守新协议预算，隔离不能同时限制旧进程的配额。旧清单/事务恢复、Typst/OCR 完整迁移和实际崩溃、三引擎桌面/MCP 全传输、TeX 冷态与正式材料、展开磁盘配额/磁盘满、长期压力和非 Windows 原生继续待验；第三批仍进行中。
