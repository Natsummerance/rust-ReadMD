## 变化与实际行为

HTTP 与 MCP 将已有取消状态传给同一执行实现。SQLite 直接在当前请求运行，进度回调检查取消及期限；取消／超时返回前不留下脱离请求的 SQL 线程。内存 SQL 拒绝文件 ATTACH、VACUUM INTO、目录 PRAGMA 和扩展加载，仍可使用显式内存数据库。

外部子进程属于本次请求：Unix 使用独立进程组，发出组信号前保留可等待的根进程，避免提前回收 PID；Windows 复用现有受管 Job，进程创建时即加入，所有者关闭后停止执行。输出读取和停止结果均参与请求完成。无法证明停止的状态继续报 `execution_stop_pending`，不伪造成功。现有静态代码筛查不因此成为操作系统沙箱。

Windows CMD 的固定 `/c` 不能使用通用 CRT 参数引号，否则 CMD 会把它当作命令正文。仅这个固定开关使用 CMD 所需的形式，其他参数保持转义；工作目录以已核验的实际目录绑定，兼容安全的常规路径形式，避免 `\\?\` 被 CMD 当成 UNC 后回退系统目录。

Mac 原生探针确认 `proc_listpgrppids` 返回 PID 数量，而非字节数。只剩已退出成员时，Darwin 可能对组信号返回 EPERM；实现逐成员核实组和退出状态，不概括忽略 EPERM。该分支包含真实子进程及持管道子孙的回归。
