## 当前源码的执行结果

- 完整 Rust 库：2,117 通过、0 失败、3 项既有忽略，139.82 秒。三项忽略的名称及原因保留在原始日志和源码清单中，没有以重试改变结果。
- Windows 工作进程回归通过：创建时加入任务组、拥有者异常退出、取消／Drop、根进程退出后的子孙回收、两个独立拥有者隔离，以及受限环境与标准句柄。测试使用真实进程和句柄，辅助执行体是测试程序，不能代替真实 TeX 引擎认证。
- 上传回归通过：真实跨进程活动上传不被回收；结束拥有者后只回收已识别产物；未知文件、损坏标记和正文创建失败时的既有文件保留；活动 Windows 标记不可删除／重命名；闲置子进程不继承所有权句柄。
- 跨进程字体／安装服务 12 项通过：两个真实 PDF 读取者阻止修复和卸载；异常退出只释放本进程租约；最后一个读取者退出后恢复安装；等待写入时取消耗时 13ms，旧 PDF 不变；无关能力状态耗时 2ms。
- 桌面正式 CSP 字体／出版 6 项通过：缺包说明和取消、离线安装、真实分页、内置 PDF 与 Typst 输出、损坏后修复、保留未知文件、实际重启后再次导出。独立检查确认中文可搜索、常规／粗体字形嵌入及矢量公式，目检了分页截图。
- 桌面正式 CSP OCR 8 项通过：首次安装继续，PNG/JPEG/BMP/GIF/TIFF/WebP 中英文识别，扫描 PDF 两页，保存重开，损坏输入，取消，模型损坏与修复，重启后识别。本次取消确认 5ms、完成 10ms；这是一次专项观察，不是压力或完整 P95 认证。

四个能力包来自应用固定的自有发布目录，逐一验证归档大小／摘要、完整清单和每份展开内容。首次 Node 下载在 Typst 连接阶段超时，失败日志保留；随后系统下载器取得相同固定内容并通过校验，没有更换版本或放宽检查。

原始日志、源码摘要、二进制身份、实际报告及选定产物归档至缓存目录之外，索引见 [执行证据](../evidence/capability-upgrade/2026-10-11/batch3-cache-resume-manifest.json)。此前被清理的 B3-51 原始材料仍视为缺失；本次使用当前构建重新取证，不重建或改写历史成功记录。

## 取证边界与截图修正

字体测试通过真实窗口检查提示，安装调用真实服务；OCR 离线导入使用浏览器文件上传路径，为选择专用材料临时关闭原生文件选择桥接。没有模拟 OCR、导出、安装或资源状态；这些结果也不认证 Windows 系统文件选择对话框。

目检发现 OCR 安装截图拍在淡入动画途中，出现背景透过面板的暂态画面。独立原生复核测得开始透明度为 0、动画结束后为 1，面板背景不透明，稳定截图没有内容重叠。取证脚本现等待有限入场动画结束后抓屏，保留实际动画；早期截图和失败的首次自检启动日志也保留。此次截图调整发生于八项 OCR 流程完成后，后续复现使用更新脚本，不将它冒称为已重新执行整套 OCR。

## 第三批仍在进行

本次确认清理期间的代码可编译并走通上述 Windows 流程；不等于 B3-51／B3-52 或第三批全部验收。仍需：

- 三种真实引擎的跨进程预算与拥有者崩溃矩阵；正式 TeX 输入、对应源码／材料和许可证审查；冷态时限。
- 安装／卸载的持久化事务与重启恢复，跨进程传输总预算、旧客户端隔离，AppContainer 配置与临时映射回收。
- 完整数学语义、全部出版参数、真实 Word 往返和独立 EPUB 阅读器；八小时压力、46 语言语义及其他平台原生证据。

安装和卸载的 `install-*`、`remove-*`、`replaced-*` 仍可能含回滚依据，不能按前缀清除。尝试删除本次四个明确拥有、已结束且已归档的测试配置时，自动审批返回 `blocked by policy`，命令没有执行；这些目录继续保留，不换工具绕过。构建保持一份并关闭增量，正式包只保存一套。TeX 固定输入的恢复独立记录，不把宿主 TeX 当作软件运行依赖，也不恢复历史重复构建与测试副本。

恢复 TeX 固定输入时，533 份容器中已有 524 份通过原摘要；其余 9 份包含连接失败、传输中断和上游内容超过锁定大小。基础归档两次下载超时，尚未取得可验证的完整文件，独立续传仍在进行。没有放宽摘要、更新受信清单或建立运行库；失败记录见[输入恢复状态](../evidence/capability-upgrade/2026-10-11/batch3-cache-resume-tex-inputs-status.json)。缓存分类及删除拒绝见[本次缓存清单](../evidence/capability-upgrade/2026-10-11/batch3-cache-resume-cache-inventory.json)。
