# 第三批：公式装饰与注释起始编号实测

本轮完成 B3-55、B3-56 的一个增量，完整第三批仍未完成。未发布、未替换用户安装程序。

## 实现与实际行为

公式分组字符正确区分缺省与显式空值，位置和基线独立控制四种排版。长重音及分组字符使用 OpenType MATH 横向变体和有界装配，延长符号时保持笔画尺寸。MathML 导入区分重音、横线、分组符和普通上下限，显式 false 优先；不能准确表示的装饰保留内容并报告投影诊断。本增量不宣称完整 MathML 算子字典兼容。

注释高级设置增加 1–9999 起始编号，提供 46 语言文字。DOCX 写原生 w:numStart；Typst PDF 与 EPUB 产生对应可见编号。编号偏移与注释身份分离：重复引用沿用同一目标，回链仍有效。长字母编号使用自适应列宽，避免挤入注释正文。用户预设在真实进程重启后保留。

PDF 加载遮罩的隐藏规则移除多余 !important，真实窗口验证加载时隐藏旧内容、完成后隐藏加载及上下文控件。

## 原始失败与修正

新增 Rust 测试先出现 2 项、后 1 项断言失败：Office 数学字形与 LaTeX 多字母文本投影不能直接比较；不同长度会选择不同字体变体，任意高度阈值不可靠。最终比较原生 Office 字形及两种实际装配长度，严格验证高度／深度不变和字形缩放 1.0。两轮失败源码、结果保留；首轮完整输出被工具截断，明确记为缺失，未重建伪造日志。

出版布局首次失败是旧 QA 未安装锁定字体包，第二次是字体变化使旧分页临界材料失效。先保持核心 Word 无外部引擎检查，再安装正式字体包；按实际 PDF 行距调整材料的两处填充行数，保持标题随文、整段保持和孤行控制的原严格断言。两轮原始失败报告、源码与输出均保留，未计入最终 35 项。
