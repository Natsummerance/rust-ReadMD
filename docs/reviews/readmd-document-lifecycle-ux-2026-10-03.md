# ReadMD 文档生命周期与用户体验检查清单

日期：2026-10-03；工作树基线：`05ec02d`。这是[全部前端功能清单](readmd-ui-function-inventory-2026-10-02.md)的文档保护细则，覆盖编辑、保存、另存为、副本、转换输出、AI改写、撤销、关闭与恢复。既记录操作结果，也说明落盘位置、失败行为、前后端实现和实测范围。新增入口已纳入总清单 F102–F104。

## 采用的交互原则

参考 Office 的编辑与保存惯例，没有把某个产品的行为称为正式行业标准。Microsoft 建议先保存副本再编辑，以避免自动保存改变原文件；ReadMD 用“创建编辑副本”建立独立草稿，用户选择路径后才落盘。[Microsoft：编辑前保存副本](https://support.microsoft.com/en-us/office/collab-files/save-a-copy-before-editing-to-prevent-changing-the-original-file)

Office 的 AutoSave 具有云文件和环境条件，AutoRecover 则用于异常后的内容找回。ReadMD 对本地文档采用“手动保存原件 + 自动保留恢复草稿”，避免未确认的 AI 修改或转换结果进入原文件。[Microsoft：AutoSave](https://support.microsoft.com/en-us/office/collab-files/what-is-autosave)、[保存、备份与恢复](https://support.microsoft.com/en-us/office/collab-files/save-back-up-and-recover-a-file-in-microsoft-office)

历史版本和当前编辑内容分开。恢复时先成为未保存草稿，可以检查、撤销、另存为；明确保存后才替换磁盘文件。跨会话恢复使用持久化历史记录，不冒充跨重启仍可使用的编辑器撤销栈。[Microsoft：恢复较早版本](https://support.microsoft.com/en-us/office/collab-files/recover-an-earlier-version-of-an-office-file)

## 状态与存储约定

| 对象 | 用户看到的状态 | 所在位置 | 什么时候写原文件 |
| --- | --- | --- | --- |
| 已打开原文件 | 文件路径、标题、原文与内容指纹 | 原文件 + 内存标签 | 点击保存且后端确认成功 |
| 正在编辑的草稿 | 脏标记；恢复反馈与“已保存”分别显示 | 编辑器/标签；自动恢复记录 | 不随输入直接写原件 |
| 新建空白文档/转换/OCR/网页预览 | 未编辑时关闭无提示；编辑后首次保存需要路径 | 内存；实际修改才写恢复草稿 | 用户选择保存位置后 |
| 编辑副本/AI副本/剪贴创建/历史恢复 | 新创建的未保存内容需要保存确认 | 内存；集中恢复记录 | 用户选择保存位置后 |
| 保存前版本 | “保存前版本”记录 | 应用数据目录 `document-history` | 不直接覆盖；恢复后再保存 |
| AI替换/恢复/冲突重载前内容 | “操作前检查点” | 同一集中目录 | 仅保存当前编辑器时 |
| 用户选择不保存的内容 | “已放弃的草稿” | 同一集中目录 | 原文件不改变 |
| 浏览器另存为下载 | 已发起下载，草稿仍未保存 | 浏览器下载流程 + 恢复记录 | 浏览器无法确认用户实际落盘，不清除脏状态 |
| 图片伴随资源 | Markdown 中使用的相对引用 | 用户明确选定的 `<文档名>.assets` | 属于实际文档资源；按需复制、同内容复用 |

恢复正文使用 gzip，元数据使用 JSON，正文完整性使用 SHA256。统一限制：正文 UTF-8 最大 **16 MiB/条**；**每文档10条、总256条、正文和元数据共64 MiB、保留30天**。元数据单条最多8 KiB，包含来源目录和资源引用；不将图片二进制复制进历史记录。超限或磁盘写入失败会反馈并保留当前编辑器；覆盖旧文件前无法建立版本记录时拒绝覆盖，用户可以另存为新路径。

自动恢复在输入停止约 **1.5秒**后触发，另有10秒维护、失去页面可见性和正常关闭时的刷新。只有后端确认的草稿才能跨重启找回；强制终止前尚未完成写入的最后一小段输入仍可能缺失。相同内容去重、每文档仅保留一个当前自动草稿；旧版本按期限和容量清理；中断产生的孤立正文/元数据对在维护时清理。恢复记录位于本机应用数据目录，未加密，随当前用户的文件权限保护；删除记录会删除该条正文和元数据。

跨目录另存为会自动处理标准 Markdown 图片及已登记的资源；普通附件链接、HTML `<img>`、CSS资源与用户手写的其他相对路径保持用户文本，不能把此功能当作任意网页项目的完整打包。删除或替换图片后不自动删除既有用户 `.assets` 文件，避免损坏其他引用；集中历史限额也不会擅自清理用户文档资源。

## 2026-10-04 关闭与更新补充

关闭确认以当前文字与保存基线的差异计算，LF/CRLF/CR规范化后比较。打开、进入编辑、移动光标及撤销回原文均不提示；真正输入、删除或应用改写才提示。AI生成的新副本、剪贴创建和恢复草稿仍属于新建内容，关闭前保护。转换/OCR/网页只读预览没有改动则可直接关闭。

关闭窗口默认只收起到托盘，编辑器和草稿保持运行；更多菜单“退出 ReadMD”才完全退出并检查全部标签。取消驻留后，窗口关闭与完全退出使用相同保存保护。安装更新也先处理未保存内容，取消不调用安装接口；失败保留恢复数据。证据：`ui-tests/window-upgrade.spec.js`、`ui-tests/window-native-smoke.cjs`。
