## 当前实现

- 文档关闭、编辑退出、主页、新建、切页及真正退出共用本地操作所有者，直至完整操作结束才释放。外部打开与导入排队；普通保存继续使用固定文档快照，允许切换到其他文档。
- 确认绑定页面对象、路径、修订、编辑 generation 和 Rust 审阅头。同文撤销仍使旧确认失效；保存等待期间的新输入不会被旧的“保存并退出”结束。服务提交自身的同步资源改写与新输入分别计数。
- 丢弃保留原文后逐次复核 generation，并把预期审阅头交给既有 Rust 修改服务。通用草稿清理带原文和时间界限，保护另一个写入者新增的草稿。
- 缺失正文显示受保护失败页，提供重试与历史记录，禁止空编辑／另存／导出和普通关闭。Rust 的 `preserved_tabs` CAS 约束同时检查旧、新快照中的完整描述，参与幂等指纹；旧后端没有 `recovery_guards` 能力时继续拒绝写入。其他页面仍可关闭，应用可正常退出并保留缺失记录；真实正文找回后继续恢复。
- 新文件激活前先保存旧编辑器的所属页面，防止相同正文导致跨文档继承选区／编辑状态。旧页再次激活时保留自己的选区。

受保护的 `editor.js`、`preview.js` 保留精确字节，未修改保护摘要。新的入口适配器复用原保存、审阅和恢复服务，未复制 Rust 业务写入，也未改变后端权限边界。
