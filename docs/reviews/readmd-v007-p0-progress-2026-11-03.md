本次获授权完成 P0 开发，正式发布另行执行。基线为 `87dde50d`，开发分支为 `codex/v007-p0-safety-20261103`；日常安装的 V0.0.6 和 GitHub 下载未由本次开发替换。75 条合同状态仍为 63 进行中／12 待办／0 整项验收。

## 当前实现

- 文档关闭、编辑退出、主页、新建、切页及真正退出共用本地操作所有者，直至完整操作结束才释放。外部打开与导入排队；普通保存继续使用固定文档快照，允许切换到其他文档。
- 确认绑定页面对象、路径、修订、编辑 generation 和 Rust 审阅头。同文撤销仍使旧确认失效；保存等待期间的新输入不会被旧的“保存并退出”结束。服务提交自身的同步资源改写与新输入分别计数。
- 丢弃保留原文后逐次复核 generation，并把预期审阅头交给既有 Rust 修改服务。通用草稿清理带原文和时间界限，保护另一个写入者新增的草稿。
- 缺失正文显示受保护失败页，提供重试与历史记录，禁止空编辑／另存／导出和普通关闭。Rust 的 `preserved_tabs` CAS 约束同时检查旧、新快照中的完整描述，参与幂等指纹；旧后端没有 `recovery_guards` 能力时继续拒绝写入。其他页面仍可关闭，应用可正常退出并保留缺失记录；真实正文找回后继续恢复。
- 新文件激活前先保存旧编辑器的所属页面，防止相同正文导致跨文档继承选区／编辑状态。旧页再次激活时保留自己的选区。

受保护的 `editor.js`、`preview.js` 保留精确字节，未修改保护摘要。新的入口适配器复用原保存、审阅和恢复服务，未复制 Rust 业务写入，也未改变后端权限边界。

- 当前源码候选：Node 1807 项，1804 通过、0 失败、3 项 Windows 专属跳过。浏览器 30 条通过，使用当前 Rust 后端、正式 CSP、真实鉴权；其中历史 Save As 用例仍是既有 chooser 适配器测试，不计作原生选择器证明。
- Rust 设置／会话回归：20 通过、2 项原有忽略。真实持久文件验证保护描述不能被删除、改写或重复，以及严格版本、幂等、故障与回执语义。不是全库回归成绩。
- 前一前端候选在实际 Mac 宿主中完成关闭／保存 32 项、不可用文件恢复 24 项、受保护草稿恢复 35 项、应用菜单及 delegate 生命周期 35 项，共 126 项。该候选的 boot 摘要与各原生报告绑定；不移用到随后增加编辑器所属页修复的候选。
- 受保护草稿原生用例包括实际 Rust HTTP 409 拒绝、版本与描述不变、无空草稿、其他页关闭、正常退出、找回正文、同页恢复、新进程重开和明确丢弃。中间一次在已确认检查点后受控退出，单独记账，不等同真断电。
- 原生红黄绿窗口用例保留首次失败。最后一个标签表示保存前置条件失败，并非已经成功保存后脏标不清；取消关闭后，用例原先只等待弹窗隐藏，现改为等待整个操作结束。新等待条件尚待最终原生重跑确认，未记为通过。
