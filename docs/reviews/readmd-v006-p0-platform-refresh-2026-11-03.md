# V0.0.6 P0 全平台发行包替换

2026-11-03。[现有 V0.0.6 发布](https://github.com/Natsummerance/rust-ReadMD/releases/tag/V0.0.6)的 **十个软件/集成包及总摘要已全部核对**：保留本轮已通过原生验收的四个 Mac 包，另替换 Windows ZIP/安装程序、Linux tar/DEB、VS Code VSIX、MCP 配置工具包。没有移动原标签，没有发布 V0.0.7。完整摘要与回执见 [机器记录](readmd-v006-p0-platform-refresh-2026-11-03.json)。

Mac 包源码 `fb6eaa74`；其他包构建源码 `adf7ac45`。两者 Rust、前端及 VERSION 的 Git 内容相同，后者只增加验收流水线及测试。Windows 检出把未固定换行的文本转为 CRLF，其实际 boot 为 `40bbdec8…`；Linux/Mac 为 `0870e8a9…`。检查使用精确 Git 字节或精确 CRLF 派生两种预期，其他字节差异均拒绝；实际包摘要分别绑定，没有将 Mac 的摘要冒充 Windows 结果，也未修改受保护源文件或测试摘要。

Rust 库计数包含隔离时限通道 34 条和其余库回归，两个通道不重复计数；main/xtask 等检查也通过，但不混入库计数。所有编译继续使用锁定依赖和离线 Cargo；下载依赖在独立准备步骤完成。

真实归档逐项检查 PE/ELF 架构、boot/index/生命周期资源、VSIX 编译产物和 MCP 原始配置/文档。Windows 安装器的程序及这些资源与便携 ZIP 完全一致；Linux DEB 与 tar 中程序完全一致。MCP ZIP 仍是说明及配置工具包，不声称其中内置了 Rust 服务程序。

源码检查确认 Windows/Linux 窗口关闭都进入共享恢复边界；关闭决定、generation、会话 CAS 及资源恢复由同一前端/Rust 服务处理。两平台正式二进制均在生产 CSP、真实鉴权下验证保存、丢弃、取消、延迟请求、新输入、跨文档目标、缺失文件、重试和重开。历史 chooser 适配器用例不计作原生文件选择证明。

## 发布与首败

[候选构建](https://github.com/Natsummerance/rust-ReadMD/actions/runs/41633639030)的全部门槛通过后，[替换工作流](https://github.com/Natsummerance/rust-ReadMD/actions/runs/41639269079)先下载并校验原始 CI artifact 摘要、复查实际包，再上传全部候选；整组候选认证完成后才切换正式名称。每步留意图与回执，中途失败恢复原公共资产。最终摘要/说明核对完成后删除本轮旧备份，回执为 `complete`，无遗留备份。

替换工作流匿名重新下载六个包及 SHA256SUMS，共 7 项字节/摘要检查通过；本机又独立核对 GitHub 十个正式文件、全局摘要、原标签及本地六包与远端回执一致。Mac 原生候选的四个摘要保持不变，先前公开 ARM 下载与本机安装一致的证据仍有效。本机应用及“最新交付”的十个软件入口已同步，本地按实际文件名执行十项摘要校验全部通过。两处官网链接继续指向同一 V0.0.6 正式入口。

首败没有删除：Mac 独立单测竞争同用户安装锁，收到正确的 busy 拒绝，改为串行调度并保留专用并发测试；Windows 输出截断用例首次在完整回归中超时，同提交完整复查通过，没有修改产品超时或降低原断言。后续 CI 配置将整个代码运行模块（含 parity 适配器）放入独立时限通道。该 CI 修改还遇到未引用的双冒号 YAML 语法错误，已改为命令块并通过本地 YAML 解析；它没有改变已验候选的业务源码。只允许 LF 的初次归档检查则发现了 Windows CRLF 检出，随后按上述精确字节规则记录，未把其他改动抹平。

## 继续开发的边界

用户接受本轮非 Mac 的 CI/原理级验收；原生宿主缺项保留，未安装或启动虚拟机。[虚拟机调研](../design/cross-platform-vm-options-2026-11-03.md)已经完成。非 Windows 严格组重命名继续明确禁用；手工图片历史缺少精确映射时跨目录另存安全拒绝。Linux 容量前检及跨平台预算协调、实体 Intel、原生 IME、语言语义和长期性能继续列账。

本轮未加载本机模型，未影响用户 LLM，未修改宣传/安卓资产。清理约 1.136GB 本次重复包镜像、下载副本和 artifact 外层 ZIP，保留正式包、失败证据、恢复输入和私下回退，不跟随符号链接清理。75 条合同仍为 63 进行中、12 待办、0 整项验收。下一阶段按 [V0.0.7 计划](../design/v007-execution-plan-2026-11-02.md)完成 P1，再完成 P2；全部验收前不发布 V0.0.7。
