## 实际实现

- `omml.rs` 共用最小列宽、空槽判断和占位符开关。依据 [Microsoft cSp](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.math.columnspacing?view=openxml-3.0.1)，实际列宽取内容宽度与 `cSp/20 pt` 的较大值，再另加列间隙。12／24pt 正文及脚本中绝对单位保持，宽内容不截断。
- 依据 [Microsoft plcHide](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.math.hideplaceholder?view=openxml-3.0.1)，省略／显式关闭显示细线空框，空开关／开启隐藏。空框不产生正文字符；隐藏状态仍保留可选源槽位及尺寸。保留空格、隐藏 phantom 和嵌套结构，不误判为空。空框形状是 ReadMD 的表现选择，不能据此宣称与 Word 外观完全一致。
- 矢量预览、HTML、PDF 复用 Rust 布局；MathML 保留原生可访问结构，使用物理 CSS 最小宽度。实际发现应用的全局 `border-box` 与 MathML Core 忽略 `columnspacing` 会吞掉间隙，因此明确投影内容盒、内部半间隙、外沿零间隙及列对齐。不使用可能裁切的 MathML 固定 `columnwidth` 冒充最小宽度。
- MathML 回流识别统一最小宽度及生成的无文字空槽，恢复最小列宽、隐藏状态及参数字号；不同列下限、混合可见性、其他空白或样式给出既有损失诊断。格式化 XML 缩进与 CSS 空白纳入边界验证。
- 沿用现有高级属性及正文槽位编辑，没有新增面板、按钮、依赖或可见文案；已有可读 DSL 可以完整表达这些参数。
