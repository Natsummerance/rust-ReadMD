# 第三批：MathML 结构格式与自包含电子书数学字体

修复 Word 结构控制格式在 MathML 中丢失，以及直接使用运行点数造成上下标不能正确缩小的问题。共享数学样式状态计算分式、脚标、根指数及参数字号；渲染临时树分别解析控制字符与子运行的字号／颜色。原始模型、DSL 和磁盘正文不因此修改。

EPUB 采用实际导出预设的默认点数和前景色，自动颜色不会误继承外层控制字符的显式 RGB。含普通 LaTeX 或 Office 公式的书籍嵌入已有 STIX 字体及完整 OFL 许可；无公式的书籍不增加字体。没有新增依赖、下载运行引擎或改动默认界面。

验证同一离线构建（SHA256 `1e59849f70a25f36d9d8261cc6dd02f9a3fe40acab5c4a379ecf440c73d9981f`）：

- Rust 完整库：2271 通过、0 失败、3 项既有忽略，147.76 秒；数学专项162通过、0失败。
- 正式 CSP Edge：8 项通过、零自动重试，52.8秒；Windows 原生已有控件流程6项通过，实际 MCP4项通过。
- 新增 Windows 原生链路：真实 HTTP 编译和 DSL 往返、导出三份 EPUB、独立解包、以原始 XHTML/CSS/字体在 Edge 渲染，4组检查通过。未重写 HTML、注入替代字体或绕过 CSP。
- 实际几何检查：24pt 红色结构、16pt 蓝色操作数、默认 `#123456` 自动色；70%／55% 脚标比例分别产生11.2pt／8.8pt，嵌套分式和根指数均检查。检查1160×820及1024×680截图，无遮挡。
- 三份实际 EPUB（Office／普通 LaTeX／纯正文）由固定 EPUBCheck5.4.0 离线检查，全部零致命、零错误、零警告。该工具从已有锁文件指定的官方发行版恢复到隔离 QA 目录，校验发行包及全部运行文件摘要；不作为软件运行依赖。

失败保留：第一次原生检查错误地比较不同语法的源节点路径，实际值相同；改为比较数学语义元素及所有渲染属性。新增 MCP 断言第一次没有考虑源映射的合法 mrow 包裹，修正匹配后通过。两份原始失败报告和对应日志保留。数学首轮编译时测试中未限定 json 宏，已改为明确的 serde_json 宏；编译失败日志保留。没有跳过失败检查或增加自动重试。
