# V0.0.5 发布候选验收与范围

2026-10-25。本报告记录当前有限版本的实际证据；正式发布还必须由 V0.0.5 标签对应的全部质量检查和四平台打包任务共同放行。没有将第三批所有长尾、第四批或其他平台完整原生体验标为完成。

## 版本合同

沿用[发布范围和 V0.0.6 接续](../design/v005-release-scope-2026-10-25.md)。75 条大范围需求保持 60 项进行中、15 项待办、0 项整项验收；这不是 V0.0.5 不能发布的承诺，也不是将未完成能力变成已实现的依据。保留工具栏修复、现有保存／外改保护、首屏刷新和宽屏阅读体验。

本轮修复包括：

- Windows 受管理能力包深长路径空间查询；真实长路径安装三包成功，并运行了真实 OCR，未缩短产品测试路径。
- 明确区分真实 STIX 数学字体与 Cambria 等替代字体；格式修订损失按实际行为提示，保留源文件。
- 段落装饰不再使引用、编号等整个阅读投影退化；46 种语言补齐本轮新增提示的译文。
- macOS 固定系统目录别名按受信任前缀处理，不放行普通用户目录中的符号链接。
- Unix 能力租约释放不再被无关继承描述符延长。两个真实 fork 对照验证原始 close 的失败形态、显式解锁后的即时重获和独立共享拥有者保护；Windows 实现和既有跨进程断言保持。
- 历史录屏绑定实际历史清单，不把已变化的功能语义冒称为录制内容；新能力和说明型交互图与旧操作视频明确区分。

## 追加的二进制隐私阻断

递归检查已解压文件、桌宠 ZIP 内部内容和 UTF-8／UTF-16 字符串时，旧受管 SVG 渲染器发现本机编译路径。没有发现个人模型连接配置或密钥；旧候选归档仍被判为不允许正式发布。

从原已审归档恢复同一 `resvg 0.48.1`，源归档 SHA-256 为 `13ed5a2bae7a01156288ecae5bf944cf7d1c572742c19fc68027947a4d87294c`。构建使用 `--locked --offline --release`、两个编译任务、关闭增量并复用唯一构建目标；不修改或补丁替换二进制字符串。

源码、Cargo、Rustup 和用户目录使用 `--remap-path-prefix` 映射至稳定虚拟路径。新渲染器 SHA-256 为 `a07a9e379a891d4ccc04d9162aa4cdffebb2c0b62759be058d0435d37be35d84`、4178944 字节，60 项依赖许可清单保持。研究图、透明渐变、数学文字三个实际样本生成六张 PNG，新旧对应文件逐字节相同。

永久门禁在一般目录／文件类型跳过之前识别 PE、ELF、Mach-O 和原生库，检查 ASCII 及 UTF-16 LE／BE；错误仅说明文件和类别，不回显匹配内容。SVG 打包器在创建输出前拒绝污染内容，写出已检查的同一份字节。Windows、Linux、macOS 发布暂存目录在压缩前接受该门禁。新增正反控制同时覆盖外部产物、无扩展程序、Windows 空格路径和环境文件注入。

最终资产以正式工作流、发布页和 `SHA256SUMS.txt` 为准；上文旧便携包的核心功能证据不能当作新安装包摘要。最终发布后还需对实际新包进行关键冒烟和私密值扫描。

## 首败和未验范围

- 原 Windows 长路径 `space_query` 首败保留，修复后真实安装及 OCR 成功。严格跨传输故障矩阵仍未认证：产品准备完成，但本机 Python 启动器造成观察器声明的进程层级不一致；直接启动对照又不能正常传递定向控制事件。没有放宽拥有者校验、200ms／2s 断言或改写失败结果。
- RC4 Windows 两项短 Node 脚本在共享 runner 上出现截止时间／退出码失败，诱因未定；RC5 因 Unix 产品修复形成新候选且完整通过，不记作已根因修复 Windows 性能首败。受控冷启动、阶段采样和并发压力进入 V0.0.6。
- Word／WPS／阅读器 GUI 互操作、完整 OMML／CSL／复杂分页、TeX 正式资源闭包、八小时压力、全平台 GUI 与全部 46 语言人工语义审校仍待验。保留原记录，不用 XML 合法、交叉构建或测试数量替代。
- 第四批持久正文 AI 审阅、多轮 Harness、协作、专业图像／绘画等依照 V0.0.6 工作包推进；不作为当前宣传片的已交付能力。
