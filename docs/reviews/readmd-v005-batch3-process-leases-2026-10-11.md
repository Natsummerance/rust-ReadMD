## 实现

受管理能力使用固定、空的 `capabilities/.locks/{id}.lock` 协调同一配置的桌面、MCP 和安装进程。使用资源持共享租约；安装、修复、卸载和真实就绪探测持独占保护。文件不作为 PID 标记，也不删除或截断；进程结束后由 OS 关闭句柄。锁名只能来自固定能力 ID，非空文件、非普通文件和重解析目录均拒绝。

Windows 使用不继承的文件句柄及共享模式。Linux/macOS 有 `flock` 实现，但本次仅 Windows 原生验收，不能从源码推定其他平台通过。该机制协调遵守同一协议的 ReadMD 客户端，不代替引擎 OS 沙箱；旧客户端兼容边界另在 B3-52 验收。

出版字体从仅计数改为实际资源租约，覆盖读取、排版和输出期间。OCR 的最小实际探测同样在租约内执行。字体等待被取消时优先返回取消，不误报缺包；内容和既有输出不被取消写入。

检查发现等待另一个进程安装资源时仍持有本进程全局安装锁，会阻塞无关能力；现在每次 OS 锁争用后释放全局锁再等待。拿到共享保护后才登记本机租约和工作名额，之后释放全局锁执行完整摘要校验。能力清单先检查，缺少或损坏应用锁时不创建协调目录、工作文件或占用名额。

没有新增应用依赖、UI 或翻译键，继续使用已有忙碌/取消/损坏提示。

## 实际验证

`capability_process_probe` 调用真实安装/API、字体作用域和内置 PDF 服务；使用正式审查过的字体包、合成材料与独立配置。两个读取子进程均先实际导出 PDF，再保持资源作用域。12 项检查通过：

- 活跃共享资源阻止另一进程修复、卸载、离线导入和开始上传，字体摘要不变；其他能力仍可查询。
- 终止第一个读取者不会解除另一个的保护；终止最后一个后恢复实际就绪，无 PID 清理。
- 安装器在真实验证阶段持独占保护时，状态查询不穿透探测，其他写入拒绝。日志屏障只用于安排此竞争时序，明确属于 QA，不把它当普通用户操作。
- 真实导出等待安装器时，取消完成 8ms，原先输出保持；同一时刻 OCR 状态查询 4ms，不再等待字体锁。
- 写入者正常完成后资源恢复；闲置卸载保留未知文件及固定空锁。非空锁原字节不被截断；实际 Windows junction 指向隔离哨兵目录时拒绝，不写目录外文件。

正式 CSP 的字体原生流程另有 6 条通过：无包基础 DOCX/数学 PDF、缺中文字体旧输出保护、入口取消及恢复、实际安装继续分页、两引擎真实输出、损坏/修复/卸载缓存失效，以及真正宿主重启。该套为既有六条工作流回归，不与其他套件相加当成功能数；本次截图为 1160×820，其他语言/窗口/DPI 全矩阵仍按原合同验收。

两个进程输出的 PDF 字节一致。独立检查覆盖六份实际 PDF 共六页的中文/希腊符号/表格文字、字体、矢量和无栅格图像，并逐页目检；正式分页截图也已查看。中文 TrueType 字体确实嵌入，数学交换文字的 Type3 字形程序及 Unicode 映射分别检查。标准 Helvetica 仍未嵌入，不把本样张当成全部字体完整嵌入认证。默认原生与 Typst 表格宽度/版式存在差异，完整跨格式参数一致性保留在 B3-56。

清理前直接读取的完整离线锁定 Rust 日志为 2,100 通过、0 失败、3 项既有忽略，耗时 172.05 秒。先前运行还报告最终主程序/示例构建及静态检查通过；原始材料目前不可复核，不能为新代码或发布验收背书。已归档的历史证据没有被覆盖；正式包目录仍只有原四包。

## 失败与修正

初次完整库为 2,099 通过、1 失败、3 项既有忽略。失败是缺少 TeX 清单仍创建了协调目录；修正前置清单检查，没有修改不写入断言。

真实示例的名称遮蔽已修正；第一次编译其新增通道检查时出现作用域借用错误，改为显式转移发送端和克隆的 App 引用。该失败日志保留，不计通过。

第一次字体原生检查在独立字体检查器失败：此前检查器把所有 ReadMD 命名字体都要求为 TrueType，误含新增的 Type3 数学交换层。现在分别严格检查真实 TrueType 字形与 Type3 内嵌字形程序/Unicode 映射，不跳过数学层，随后完整重走六条实际流程。单次临时检查也曾犯相同分类错误，未作为通过证据。
