## 实际交付

| 范围 | 实现与操作行为 |
| --- | --- |
| P05／P08 编号 | 文档持有可读的 readmd-numbering:v1 声明，六级标题与公式／图／表分别设置格式、起始、重启及分隔。现有版式／导出高级区复用同一折叠组件；读取不改正文，应用／清除均为一次受修订保护的可撤销事务，异步返回不能覆盖其他页。编号不改变作者标题和稳定引用身份。 |
| 多格式编号 | Word 输出原生多级编号、STYLEREF／SEQ／REF 字段；EPUB、阅读、Rust PDF、Typst 与 TeX 共用源规则。Office 字母序列采用 27=AA、28=BB、52=ZZ、53=AAA；非 Excel 列号算法。TeX 标签使用可逆、无碰撞的编码，中文／希腊 ID 与相似 ASCII ID 不互相覆盖。 |
| 目录避让 | TeX 按目录实际字体、字号及字重测量每层编号，缓存宽度并保留原生缩进、引导点、页码和换行布局。新增独立逐字符几何检查，旧候选的真实重叠页面必须被拒绝；文字齐全不再等于布局合格。 |
| P06 注释 | 连续、源分节及物理页重启进入统一模型；DOCX 写原生注释设置及分隔／续页故事；长注保留分段与拆分策略。EPUB 没有物理页概念，无法表达的续注与页重启明确报告；章节拆分不冒充源分节。 |
| P07 引用回流 | DOCX 内为引用与参考文献写独立身份、来源摘要和有界资源包。搬离原目录后可读回可编辑引用，不依赖旧主机路径；源改、显示改、混合改、重复／移动身份分别处理。手工修改过的引用、文献和注释保留当前内容，旧源用于恢复，不静默还原。 |
| 导入与锚点 | Word 复杂字段跨段落及嵌套解析隐藏指令而保留结果；用户文字中的 HTML／Markdown 语法做正确边界转义，真实富文本不被破坏。Typst 内部注释、回跳、源分节标签与作者 ID 分域。阅读首次分页和回到已访问页时先建立完整标题身份，避免编号和目录失联。 |
| 错误与本地化 | 新增 51 个界面／诊断键均提供 46 语言显式内容，结构检查为 2806 键。新增脚注布局错误有定位数据和可操作提示；这不是全界面母语审校认证。 |

编号 HTTP /api/publication/numbering 与 MCP readmd_publication_numbering 共用 Rust 服务。编号声明是文档属性，不混入导出预设，也不会因仅打开文件而保存到磁盘。

关系上下文的证据分层记录：真实 DOCX／MCP 覆盖链接目的地修改、无关关系及旧签名回流；Rust 确定性回归覆盖三个 story 的 r:id／r:embed／r:link 及同目标媒体载荷变化。实际媒体变异另检查回流和再导出资源字节。当前引用富文本模型不支持原生图像节点，没有把伪造并重签的图像 SDT 冒充实际源生的完整 MCP 绑定链。

编号与注释设置的回导单独保留缺口：本轮 DOCX／EPUB／PDF 转回读取验证正文、号码和身份，没有完整重建源编号配置；DOCX 注释设置也没有无损回导认证，二次导出的测试显式重新提供设置。可读产物与相同设置下的再次输出不能冒充完整可编辑参数往返。

## 实际发现的引擎限制与保护

锁定 Typst 0.15.1 的原始 72 段／144 注释测试发现，默认可拆段落布局会把少数脚注起始页排在引用之前，原始 PDF、逐词坐标及视觉检查全部保留。该问题对应上游 [#5314](https://github.com/typst/typst/issues/5314)，本轮没有把改动测试布局称为修好了引擎。

生成源末尾增加不改变布局的真实脚注起始页核验；不一致返回 publication_note_layout，附注释序号、引用页和定义起始页；诊断按随机身份、生成文件及严格字段校验。编译未收敛也在提交 PDF 前拒绝。真实 MCP 测试用已存在的有效 PDF 作为目标，确认失败后原字节和摘要不变。选择“段落内不分页”的同一完整材料通过 144 对注释／引用、页内重启与双向跳转检查；默认原案例记录为受保护的失败，不认证默认布局成功。长注续页允许，核对的是起始页，不要求所有续页与引用同页。

官方依据另见 [Typst 0.15.1](https://github.com/typst/typst/releases/tag/v0.15.1) 及其 [footnote 实现](https://github.com/typst/typst/blob/v0.15.1/crates/typst-library/src/model/footnote.rs)。
