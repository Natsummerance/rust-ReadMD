## 首次失败与修复

Mac 真实 HTTP 请求启动专用 Node 定时器后，正常终止它自己的内核，worker 仍继续等待。首败、精确脚本与进程归属证据保留；只清理核实过的测试进程。初次夹具误认脚本所在层级的失败也单独保留，未当作产品成功或失败。

代码请求及底层 SQL、子进程现在登记到当前内核持有的执行集合。宿主正常关闭时关闭新准入、发出取消并有界等待实际回收，调用者原来的取消信号仍然有效。两秒内未确认回收时保留退出失败，不返回正常完成。登记不扫描宿主其他进程，不触碰用户 LLM。
