## 实际实现

| 项目 | 行为与验证 | 保留边界 |
| --- | --- | --- |
| M01 noBar | 使用字体 StackTop/BottomShift 与 StackGapMin，独立处理行内／独立样式；墨迹间距不足时双方分担修正。smallFrac、缺省继承和显式控制字号分别验证。 | 不把普通横线分式参数冒作叠式；Word 应用排版仍需独立比较。 |
| M01 skw | 使用字体横纵 gap，斜线绕数学轴居中，选择实际变体／装配；长分式超过字体最大 slash 时有明确均匀放大回退，保留参数身份和覆盖范围。linear 与普通分式保留原语义。 | 无 slash 装配时均匀放大可能增厚，未宣称 Word 像素等价。 |
| M02 根式 | 从真实根号与指数墨迹确定百分比位置，读取字体前后 kern；短指数夹限，长指数、正／负 yMin、空／隐藏指数、高根式装配均测试。 | 使用被冻结字体的 55% 与 65/−335 设计单位，而非固定 60% 和任意距离；全字体／Office 认证未完成。 |
| M02 横线 | 上下横线独立 gap、厚度及额外高度；额外高度只保留逻辑留白。嵌套横线不重复计算内部留白。 | 整体绘制与结构尺寸分开；其他 Office 组合继续验收。 |
| M02 重音 | 基底与实际选中字形的附件点对齐，计算 glyph 原点；复合基底使用中心回退，保留左右墨迹范围。有限变体没有装配时只横向拉伸，保持设计高度，点重音不拉宽。 | 冻结 STIX 的 wide hat 无装配，未伪造“使用了装配”；字体 flattening 和复杂文字仍开放。 |
| phantom 组合 | 有效尺寸独立于显示；根式／横线／重音尊重隐藏内容及 zeroAsc/zeroDesc/zeroWid。最外层占位拥有零尺寸开关；隐藏后不会被误判成单字形基底。 | 新增混合可见／隐藏内容、嵌套、零尺寸的反例回归。 |
| PDF 继承字号 | 标题与表格中的公式按实际段落字号重新排版；冻结源码、字体与宽度，避免把显式 Office 物理字号一并放大。同字号复用原公式；栅格图片尺寸保留。 | 非法字号不更新公式几何或 Run.size；有效出版字号来自现有参数约束。 |
| PDF 显式样式 | 行内代码保留独立字号和颜色，链接保留原 href 与颜色。 | 继续完整出版参数与其他引擎的一致性验证。 |

## 首次失败与修复过程

初始 Rust 专项捕获宽重音超过有限变体、斜体基底负左边界和隐藏占位组合问题；另一个 noBar 失败源于测试遗漏了首操作数继承控制字号。产品问题加入反例后修复；测试预期按明确的字号契约修正，并增加显式控制参数对照，未降低间距和边界断言。

旧候选三次原生检查独立保留：第一次是 DOM 矩阵逆变换约 1e−16em 的浮点差，改用既定数值容差且保留字形／数目检查；第二次发现正文参数合法范围为 8–20pt，不能将被归一化的正文输出当作 24pt；改用正式支持 24pt 的标题参数后，第三次捕获真正的 PDF 公式继承字号缺陷。此前按默认正文尺寸布局，再把公式作为普通图片跳过继承，标题字号未传到数学引擎。

修复后重新跑定向、完整库、离线构建、所有原生组和 MCP。旧 `ab4fec…` 的成功／失败记录均不计入最终 `2a3fdf…` 的通过数；原始失败、输入、输出和日志保留，没有自动重试成功替代修复。

## 尚未结项

真实 Word 编辑／保存往返及独立 EPUB 阅读器没有取得证据。混合公式的 Office 文档级默认值仍由 DOCX 明确报告冲突，不能把原生 XML 保真视为局部视觉等价。主 PDF 示例标题的装饰 emoji 仍因既有字形警告未呈现，不能认证完整字体支持。正文完整字号范围与其他出版参数属于 P04 等后续项。
