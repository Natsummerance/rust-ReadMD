# B3-52：真实大包卸载、取消与恢复

本增量完成受管理卸载的进度、取消、提交边界及 Windows 原生界面链路；第三批仍在实施中。没有替换用户已安装软件，没有发布版本，TeX 包仍为不可再分发的 QA 输入。

## 实际行为

插件面板确认卸载后在原有行内显示进度及取消。提交前取消恢复已移动的文件；提交后关闭取消入口并拒绝晚到请求。失败恢复不能被取消标志掩盖。已提交但清理未完成会明确提示待清理，保留可恢复事务。重复卸载加入同一任务；安装不能误加入卸载任务。

目录句柄复用减少重复打开，同时每次查找仍检查可变的路径重定向属性及最终父目录。Windows 实际读句柄拒绝目录重命名，允许正常子文件移动所必需的写共享；原位修改为 junction 的原生测试验证拒绝继续访问。没有把路径缓存当作不可变身份。
