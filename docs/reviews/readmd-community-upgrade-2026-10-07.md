## 社区研究

[研究矩阵](readmd-community-research-2026-10-07.md)对照 32 个项目，其中 28 个阅读器、编辑器或相关产品工具，4 个编辑/解析组件。仅使用官方仓库和文档；没有逐个安装所有社区软件，也不声称穷尽全网。采用分组工具箱、按需操作、当前草稿预览、原生撤销、离线资产和明确错误反馈，没有复制不兼容许可证的产品源码。

| AI/桌宠及原有面板 | 复验模型发现、独立原生运行时、精灵图/Live2D/BongoCat、原有面板与文件工作流；本轮不额外堆叠顶栏入口。 |

| 工具箱 | 按用途分组折叠，标题栏仅保留主要预览入口；命令、错误、状态及设置具备中英文文案。 |
| 实时预览 | 每文件复用面板，防止重复创建；双向滚动有回环保护，草稿改动自动刷新。 |
| 离线渲染 | marked、KaTeX/字体、Mermaid、Reveal、工程图表全部随 VSIX；无 CDN 请求。严格 CSP，清除文档脚本/事件，远程追踪图片只显示替代文本。 |
| 本地图片与链接 | 解析实际图片元素，支持引用式和含空格路径，代码示例保持原文；读取受 Webview 资源目录限制。本地文档链接交给编辑器打开。 |
| 工程图表 | WaveDrom、Bitfield、Graphviz、Vega/Vega-Lite、Chart、TikZ 在一次性隔离 iframe 渲染；图表外部数据 URL 禁用。PlantUML 需要本地依赖；WSD/D2/Ditaa 为原生基础语法渲染。失败保留源码和提示。 |
| 演讲 | 元数据不误作首张幻灯片；随包主题及转场生效，字体使用本地资产/系统回退。插入模板不再包含未支持的任意文档 CSS。 |

| AI 与模型 | 使用桌面已保存的安全凭据引用；支持获取/刷新模型，心跳不混入正文；选区仅发选区，全文操作发全文。 |
| 应用 AI/修复结果 | 最终响应为正文依据；等待期间文档发生变化则阻止直接替换，可另开结果；原生编辑事务可撤销，不自动保存。 |
| 代码执行 | 工作区信任及逐次确认，取消不执行；正确识别长围栏和波浪号围栏；结果面板展示输出、错误和生成图片。依赖本机运行时，不宣称安全沙箱。 |
| 导出 | 预设从内核实际读取，移除不存在的选项；PDF/Word/HTML/EPUB 及演讲使用源目录解析图片；保存框确认替换后正确传覆盖标志。演讲单文件取消外部字体请求，按需内嵌 Mermaid，真实文件在断网浏览器验证图片、公式和图表。其他工程引擎的增强预览不等于演讲导出全引擎支持。 |
| 转换 | 资源管理器入口及“所有文件”选择器不限制内核已有格式；结果为未保存的新文档，保留源文件。 |
| MCP 配置写入 | JSONC 保留其他服务和注释；严格校验根对象、重复冲突、脏缓冲和并发修改，原子写入，不堆积 `.bak`。多根工作区需选择目标。 |
| 模板与资源 | 图表/引用用 SnippetString API 转义 `$` 和括号；离线 VSIX 排除源码、测试、依赖和 source maps，保留字体及许可证。 |

## Rust MCP：22 个工具

完整清单与参数以 `tools/list` 为准，见[MCP 说明](../../packages/mcp-server/README.md)。

| 协议/能力 | 完成与边界 |
| --- | --- |
| 当前与旧协议 | 支持 2026-07-28 逐请求元数据及 `server/discover`；保留 2025-11-25 等旧初始化握手。不支持版本明确返回 `-32022`。 |
| 结果与发现 | 对象结果提供 `structuredContent` 及兼容文本，工具标注只读/副作用；当前响应包含结果类型和服务器信息，用户资源不共享缓存。 |
| 参数 | 校验类型、必填、枚举、未知字段及目录深度，不静默转换错误参数。 |
| 新增工具 | 保存连接的模型获取、真实导出预设目录、本地工程图表；未知预设明确失败。 |
| 运行容量 | 最多 8 个在途工具；超载返回忙碌，重复请求 ID 拒绝，线程创建失败释放计数。32 MiB 输入超限后排空整行并恢复。 |
| 进度与取消 | 有 progressToken 的耗时操作每 10 秒发活动状态；取消后忽略迟到结果，单文件导出提交前再次检查。正在运行的同步网络/渲染可能继续，不能撤销远程费用或已经提交的文件。 |
| 导出写入 | PDF/Word/HTML 先临时渲染，再原子发布；EPUB/演讲同样原子写入。禁止覆盖在最终发布仍生效。TeX 有关联图片目录，其写入以开始提交为边界。 |
| 隐私 | 不输出密钥、授权头、Cookie；目录中的连接 URL 去除用户凭据、查询和 fragment。不会修改实际保存的连接设置。 |
| 可选能力 | 不宣称实现 Tasks、Apps、订阅或 HTTP/SSE 传输，使用本地 stdio。 |
