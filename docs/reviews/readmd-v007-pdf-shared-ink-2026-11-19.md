# V0.0.7：共享绘画单笔到原生 PDF Ink 注释

本轮交付 R052/R067 的受约束子流程：导入 ReadMD 自有 SVG，经共享 `ink::Drawing::open` 验证画面与编辑模型一致，并由 `ink::pdf_stroke` 复用 `Stroke::radius` 提取一条恒定压力笔画。在 PDF 编辑工作区点击定位后，添加原生 Ink 注释；原页不截图、不重建，不生成旁路图片文件。

只支持一个非空可见图层中的一条恒压、等宽、不透明且无蒙版的笔画。隐藏或零不透明度图层不绘入 PDF；多笔、变压、蒙版、透明图层、被 SVG 画布裁切的边缘笔迹、超过 4096 点和非统一比例/剪切变换明确拒绝。它不是完整共享压感/倾斜画笔，也不把 SVG 的图层/擦除语义假装成普通 PDF Ink。

宿主在预备导入和提交编辑时分别调用共享模型验证，并覆盖浏览器提供的几何数据。PDFium 的页坐标基向量处理 0/90/180/270 度旋转；对整数栅格宽高造成的像素比例差先归一化，保持真实 PDF 等宽。新增操作复用修订号、撤销/重做、已有注释权限、签名许可、持久草稿及保存前源文件冲突保护。自有 SVG 连同操作保留在恢复日志，保存后的注释另保留 `ReadMDInk` 源数据；完整 SVG 再编辑界面不在本次子流程内。

直接原生试验发现默认 InkList 外观为平头/尖角，与共享画笔不一致。最终实现保留原生 InkList，并以 PDFium 原生描边路径的圆头/圆角生成同一注释的向量外观；没有新增 SVG 解析器或手写压力轮廓。自有 Ink 注释可明确删除，普通外来注释不会因此获得删除权限。

[结构化结果](readmd-v007-pdf-shared-ink-2026-11-19.json)记录了当前工作进程、源文件及开发库摘要。测试只读取维护者明确指定的外部 PDFium 库，不启动或修改其所属应用，不安装、分发或登记该库，也不更改正式能力目录。它证明此开发库与当前绑定的有限 ABI 路径可运行，不证明正式 PDFium 能力包或其他平台验收。

最终直接 ABI 试验 8 项通过：四种页面旋转的笔画均可见且只改变注释边界内像素；原页面对象保持一致、第二页像素完全相同；原生保存重开保留 Ink 和自有 SVG 元数据；明确删除后恢复原页像素；合成签名字典在未明确许可时拒绝操作。合成签名门不代表有效数字签名或加密权限矩阵验收。原 PDF 和借用的库在试验前后字节不变，最终圆头/圆角 PNG 已人工查看。

首次旋转失败记录保留：像素取整造成两坐标基长度差异，被统一比例保护拒绝。第二次试验虽通过操作检查，但人工发现平头外观，不能计作保真。第三次为最终结果。原始大 JSON/BMP 采用逐文件有界 gzip 保存，解压后逐字节核对；只删除已证明与保留文件完全相同的自有 PDF/PNG 副本，记录见本地证据目录的 `evidence-storage.json`。

定向检查另有 PDF 工作区/草稿与坐标 5 项、worker 坐标 2 项、前端及此前打包回归共 89 项通过；46 语言键集与 JavaScript 语法通过。新增导入/放置/笔迹词条已追加至全部语言。现有持久恢复测试核对共享 SVG 和实际操作完整回读、无新增位图资产；本轮没有宣称真实 GUI 重启、现场触控笔、完整恢复故障矩阵或 R052/R067 整项完成。
