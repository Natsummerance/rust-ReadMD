# 第三批：便携 TeX 与 Windows 工作进程隔离

本增量为 V0.0.5 开发工作，第三批尚未完成。新增的是可指定管理运行库的真实编译入口及 Windows 隔离基础。TeX 尚未进入可安装目录，正式导出仍使用旧系统引擎路径；主程序未发布、未覆盖用户安装。既有 PDFium、Typst、OCR、字体包的功能内安装链路保持可用。

## 已实现的边界

`compile_portable` 只使用明确传入的运行库，不搜索系统 TeX、字体或用户宏包，不继承用户 PATH、代理和 TeX 配置。两个引擎均在 AppContainer 内运行，没有网络能力；运行库只读，仅各自任务目录可写。工作进程只继承明确列出的输出及空输入句柄，Job 限制进程数、内存，并负责取消时停止整个进程树。

XeLaTeX 先输出 XDV，由 Rust 显式启动同样受限的 PDF 驱动；不借系统命令壳启动驱动。版本检查、重复编译、交叉引用收敛和最终 PDF 校验共用时间、日志及输出上限。日志中的缺字视为错误，不能静默输出缺少文字的文件。错误行号指向生成的 TeX，不冒充 Markdown 行号。

Windows 旧 kpathsea 会枚举执行路径的所有上级目录。为兼容它，每个任务创建仅指向管理运行库及任务根的唯一非盘符设备视图，最后一个持有者释放后撤销。它不扩张私人上级目录的权限；TeX 资源读写仍使用普通路径，避免旧库把设备路径转换成错误的 `//./` 路径。

运行库的公共只读 ACL 检查具有幂等性，避免每次任务遍历两万多个文件。并发名额在隔离准备之前取得；第三个请求立即返回繁忙，不创建任务文件或隔离配置。取消和超时在准备前检查，截止时间包含准备阶段。其他平台尚无对应原生隔离实现，便携入口明确失败，不回退到无限制执行。

## 输入与可复用维护工具

固定输入是 [TinyTeX v2026.10 官方归档](https://github.com/rstudio/tinytex-releases/releases/tag/v2026.10)：247,389,422 字节；展开 21,454 文件、536,953,774 字节。锁文件固定版本、长度与 SHA-256。准备工具默认只离线核对，显式 `--download` 才获取输入；解包工具检查归档、路径、压缩预算、CRC、逐文件摘要和已有目录，不执行包脚本。

这只是维护输入，不能作为已审查的产品包分发。上游有 322 条数据库记录，其中 320 个组件、2 条安装配置；目前尚未完成许可证与对应源码审查，也没有完整中文出版宏包。上游字体配置带有构建机路径，因此编译器生成私有字体配置，不能原样信任该配置。应用运行和普通离线构建不依赖 Node 维护工具。

现有 JSON 能力包适合已交付的小包，但文件数、清单及内存上限不能容纳完整 TeX。下一工作包须完成有界流式大包、许可证及源码材料、中文宏包及私有字体，再接入功能内安装、修复、卸载和安装器预选；未准备完的包不会伪装为可下载。

## 原生证据及回归

固定源码、探测程序摘要、真实报告、PDF 样张和失败分类统一记录于[证据索引](../evidence/capability-upgrade/2026-10-10/batch3-tex-sandbox-manifest.json)。使用合成材料和独立任务目录，没有读取私人文档或替换已安装软件。

- 通用隔离探测实际检查 AppContainer 身份、授权目录读取、目录外拒绝、运行库写入拒绝、本地网络拒绝、中文空格及引号参数、子进程树停止与设备视图撤销。
- TeX 探测真实调用 XeLaTeX、pdfLaTeX，检查可搜索 PDF、交叉引用、生成源码错误行、目录外读取拒绝、缺字报错、预先取消／零超时、运行中取消，以及两个并发工作进程与第三个繁忙请求。
- 样张由独立 Poppler 栅格化并视觉检查：文字、公式、编号及页脚清楚，无重叠或裁切。它是简单文章测试，不能代表完整中文论文、全部模板、所有字体或宣传素材验收。
- 完整内核结果与忽略项分别归档；既有忽略不计入通过。本增量未改前端，无前端重打包或新界面通过声明。

## 失败原因与限制

早期失败暴露了设备路径、上级目录枚举、驱动自动启动以及反复 ACL 传播的问题。分别通过短执行视图、普通资源路径、显式驱动和幂等授权修复；保留尝试分类及日志摘要，不把最后一次通过当作从未失败。

尤其不能把 `openin_any=p` 当作新 TeX 的读取沙箱：固定 TeX Live 2026 输入的 `texmf.cnf` 已注明它不再限制读取。新的入口采用真实 OS 边界，并用外部文件读取失败验证；旧正式入口尚未取得同样保护。依据包括 [Microsoft AppContainer 隔离](https://learn.microsoft.com/en-us/windows/win32/secauthz/appcontainer-isolation)、[AppContainer 实现](https://learn.microsoft.com/en-us/windows/win32/secauthz/implementing-an-appcontainer)及 [kpathsea 上游路径处理](https://github.com/TeX-Live/texlive-source/blob/trunk/texk/kpathsea/win32lib.c)。

仍待完成：TeX 中文和完整模板、组件分发审查、大包事务安装及正式功能接线；Word/WPS/LibreOffice 互操作；其他平台原生沙箱与运行证据；完整参数及 OMML、长期压力和故障矩阵。Windows 原生通过不能代替 macOS、Linux 或国产 Linux 验收。

缓存按固定输入、展开运行库、测试二进制、隔离工作区及日志分类列入证据。测试结束后仅确认自有进程退出，未绕过此前拒绝的批量缓存删除。这里的样张和 QA 记录不进入视频／社交制作资产。
