# B3-55 / B3-57：小分式显示语义与嵌套样式

第三批继续实施，本增量只认证小分式和所列关联流程，不关闭全 OMML、完整出版或原有 B3-51–57 门槛。

## 实现

文档 `mathPr.smallFrac` 进入共享渲染视图。缺省关闭，元素无值时开启，显式关闭保留。块公式开启时仅缩小分子、分母；分数线和斜线保持自身尺寸，行内公式不重复缩小。覆盖四种现有分式结构，并保留参数字号叠加的既有路径；不是整幅公式缩放。

MathML 发射管线传递实际显示上下文，分式、上下标、根指数、上下限及表格中的子表达式使用对应样式。同步修复省略局部位置的大型算子在行内和嵌套位置仍按块样式选择结构的问题；已有测试改为同时检查两种实际样式，另增嵌套测试。明确的全局及局部上下限仍优先，不改原始无损数学树。

语义依据：[Microsoft SmallFraction](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.math.smallfraction?view=openxml-3.0.1)。普通编辑仍在渲染槽位中完成；本增量没有增加常驻 UI 或可见文案。
