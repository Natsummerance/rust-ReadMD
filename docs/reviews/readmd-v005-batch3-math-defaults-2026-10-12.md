## 实现与边界

Word 导入按实际 settings 关系读取文档级 `mathPr`，支持非默认包路径、绝对包路径及命名空间别名。外部关系不授予文件或网络访问；声明了本地设置部件但部件缺失时明确失败，避免默默丢弃默认属性。预览转换不修改输入、不创建 MD 或资源目录。

可读 DSL 支持默认设置和公式组成的顶层片段，例如 `row(office.mathPr(office.naryLim(val: subSup)), office.oMath(sum(x, from: 0, to: 1)))`。它在内部保存为平级数学部件，不把 `mathPr` 错塞进公式正文。重复默认容器和非法嵌套仍被固定 schema 拒绝。往返保留标准语义、命名空间及 UTF-16 源映射，属性修改保留外围源码和注释；保存迁移复用已有事务，不提前写盘。

渲染视图继承明确的 `intLim`／`naryLim`，局部 `limLoc` 优先。原始数学树不被显示决策改写。MathML 和 Rust 矢量排版共用判断；明确位置关闭可移动上下限。未声明的设置继续使用现有行内／块级回退，缺省组合及实际 Word 等价性仍纳入完整数学验收。

DOCX 将文档设置放入 `word/settings.xml`，段落只放公式内容。不同来源公式合并时，导出副本补齐每个算子的实际位置，避免一份全局设置改变其他公式；原正文和恢复依据保持独立。无法逐公式表达的其他全局设置存在冲突时，采用首个声明并返回结构化警告，不能将此类冲突计为无损支持。

旧 LaTeX 加保真元数据的公式也采用 Rust 矢量预览，保留 MathJax 条目身份以定位真实源范围。缓存包含实际字体点数及行内／块级样式，迟到结果和过期元数据不覆盖新正文。检查还发现混合格式匹配缺陷：前置 DSL 与旧公式同文字时，会消耗旧公式的候选位置。元数据阅读、就地编辑和公式面板均排除 DSL 候选，保留各自定位路径。

规范依据：[Microsoft limLoc](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.math.limitlocation?view=openxml-3.0.1)、[积分默认位置](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.math.integrallimitlocation?view=openxml-3.0.1)及[其他大型算子默认位置](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.math.narylimitlocation?view=openxml-3.0.1)。本次只认证下列实测范围，不用规范 XML 或内核一致性替代 Word 应用认证。
