## 关键故障与首次失败

- 编辑器失败时，同一虚拟占位的目标高度为 2270.9px，瞬时 DOM 高度却为 17390.535px；15119.635px 的差值与错误滚动坐标吻合。单因素 CSS 干预和最终候选均通过，原失败保留在 `editor-ux/probe12gap-krPzKO`、`final11-lHRG9A`。
- 前一检查器使用 Playwright 截图时改变了原生视口 DPR，另有把外围容器宽度当正文宽度、用伪分页类验证页面的问题。修正检查器后使用直接 CDP 截图并核对前后视口、DPR 和 PNG 像素；分页改用真实引擎产物。没有把这些检查器误报归为产品缺陷。
- 首次真实 MCP 发现 PDF 阶段文件绕过统一归属登记。原失败 `mcp/stdio-WwGxqm`、旧 PDF 和 journal 保留；修复后只回收本轮登记的文件，旧未知文件保持逐字节不变。
- 后续重启检查曾错误要求两次 DOCX 导入的内部公式 UUID 完全相同。产品原有合同是每次导入分配新身份；检查器现在只允许合法、唯一的新 UUID 字段不同，仍严格比较可见 Markdown、源码摘要、完整 OMML XML 和其他所有载荷。9 项检查器自测包含损坏 XML／摘要等负例。首次失败 `mcp/stdio-Durl0e` 和解码对照全部保留。
- 历史 candidate-08、后续 candidate-09～11 证据均未回写。旧候选通过数字没有冒充最终候选结果。
