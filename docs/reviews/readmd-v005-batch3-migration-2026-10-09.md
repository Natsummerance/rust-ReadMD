## 行为与实现

标准旧公式打开时保持原文件，明确保存时编译为可读 DSL。迁移先重新编译并比较 XML 语义，不能表达的属性保留原稿并给出诊断。压缩属性按钮直接打开对应公式的渲染编辑器，不向用户展开机器状态。

外部改过的公式以新正文为准；脱离旧属性前，先将旧公式存入集中保护恢复记录。重复属性按原文修订及公式范围分别登记；重复保存保持幂等，普通历史清理不能删除这些恢复依据。保存后可以从现有历史面板打开可读恢复副本，不自动覆盖正文。

修复实际 Windows 测试发现的 CRLF 问题：磁盘保存回执使用原始 UTF-16 坐标，而 CodeMirror 使用 LF。现在验证整份回执并映射坐标、归一插入换行，再提交编辑器事务。迁移与图片资源保存共用此处理。保存期间的新输入保持未保存状态，不被迟到回执覆盖。

无写盘保存同样返回正确正文与修改回执，并先确保必要恢复记录存在。撤销迁移再保存，不再出现磁盘已是 DSL 而编辑器仍停留在旧格式的分歧。引用、列表内的公式保留容器范围；代码示例、HTML、链接目标与元数据不误编译。
