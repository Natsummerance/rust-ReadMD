## 用户可用的闭环

打开文档并进入编辑 → 让 AI 修改正文 → 在正文块上同意或撤回 → Ctrl+S → 重开后继续审阅。保存当前可见文字，保存本身不等于同意。已同意块仍能撤回；撤回本身支持撤销与重做。普通 Markdown 文件只保存正文，恢复与审阅依据集中存放，不生成旁边副本。

## 检查中修复的实际问题

- 保存的系统改写使用既有事务允许的来源，并组合精确编辑；分离的两处图片路径改写不吞掉中间待审块。ASCII 内容按确认编码提交，避免已成功写出的 GB18030 被自动探测成 UTF-8 后误报失败。
- 4096 被误用为终身事件上限，可能永久阻止后续保存和撤回。已改为安全单调计数；4096 仍是单次编辑与审阅块数量的限定。边界测试覆盖跨限后的保存、撤回、撤销、放弃及旧回执重放。
- 通用草稿可能比 SQLite 新，也可能更旧。新增因果水位；同水位的新输入通过 CAS 补交，未知或旧水位先留集中恢复点，再选择已持久正文。保留失败时不覆盖可见输入、不清理草稿，允许重试。
- 普通阅读的刷新／切页／关闭刷新不再创建无用审阅会话；进入编辑或明确操作时按需初始化。
- 原生 AI 审阅不能忽略用户选择的模板。现在服务端冻结已启用模板及摘要，验证真实选区，以原生读取结果提供源内容；模板变化不能借旧回执重放，调用参数不能覆写凭据、地址或系统权限。
- 手工接管块提供明确的“保留我的修改”，不再仅停在无法结束的冲突提示。已接管内容不会被旧候选直接覆盖。

初次全量 Rust 验证中的跨目录原图保护分支返回422而预期409，已修正；另一次完整回归发现新增 Anthropic 测试材料缺少 `role: assistant`，仅修正材料后重新完成整库回归，严格协议解析未放宽。两次首次失败日志均保留。初次 Node 回归的两条旧文件摘要保护随明确授权的编辑／保存集成更新，原设置、样式及 toolbar 的保护基线未回退。CSP 等待与 Shift+Z 的脚本问题独立记录，正式 CSP 未放宽，未通过重试掩盖产品失败。

## 当前明确边界

- 本批审阅正文上限4 MiB，单请求至多4096处局部修改，单文档至多4096个保留审阅块，逻辑存储预算64 MiB。普通输入无4096次终身限制；存储真正耗尽时拒绝相关操作，保留内容和恢复依据。
- 普通文本的选区与审阅已经接通；数学、代码、复杂表格、跨块变形投影不伪装成精确结构编辑，继续使用既有安全流程。
- 待审原文中隐藏的相对图片引用尚未实现跨目录搬迁；这类另存在文件／资源提交前以本地化冲突拒绝。原图、旧目标和审阅记录均保留；同目录保存、普通文字另存和既有可见资源物化仍可用。
- OpenAI 兼容、Anthropic、Gemini 的工具协议均有契约测试；本机真实服务成功证据只代表实际使用的连接，不代表逐个公网服务商认证。
- 等待取消与提交取消已验证；底层最多两条同步网络线程按90秒超时收敛，不声称所有线程两秒内终止。
- 本批增加43个词条并同步46种语言，共2880个键通过结构检查；全语言人工语义、RTL、读屏及高 DPI 仍留统一验收。
- 未启动原生 Wry 窗口、Office 或其他 GUI；headless 实测不能冒充 Wry、macOS、Linux、实际磁盘满或八小时认证。既有三项 Rust 忽略不计通过。
