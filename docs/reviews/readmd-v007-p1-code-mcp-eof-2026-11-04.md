# V7-05 MCP EOF 限定验收

2026-11-04，源码 `7b9d6fa7cc0d1ec60f5442ce3786c9c3b40d68fd`，版本仍为 V0.0.6 开发候选，不发布 V0.0.7。

真实首败为关闭 stdio 输入后，长 SQL 继续运行约 9.9 秒。修复先给即将完成的请求至多 50 ms 排空，再关闭本进程代码执行准入并取消已拥有的代码任务；从 EOF 起总停止预算 2 秒，不能确认停止时返回失败，不伪装正常退出。其他可能提交持久结果的工具保留原有安全排空策略。

[精确候选 CI](https://github.com/Natsummerance/rust-ReadMD/actions/runs/41721389885) 的 8 个任务全部通过，14 份相关产物摘要已独立核对。三平台各使用真实 SQL 和实际 Node 子进程，观察 EOF、宿主退出、子进程停止及临时脚本清除；没有强制清理代替成功。
