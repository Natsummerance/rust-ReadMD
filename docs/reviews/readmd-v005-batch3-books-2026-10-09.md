# 第三批增量：书籍、学术与通用预设

2026-10-09。纳入用户追加要求，第三批整体继续实施；本记录不代替全 Office 属性、实际 Word 往返或完整平台认证。

## 真实行为

同一份目录提供五类书籍、五类学术及三类通用预设。书籍包括小说、非虚构、教材、图文作品和技术手册；通用及书籍复用于 PDF、DOCX、EPUB、HTML。学术预设按格式显示。完整列表分组，默认只显示少量推荐和当前选择，没有增加常驻面板。

所有预设都传递实际排版参数；选中后仍可调整并保存为自定义。格式切换保持修改，不适用的预设保留参数并显示为自定义。旧自定义预设若恰好与新增内置 ID 重名，优先保留旧配置。学术预设是可编辑的起点，不宣称期刊或学校认证；双栏与完整出版参数仍待实施。

EPUB 从文档元数据读取书名、作者、语言、出版方等，支持自包含 SVG/位图封面和自动 2400×3200 矢量封面。真实 EPUB 样式使用共享字体、段距、缩进、标题、表格、代码和配色参数，阅读字号与行距单独设置。预览直接使用打包章节与资源，不创建旁文件；目录、跨章链接、重复脚注和所有返回入口可点击。

修复“整本不拆分”选项仍按一级标题拆分的问题、原生预览锚点跳到宿主页而触发 CSP 拒绝的问题，以及中文 PDF 字体回退触发文字提取器崩溃的问题。PDF 保持实际字体渲染编码，同时补充 ToUnicode 映射，文字投影失败不破坏预览。封面不可读取时保留已有导出，来源文件与资源保持不变。

视觉复查补充：电子书预览隐藏无效翻页按钮，去掉重复格式说明；真实分页 PDF 仍保留翻页。标题对齐选项复用现有多语言词条，使用 DOM 创建选项；封面与书名标签去掉过时的“留空使用文件名”说明。预览为可重排电子书，不称为 Word 真实分页。

用户追加的顶栏要求一并落实：ReadMD／文件名紧邻 LOGO，标题区按窗口宽度限定在最大 240 CSS px，长标题尾部省略并通过悬停显示全名。标题长度不会推动操作图标；空白区域保留拖动，标题双击仍可最大化和还原，按钮不触发拖动。LOGO 返回主页后恢复 ReadMD 标题。

## 验证范围

完整 Rust 内核离线锁定回归 2010 通过、0 失败、3 项既有忽略。真实输出专项逐项检查 13 套 Word/PDF 参数和通用、书籍 EPUB 样式；CJK 字体回退测试不依赖本机是否安装字体。HTML 使用实际导出文件检查修改后的参数。

正式 CSP、真实 Rust 服务的公式、迁移、恢复、资源保存、出版、新预设及顶栏回归为 88 项；最终旧预设兼容、当前语言和顶栏专项为 13 项，均无失败、跳过或重试。报告记录最终结果，失败与中断单列，不将自动重试视为通过。旧预设测试修正异步文档渲染的操作顺序，PDF 翻页检查等待真实引擎结果；数据和可见性断言没有放宽。

Windows 原生验证共五条检查，使用专用哲学阅读手册、CSL 文献、重复及循环作者脚注、公式、代码、表格和插图；包含真实窗口双击最大化/还原和标题布局。五种书籍预设通过实际面板选择、实际导出。官方 EPUBCheck 5.4.0 的 40 个运行库文件锁定摘要，离线独立验证八份 EPUB；零致命错误、错误和警告。没有安装到用户主配置，没有使用私人文档。

新增预设词条在现有 46 种语言中有独立译文，并检查实际语言文件与 UI。1024×680、1160×820 使用长德语名称检查完整显示、无横向溢出；Arabic 对齐选项检查实际翻译。该检查不等于 46 种语言的人工语义与完整布局认证。

## 剩余与缓存

实际 Word 打开、刷新字段及数学往返仍未验收；独立电子书阅读器未安装，因此 EPUBCheck 与 ReadMD 自身预览不能代替独立阅读器实测。完整出版元数据、全部版式及局部覆盖、PDF 真正分页脚注、Typst 与 LaTeX 模板/沙箱继续属于第三批。
