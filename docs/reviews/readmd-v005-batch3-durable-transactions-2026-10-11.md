# 第三批：能力包持久化事务与恢复

本记录接续清理后的重新构建，属于 B3-52 的限定增量。版本未发布，用户安装未替换。构建使用同一 `.cache/community-upgrade/build`，锁定离线依赖并关闭增量编译。

## 已实现的恢复规则

卸载在移动任何原文件前落盘准备记录；全部移动完成后落盘提交记录。准备阶段中断，下一次状态检查或实际资源访问恢复原文件；提交后中断则继续清理，不把已经卸载的资源恢复为已安装。遇到用户新建的同名文件时保留双方及记录。

安装替换也先写入记录：旧目录移开而候选尚未就位时恢复旧目录；候选已就位但提交记录未写完时，完整验证候选后再提交。原来就损坏的旧安装恢复后仍报告不可用，不以“恢复完成”冒充引擎就绪。

清理与资源可用性分开。旧备份或已提交的清理暂时受阻时，保留恢复依据并返回 `cleanup_pending`，不阻止有效的新资源和其他读取者。旧备份已有子卸载记录时，不重复清理同一目录；未解决的冲突原件继续受保护。取消及期限错误保持原错误，不能被降级成普通清理提示。

所有记录校验能力清单摘要、版本、唯一身份和受限相对路径。恢复与安装共用进程内互斥和能力级 OS 锁；不跟随已识别的重解析路径，不按名称前缀递归删除目录，未知额外文件保留。Windows 移动不启用覆盖目标或跨卷复制回退；API 依据为 [Microsoft MoveFileExW](https://learn.microsoft.com/en-us/windows/win32/api/winbase/nf-winbase-movefileexw)。这不构成对断电或任意恶意路径竞争的认证。

## TeX 输入与实测边界

基础归档恢复并离线组合完成：34,822 文件、736,565,687 字节。533 份锁定容器已有 529 份校验到位，剩余 `pdfmanagement` 和 `tagpdf` 的 source/doc 四容器仍不可得。二进制对应源码、四条历史材料记录、逐组件许可和正式包仍未完成；所有 QA 记录保持 `redistributionApproved=false`，正式应用目录不变。

首次 TeX 进程实测的就绪检查失败。测试直接硬链接运行树，目标根目录虽有隔离读取权限，引擎文件没有继承对应权限；这条失败不能计入引擎通过。实测工具改用实际流式离线安装 API 后，真实安装、就绪和两个引擎进程启动通过，但第三请求忙碌拒绝超过 200ms；该失败同样保留，不能被后续成功抹去。

定位到忙碌检查前解析约 35,000 文件的清单。TeX、Typst、OCR 现先只读探测既有固定 OS 名额，容量满时提前拒绝；不会为探测创建配置、任务或锁。它仅用于提前拒绝，不代替资源保护下的正式名额占用，竞争时仍由正式占用决定。取消和到期先于忙碌错误返回，显式配置根别名保持兼容，配置内重定向继续拒绝。完整库及上述实际 TeX 矩阵分别验证；实际 Typst/OCR 工作流通过不等于它们的完整拥有者崩溃矩阵也已通过。

输入恢复及失败记录见[事务归档目录](../evidence/capability-upgrade/2026-10-11/batch3-transaction-resume/tex-inputs-remaining.json)。QA 安装及就绪会预热运行树，后续成功不计作冷态认证；历史冷态全树校验 139,449ms 超过 120 秒的缺口继续保留。

按 [TUG 的固定日期归档说明](https://tug.org/texlive/pkginstall.html)补查原镜像、2026-10-10 归档和 TinyTeX 镜像，四份缺失材料仍为长度不匹配或 404；没有用新版本材料替换锁定摘要。输入仍为 529／533，正式分发仍不批准。一次维护脚本的模块模式错误在联网前失败，修正后的真实查询结果及错误日志分别归档。

## 仍需接续

本次不是 B3-52 或第三批整体完成。仍有：Typst/OCR 真实完整并发／崩溃矩阵和桌面/MCP 传输；跨进程上传总预算；旧客户端隔离及版本迁移；提交记录产生前的崩溃暂存；AppContainer 配置和映射生命周期；磁盘满及全部大包故障；独立冷态性能与长期压力。当前大运行库的实际安装、完整验证和逐文件事务卸载耗时较长，不能因正确性通过宣称安装性能已达标。

Unix 保留既有移动实现，原子拒绝覆盖的目录移动及恶意竞争仍需平台适配和原生证据。仅 Windows 有本机环境，其他平台不能由此次编译或 Windows 测试推定通过。完整 OMML、出版参数、Word 往返及独立 EPUB 阅读器继续按第三批账本验收。

本次不自动删除可能含恢复原件的目录，也不绕过此前对四个已完成 QA 配置删除的自动审批拒绝。当前运行树与证据按用途集中保存，最终清理须在取证和引用核对后执行。
