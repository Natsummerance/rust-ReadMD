# ReadMD V0.0.7 发布候选 · Mac 本机验证

2026-11-19，macOS 27.2（26B123），Apple Silicon ARM64。测试文档、偏好和草稿均放在独立目录。桌面回归使用 LaunchServices、Cocoa 和 WKWebView；普通分发包另从归档解压，用中文版测试文档冷启动和重开。

## 用户工作流

| 场景 | 核对内容 |
| --- | --- |
| 关闭与还原 | 同时打开四个中文文件，混合关闭干净标签、取消、丢弃和保存，逐个核对原件的 BOM、CRLF 和正文。空会话重启回主页。 |
| 保存冲突 | 保存当前编辑、关闭后重开。文件被外部修改时原件保留。平台无法安全提交的跨文件改名保留原文件和引用。 |
| 草稿恢复 | 先恢复不可读取文件的标签，再恢复可用原件。缺少草稿时阻止空正文覆盖文件，重开可继续处理真实恢复记录。 |
| 菜单与导出 | 从 Cocoa 菜单操作插件和转换；在显式指定的工作区输出测试 PDF、DOCX、EPUB、HTML、TeX 和 PPTX。提供校验过的离线字体包，核对中文和图片输出。本轮六格式检查使用显式测试路径。 |
| 语言 | 46 份字典的 3092 个键和占位符完成检查；实际切换语言，检查恢复按钮和编码弹窗。46 次取消都保留磁盘原字节和未保存正文，确认转 UTF-8 后字节符合预期。[多语言结果及待审项](v007-rc-i18n-2026-11-19.md) |

## 版本与回归

- **四页末页关闭的首败**。前一次关闭已收到 Rust 的持久化回执，下一页的关闭按钮也已经可点击，但前端仍在等待相邻页渲染结束。此时再次关闭会被前一个操作拦下。仅提前刷新标签栏时，普通模式曾连续通过两轮，随后又失败。通过延迟真实邻页渲染的完成回调，可以稳定重现。修复把回执后的点击绑定到被点击的页对象，等待上一轮完成再关闭，并对重复请求去重。保存确认期间沿用原有保护。关闭按钮、命令和标签右键菜单分别通过受控时序回归，另连续运行三轮常规流程，共 24 个原生进程阶段。[关闭验收记录](v007-rc-tab-close-2026-11-19.md)
- 应用和包管理清单采用 `0.0.7`。官网以已发布的 `0.0.6` 元数据维护下载入口。候选构建、官网发布、GitHub Release 是独立操作。
- Rust 核心库串行回归通过 4447 项；代码运行另组通过 80 项。两组合计 14 项由原用例标为忽略，系统 OCR 实际推理另行验收。桌面命令行与原生测试入口通过 124 项。
- 首次全库运行有 9 项失败。固定资源路径指向当前源码，并让隔离的资料目录沿用应用目录名后，7 项通过。其余两项为 TXT 转换响应测试沿用旧键集合，现已核对新增的格式保真报告，并保留对空文档提示、生成正文和文件写入的验证。
- 前端、扩展预检及发布专项 605 项通过，另跑仓库前端质量组合 124 项通过。两组有重复用例。Office 测试响应补齐真实服务提供的原件修订头，并检查头缺失、格式错误、修订变化时拒绝旧页。数学源边界测试逐段核对新增代码，继续验证原先受保护的字节。
- 发行工具会在接触 Release 文件前核对标签和应用版本。Mac 测试包采用 ad hoc 签名，保留既有安装说明。正式发布前仍要同候选复核 Windows、Linux 和 Mac Intel 的分发差异；Windows、Linux 的离线转写包需各自完成安装与短音频输出。

同版本检查及官网已发布资产核对见[候选版本记录](readmd-v007-candidate-version-2026-11-19.md)。
