# V7-05 内置 SQL 的批量结果闭环

候选 `5cf7bd5135c02780f32c879c60f44d5f4b9bc6e5` 的 [8 个 CI 任务](https://github.com/Natsummerance/rust-ReadMD/actions/runs/41715318531)全部通过。11 份平台与浏览器产物逐个校验 GitHub 摘要，同一内核任务的执行器、批量结果和旧版本拒绝回执也核对了二进制摘要。[结构化记录](readmd-v007-p1-code-batch-2026-11-04.json)保留具体平台边界；V7-05、全部 P1/P2 与 V0.0.7 发布门槛继续开放。

## 改变的行为

“运行全部”从固定间隔点击全页卡片，改为 Rust 从同一修订准备根级可执行围栏，依次执行，全部成功后以一次持久正文事务写入。隐藏页面和生成输出内的围栏不作为输入，重复代码各自保留 UTF-16 范围与节点身份。运行中切页只更新原目标的持久草稿；手改后再撤销仍使旧任务失效。失败、取消或关闭标签不提交部分输出，成功结果与保存回执分开核对。

首个完整子切片使用内置内存 SQLite。每批最多 32 块，总代码 200000 字符、总输出 400000 字符、总执行 60 秒，每块仍有 10 秒上限，由后端检查。混入其他语言时整批在执行前明确拒绝，不以 PATH 可用冒充受管环境；原有单块语言入口保留。其他语言的受管运行资源及未知副作用检查点没有因此完成。

## 实际通过

| 平台 | 执行器与其余库通过 | 批量服务与文件 | 进程 |
| --- | --- | --- | --- |
| Windows | 4364 | 5 项 | 3 个真实 HTTP/MCP 进程 |
| macOS | 4291 | 5 项 | 3 个真实 HTTP/MCP 进程 |
| Linux | 4280 | 5 项 | 3 个真实 HTTP/MCP 进程 |

这些结果分别覆盖整批一次撤销/重做、BOM/CRLF 保存、新进程重开、独立待审原文、幂等回执、跨文档拒绝、先成功后失败也不提交部分结果、混合语言拒绝、生成代码排除，以及真实并发取消。各平台两个执行器 helper 单独运行，既有忽略与平台差异仍保留，没有改成全无忽略的口径。

实际 Linux 浏览器取得新增 5 项和原单块 7 项，使用正式 boot、CSP、真实鉴权与保存服务。新增流程验证菜单入口、物理历史键、隐藏阅读卡片、切页持久草稿、新内核恢复、改后撤销、取消及关闭。它仍是 headless，不能冒充 Cocoa 或 Windows 原生宿主。

本机通过 4183 项不启动模型的库测试、77 项执行器、1810 项前端（3 项平台跳过），以及相同的真实文件和浏览器检查。OCR 核心的无引擎/纯函数保护不构成 OCR 推理证据，实际识别与语音继续延后。保护文件的字节摘要未修改。

## 首败与剩余范围

前端首轮指出重打包 boot 后缓存 URL 仍指向旧摘要，已更新实际资源引用并重跑；没有改测试摘要。浏览器首轮把刻意保留 CRLF 的非活动标签误按 LF 比较，已按既有持久投影语义修正独立预期并复测。误选零项的命令没有计入验收，私有执行器现会拒绝零项选择。原始日志均保留。

Mac Cocoa 的五阶段脚本已准备，仍待实际桌面时段。后续另发现 MCP EOF 等待长代码超时，本机修复与跨平台跟进使用另一候选记账，不能把本记录挪给新源码。受管语言、Unix 宿主强杀、全部任务检查点及其余 P1/P2 尚未完成；没有更新日常应用或发布开发包。
