# 第三批：HTML 公式、复合上下标及深色出版输出

本轮补齐 B3-55／56 的限定增量，完整第三批继续开放。前一轮发现的 HTML 导出 DSL 原样显示已修复：行内、独立、引用及列表中的公式共用 Rust 数学模型和实际矢量字形；普通 LaTeX、代码示例及原始 HTML 的解析边界保持兼容。

## 实际变化

- 独立 HTML 内嵌公式路径，离线打开即可显示，不依赖编辑器脚本。静态输出保留数学语义名称，避免重复的编辑选择 ID；缺字明确提示并降级为 MathML。
- 复合上下标读取实际字体的 `SuperscriptBottomMaxWithSubscript`，按允许范围分配上推和下移，之后计算四角间距。单独上标／下标的位置保持原规则。256 组独立字体样本在两种字号、两种样式下比较 1,024 次实际布局，并检查分组和嵌套字形边界。
- HTML 小预览和最终文件使用同一 Rust 深色调色表，覆盖标题、表格、引文、代码、链接和分隔线。非默认自定义色保留；与默认值相同的颜色随深色主题调整。其他格式保持各自的配色规则。
- 数学语法和属性失败返回可本地化错误码；前端同时识别旧接口错误字段与预算错误，复用既有 46 语言公式提示。实际中文、英文切换验证语法、未知版本及超大公式失败，既有目标文件字节不变。
- 修复 Windows 工作进程停止过早报成功的问题：任务计数归零后还须确认根进程退出，两者共用原来的停止期限。严格恢复断言保留，并增加根进程已经终止的断言。

上下标依据 [OpenType MATH](https://learn.microsoft.com/en-us/typography/opentype/spec/math) 和 [MathML Core](https://www.w3.org/TR/mathml-core/#base-with-subscript-and-superscript)。FontTools 仅用于独立 QA 材料，产品没有新增 Python 或外部依赖。
