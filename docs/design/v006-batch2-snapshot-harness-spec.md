# V0.0.6 第二批：固定导出快照与多轮任务

基线：`76f64d37be2aa139761415999557fef14c08b5c6`，日期2026-10-27。对应 V6-21–27；复用第一批审阅服务。正式版本仍为 V0.0.5，本轮不发布、推送或制作宣传。通过状态以最终报告与真实产物为准。

## 导出操作与提交合同

刷新编辑队列 → 冻结当前正文、精确待审块版本、稀疏参数来源、资源字节及引擎／字体身份 → 如有待审修改，选择“全部同意并导出”／“查看修改”／取消 → 生成隔离产物 → 校验目标未发生外改 → 持久化提交意图 → 原子提交文件 → 核对产物摘要 → 仅同意快照对应且仍匹配的修改。

- 快照由 Rust 从已授权会话读取，不信任前端重复上传的“当前全文”。准备请求绑定 generation、review_revision、call_id；重复请求返回同一快照，变更参数不得借旧 ID 重放。
- 本地图片、引用式图片、书籍封面及文献依赖保存真实字节，禁止只固定摘要后继续读取原文件。缺失资源、越界路径、外部动态依赖在覆盖目标前拒绝。资源、正文及存储各有容量上限，未确认数据不自动淘汰。
- 来源中稀疏版式与内部归一化上下文一并冻结，不能把已补全参数重新解释为用户显式设置。引擎和字体身份改变时拒绝旧快照，要求重做准备。
- 缺少受管引擎或所需字体时，先固定正文与资源并标记运行资源待绑定；沿原有安装流程补齐后，仅绑定原先缺失的身份，绝不重新读正文或图片。已有引擎、核心字体及已安装资源不得借安装改版。DOCX含CJK时采用已冻结的PDF投影字体需求；预览仍保留缺能力卡片，由用户点击安装后继续。
- 需要浏览器渲染的图表在冻结后，从快照源码生成 SVG；后端核对图表身份、SVG安全性及配额，并一次性绑定。不能将后来页面的图混入旧快照。
- HTML、PDF、DOCX、EPUB共用文件提交。TeX及其必要图片采用独立多文件合同：先提交带摘要的不可变资源依赖，再原子提交引用它们的TeX；原目标直到最后一步保持不变，重启按日志核对整组产物。
- 输出锁、取消、资源缺失、渲染失败均不清除待审状态。产物成功后出现新修改C，不会将C顺便同意；原快照块D被改动、撤回或接管时不接受旧D。
- 文件已提交而审阅回执未完成时，保留提交意图，返回明确的待对账结果；重试仅核对已提交文件，不盲目覆盖目标。接受动作使用确定的幂等ID，崩溃后不能重复接受。
- 快照预览与最终导出使用相同冻结输入。Word预览继续准确标注实际投影引擎，不声称是Word原生排版。

## 原生多轮任务合同

Rust负责工具注册、模型轮次、输入输出约束、检查点、预算和取消；前端只呈现持久事件及服务确认的正文修改。桌面、MCP及扩展调用同一API。

- 本批工具限于已授权文档的读取、提出审阅修改、检查审阅及明确结束任务；模型参数不能授予文件、工作区、网络或导出权限。
- 每轮固定原文档，读取当前真实会话；每次修改检查修订和已授权范围。人工接管及冲突保留双方内容，旧结果不能强行覆盖新正文。
- 工具意图在副作用前持久化，以任务／调用身份查询幂等回执。重启遇到未知结果先对账，不重新猜测执行。只有原生完成调用与结果检查通过才显示完成。
- 默认累计64轮／30分钟，高级预算有上限；继续任务不清零累计轮次或运行时间。达到预算为暂停状态，不能显示成功。
- OpenAI兼容、Anthropic、Gemini复用已有原生协议；工具流式参数必须完整组装并验证，保留必要的签名内容。协议错误、限流、网络错误及取消只输出本地化错误码，不泄露上游响应或私有配置。
- 切页、关闭AI侧栏及托盘驻留继续；关闭任务文档、明确暂停或真正退出时停止并保留检查点。重启仅恢复进度，等待用户继续；恢复先核对文档、模板及连接。
- 同一任务只能有一个执行拥有者；暂停与工具提交顺序必须有明确原子边界，迟到的网络响应不能越过暂停或人工修改。
- 使用操作系统租约区分存活与中断拥有者；同资料夹桌面和MCP合计最多两个活动任务。新进程不得中断另一个仍在运行的任务；明确暂停跨服务传递，轮询只读状态列，不反复解析全文。任务库schema2从本轮旧候选schema1迁移，较旧程序拒绝改写新库。
- 修改工具在审阅副作用前预留检查点完成空间；未确认意图保留预约，终止操作另留容量。达到任务容量上限时拒绝新副作用，不能先改正文再发现无处记录回执。
- 现有补全的独立模型、流式灰字、Tab／Esc、输入法及过期保护保留，并加入相应回归。

## 验收和证据

分别记录纯函数／协议测试、真实SQLite／文件、真实进程／MCP、正式CSP headless页面及实际已配置模型；互不代替。实际模型连接只读使用，不复制配置，不把模型、连接、地址或密钥写入公共文件。

必须实测：快照后修改正文和原图、只接受旧集合；失败／取消不接受；锁文件及外改保护；文件提交后审阅失败对账；TeX整组依赖；任务至少两次修改、检查后结束；预算、暂停迟到、重启显式继续、幂等、人工修改冲突和原文档绑定。保留首次失败，修复后运行适用回归，不跳过断言。

构建始终 `--locked --offline`，单个共享target、关闭incremental，不复制依赖或浏览器。缓存8GiB提醒／12GiB停止增长；先测量再清理明确归属的可重建产物，保留用户资料、未审原文和必要失败证据。
