# V0.0.7 顶栏与侧栏的限定交付

本规格延续现有文档、审阅、任务和窗口服务。它约束导航投影，不新增工作台，不改变保存、关闭或退出的决定所有者。用户要求 P1、P2 全部完成后才发布 V0.0.7；本切片通过不改变该门槛。

## 输入与布局

- 桌面使用一个 52px 全局顶栏。原编辑工具栏仍为单行，现有审阅栏保持自身状态，不把业务工具混入窗口按钮。
- Mac 使用真实系统红黄绿按钮，按原生实测边界留出间距；其余操作靠左，文件名紧邻最右的品牌。Windows/Linux 保持各自窗控的位置。
- 命令入口显示原图标，可访问名称、悬停和焦点提示提供用途及平台快捷键。
- 原文档页签放入可收起侧栏，保持同一 DOM 节点和文档 ID。重复文件名仍对应不同身份。长列表可滚动，活动项可定位，重排按当前纵向坐标计算。
- 侧栏收起释放真实布局宽度；已消费的重命名 Esc 不继续关闭侧栏。
- 浏览器宽度不超过 640px 时，把原打开、命令、搜索、AI 和图谱按钮移入原“更多”菜单；保留原 ID、监听器与快捷键，不复制按钮。阅读设置继续靠近编辑。回到桌面宽度后恢复原节点和顺序。字号和断点复用现有设计规范，侧栏随宽屏平滑调整宽度。

## 交互与失败方式

所有可见 Web 操作保留至少 44px 命中区，隐藏项不得留下空菜单行。系统红黄绿使用系统自身尺寸。没有文档时隐藏阅读设置。菜单采用现有翻译；动态提示跟随语言变化，更新标签时不得重建正在输入的重命名控件。

菜单打开模态窗口前，应先关闭菜单并保留可见的“更多”焦点入口。跨窄屏断点移动了原 opener 时，只在对应窗口关闭且没有其他模态层、当前焦点不可用的情况下归还“更多”；明确回到编辑器或其他可见控件的焦点不得被抢走。临时观察只保留一个并在关闭后释放。

自动修复弹窗使用已有色彩和间距体系，说明在列表前，诊断区单独滚动，主要操作和关闭始终可达。AI 深度修复继续进入固定目标的持久审阅流程；保存不是接受待审修改。界面整理不得恢复直接覆盖正文或直接写同名副本的旧路径。

插件能力列表的同次刷新共用实际请求。刷新、确认及卸载按现有操作回执顺序执行；后端 busy 时不把已安装误作可操作。卸载期间只观察本次 job 的实际终态，终态后再刷新，不用频繁健康探针竞争文件保护，也不重放未知副作用。

## 独立验收

固定输入包括重复文件名、中文与非 BMP 文本、BOM/CRLF、长文档列表、长诊断及空报告。覆盖 360/390/412/600、640/641 边界及包含图谱按钮的浏览器布局，以及 1024×680、1160×820、3840×2160、浅深主题和 RTL。

真实浏览器以正式 CSP、实际鉴权及 Rust 文件/审阅/会话服务验证：打开、编辑、保存字节、一次撤销重做、关闭取消、显式关闭后的新进程恢复、菜单入口与焦点、窄屏来回迁移。真实离线 Node 的安装、执行、取消和卸载另有消费者检查。旧测试应适配新的可见入口，保留原有正文、选择范围、焦点和持久结果断言，不改断言数字消除失败。

Mac 专用 App 再验证原生按钮、窗口焦点、实际 NSWindow 全屏状态、侧栏释放空间及保存/关闭/新进程。DOM 激活不等同物理输入，浏览器几何投影不等同原生宿主，WKSnapshot 与系统按钮合成不等同物理显示器截图。F11/Esc、系统输入法、原生滚轮和实体高 DPI 缺少实际证据时分别保留待验。

办公软件的实际打开、可编辑对象、另存、导出和重开按独立输入逐项记录。字体漂移、接口阻断或外部格式损失不能被 XML 合法、流程运行成功或预览图掩盖；不用的专用办公窗口在每份验证结束后关闭，正常退出保留系统未保存确认。

每轮绑定源码、index、boot、二进制、driver 及产物摘要。首次失败保留；只有对应候选实际通过后才更新进度。任何限定通过均不认证完整 P1/P2、46 语言语义或全部能力合同。
