## 必须防回归的链路

| 场景 | 独立预期 |
| --- | --- |
| 干净文件打开、进入编辑和关闭 | 不产生副本、不标脏、不弹不必要确认；读取失败不能伪造空正文。 |
| 保存、取消、不保存；退出编辑、关标签、关窗口与真正退出 | 一次确认只有一个所有者，晚到结果不能改写决定；只有明确关闭且持久回执完成后才从会话移除。 |
| 中文、emoji、重复段落、包围编辑、相邻删除及空范围 | 身份、generation、UTF-16 和逐段原文均校验；撤销/重做要恢复精确待审范围，不能只核对正文相同。 |
| 带待审和图片历史的另存为 | 原件、新身份、各历史状态所需资源和重开均正确；取消、占位、锁定、空间不足不得丢图或清待审。 |
| 同版本更新、缓存和安装 | 重打包 boot 同步内容摘要 URL；新目录的安装 helper 必须绑定实际目标并先做自有文件的独占 rename/占位拒绝探针。保留回退和默认关联，不能沿用旧路径或旧候选成绩。 |
| 发行交付与失败恢复 | 每阶段保存有限且不含隐私的失败原因；已上传资产只按封印的 ID/名称/大小/SHA 恢复。十一项真实匿名下载全过才清远端旧备份，不能用 API metadata 或本地包代替。 |

## 恢复开发时的入口

先检查实际分支、未提交改动和最新发布回执，保护已有内容；再按上述顺序选择一个切片。Rust 保持 locked/offline、单共享 target、关闭增量编译与缓存预算；不为代理复制 target。常规 CLI/服务检查独立进行，原生键鼠集中协调。所有结果先实际验证，后更新清单；已有首败、受限状态和未测平台继续保留。

本批结束不自动开启下一条任务、不创建定时续作，也不发布 V0.0.7。
