# 第三批局部排版 MVP 增量

2026-10-12。沿用已冻结的 M3-01–08 合同，补齐 B3-56 中列表／引用段落与标题的常用局部排版。此增量不新增入口、不扩张 MVP，不替代完整出版／Office 应用互操作验收。

验收前固定：

- 复用“文本 → 局部排版”，支持紧凑／松散列表、引用内段落与标题；重复段落以源范围定位。
- 隐形布局注释放在当前内联内容末尾，保留列表层级、任务状态、起始编号、标题 ID、链接、BOM 与换行。重置恢复原始源码，一次撤销完整修改。
- 编辑器仅折叠语法树确认为注释的元数据，代码示例不折叠；点击元数据定位当前段落，不跳到下一段。
- 普通预览只对当前段落应用属性，不继承到子列表；分页预览提供实际目标，临时定位标记不改变输出像素和文字几何。
- Word 保留原生编号和继承缩进；EPUB 通过独立验证；Typst 输出实际 PDF。明确保存前不写文件或资源目录，保存重开后可重置。
- 中部／重复／无效元数据拒绝导出，保留旧输出；过期修订拒绝修改。1024×680、1160×820、RTL 和深色模式检查现有 UI。
