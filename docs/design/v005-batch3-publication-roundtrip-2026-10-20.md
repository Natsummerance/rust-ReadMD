# 第三批：出版编号、注释与引用回流实施规格

本次接续 candidate-16，保留 toolbar、首次编辑绘制和 4K 布局修复。只使用离线构建、CLI 和真实 stdio；不启动用户桌面软件。Word、WPS 等原生互操作缺少本轮证据时继续保持未验收。

## 数据与交互合同

- 编号由文档中的可读 `readmd-numbering:v1` 声明持有。标题最多六级，题注按公式、图、表独立设置格式、起始值及全文／章内范围。真实段落参与编号，代码和嵌套示例不参与；引用身份不随显示号码改变。
- 设置放入现有局部版式和导出高级区的同一折叠组件。读取不改文档；应用／清除通过修订校验事务，单次撤销，不直接写文件。MCP 与桌面使用同一内核服务。
- Word 标题写原生多级编号，题注和引用写可更新字段。EPUB、阅读及 PDF 显示由同一源模型生成；不把编号写进作者标题文本。
- TeX 目录按原生 reader 的实际字体、字号与字重测量该层编号，保留缩进、引导点、页码框和换行挂起布局；宽度按层缓存。真实 PDF 逐字符检查编号与标题的间距，并以旧重叠产物验证检查器确实能拒绝缺陷，不能仅凭文字存在判通过。
- 注释区分连续、源分节和物理页重启，支持分隔线、续页分隔、续页说明及长注段落策略。无物理页概念的格式明确报告不支持；章节拆分不能改变源分节策略。
- 引用回流按节点身份和源码／显示摘要判断，保留相关文献、样式和语言资源。移动文档后不得依赖原机器路径。手动修改过的引用和注释保留可见内容，旧源只作为恢复依据，不能静默覆盖。
- 显示摘要使用明确的上下文版本：引用／书目及生成注释只绑定实际使用的 OPC 关系、目标、模式及必要包内载荷摘要。链接目标或同路径媒体字节改变都属于手改；无关关系不影响其他绑定。旧版无上下文摘要保留可见内容及来源诊断，不据此自动恢复；损坏／重复关系不能回退到宿主文件或网络读取。
- Typst 输出核验脚注实际起始页与引用页，允许长注续页；错页或编译未收敛时拒绝提交并保留旧 PDF，返回可定位诊断。不把显式改变段落策略后的成功材料当作默认布局已修复。

## 实施与验证顺序

1. 三条独立实现线完成 Rust 编号、注释和引用回流，父任务负责共享 API、MCP、阅读和导出接线。
2. 接入现有界面，补齐新增 46 语言文案及诊断；保留无编号旧文档输出行为。
3. 运行完整 Rust、前端和仓库检查，保留第一次失败。重新打包 boot 并编译正式 CSP 的本机 CLI。
4. 冻结新候选，真实 stdio 执行编号及引用的导出—迁移—回读—再导出；检查 DOCX 原生结构、EPUB 链接和真实 Typst 分页。
5. 覆盖修订冲突、BOM/CRLF、重复对象、源代码中的声明示例、手改内容、失败时旧目标保护；保存独立检查器、产物摘要及限制。

## 完成边界

每项只按已取得证据更新。XML 有效、源码断言或 CLI 回读均不代替外部软件的实际呈现和字段更新验收。现有第三批未完成项继续保留，不因本次局部通过而关闭整批。
