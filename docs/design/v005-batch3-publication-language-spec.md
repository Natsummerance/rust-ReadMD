# 第三批：出版语言与元数据边界

沿用 Markdown 开头的 `lang`／`language` 和已有导出 `meta.language`／`meta.lang`，不新增界面。导出配置优先于正文声明；EPUB 自有语言设置优先于通用元数据。没有声明的旧文档保留各格式原有默认值。

- 共用有界语言标签处理，保留文字、地区、变体、扩展、私用及祖父标签；接受下划线分隔的历史写法并规范大小写。只做语法和输入边界检查，不宣称 IANA 注册或旧别名规范化认证。无效声明不参与覆盖，原始文档保持不变。
- 只读取开头、顶层元数据；正文、嵌套字段和代码示例里的同名文字不成为全书语言声明。HTML 隐藏开头 YAML，不隐藏后面的代码或正文。
- HTML 输出实际 `lang`；DOCX 输出默认校对语言及核心属性；EPUB 的 OPF、导航及章节语言一致。Typst 使用语言主标签和支持的两字母地区，不误读扩展／私用字段。数值地区、脚本变体等完整 BCP47 与 PDF 原生表达差异仍分别记录。
- 实测 Typst 0.15.1 的 PDF 主语言省略地区，因此 Rust 在提交前追加仅修改 Catalog 的增量修订，保留完整声明；原始页面、字体、链接及结构对象的字节不改写。仍计入原任务期限及 32 MiB 输出限制，失败不得替换旧文件。
- 测试真实德语论文、法语配置覆盖、繁体中文文字／地区标签、电子书专用覆盖；实际 Typst PDF 必须编译、读取语言声明并重新渲染。保存、重开及源目录无污染与本次构建绑定。
- 旧 UI 默认值、作者指定的字体和对齐保持原约定；本轮不认证完整 RTL 排版、所有元信息或真实 Word 应用互操作。
