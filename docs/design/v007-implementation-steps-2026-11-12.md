# V0.0.7 开发与验收步骤

2026-11-12。以 GitHub V0.0.6 发布页记录的安装包源码作为基线。已有用例和证据沿用其原始候选与验证范围。V0.0.7 在 P1、P2 全部达到既定验收条件后发布。 [执行计划](v007-execution-plan-2026-11-02.md) · [当前验收与待办](v007-next-development-2026-11-05.md)

## 1. 冻结文档与窗口回归

1. 固定中文、emoji、重复段落、UTF-8 BOM/CRLF、外部改写和缺资源的测试文档。记录原件、预期结果、待审原文、修订、可撤销状态及必要资源的摘要。
2. 在真实文档上执行编辑、快捷键保存、保存并退出、取消、不保存、关标签、关窗口、重启和另存。检查快捷键保存后仍在编辑，保存按钮回到阅读，干净文档关闭直接完成。启动时复核空会话、崩溃恢复与外部版本冲突。
3. 用同一候选复验 Mac 原生菜单、红黄绿窗口按钮、桌宠右键、文件关联及安装包启动。Windows、Linux 执行同一文件与 HTTP 用例并保留各自报告。窄屏、4K、高 DPI、RTL、键盘和输入法逐项记录实际运行环境。
4. 从真实界面复核顶部标签、收起和展开的侧栏、单行编辑栏、右侧 AI、禅模式及文件选择。用浅色和深色主题核对 BongoCat 透明底、互动及原生右键菜单，逐项检查自动修复、编辑预览和插件工坊的焦点、对齐及长文本溢出。复用现有菜单与弹窗组件，删除被替代的样式前先核对各入口。

## 2. 完成 P1 办公和程序员闭环

1. 先做矩形 Markdown 表格的插入、删除行列和稳定排序。复用 `cmTableCellContext` 的语法树范围及 `ReadMDReview` 的手动修改事务，按当前文档身份和修订提交。用两张内容相同的表格验证目标归属，检查表头、对齐、转义、富文本、空单元格和待审内容。每种操作完成保存、进程重开、一次撤销重做和外部修改拒绝。
2. 用同一表格模型完成合并、扩展属性和科研三线表。先固定可表示的格式及失败回执，再核对实际 DOCX、PDF、PPTX 的内容、边框和跨格结构。用 Pages、Keynote 和可用的外部 Office 消费者各自验证；记录字体替换、分页变化及格式损失。验收完关闭测试文稿。
3. 单独测试预览首屏、缓存复用、格式切换、取消和失败重试。PPTX 预览按实际幻灯片比例适配面板，验收包含 1024×680 和 4K。用同一冻结文档分别检查真实产物和预览显示，过期渲染请求不得覆盖当前格式。
4. 让桌面、VS Code Extension Host 和 MCP 共用 OpenAPI 与代码运行的事务入口。先重现 Windows 停止流程的 `10060` 并记录请求、进程退出、回执顺序，再以最小改动修复。验收包含复杂引用、过期修订拒绝、超时、取消、停止、结果撤销、进程重开和检查点续作。

## 3. 完成 P1 容量、媒体和 AI

1. 复用卷身份与容量准入，补 Linux 用户和项目配额以及准入后写满的恢复证据。重复测试安装峰值、并发、旧包保留、取消与重新安装。
2. 用现有受管离线包打通 FFmpeg 和 whisper 的就绪检查、选段和音轨、时间偏移、字幕、回放、取消、续作及重开。每个步骤检查实际输出，记录 Mac、Windows、Linux 的依赖来源。OCR 的 Windows 实测、Mac 适配和 Mac 实际推理分列。
3. 先复核「本地 AI」内两种本地服务的认证、模型列表、切换、重开和密钥保护。使用已授权的 VPS 连接，验证流式聊天、多轮工具、补全、停止和断线恢复，优先试用用户指定的可用模型。分别记录失败后的待审、保存和任务状态，连接与凭据留在私有配置。本机推理实测安排在资源可用时。
4. 保留 Windows AI 流式队列满后停止的首次失败，分别观察 HTTP 取消响应、上游关闭、连接槽归零。Mac 受管 Node 状态与 Run 交错时，保留同一探测文件的进程、独立摘要及资源回收证据；测试采样未捕获进程时保留原始报告。

## 4. 按依赖完成 P2

| 顺序 | 实施步骤 | 独立验收 |
| --- | --- | --- |
| A 协作 | 统一服务端授权、审阅决定、结构冲突和修订回流，接入 TLS 及权限变化处理 | 真实参与者与独立客户端分别测试。撤权、重连和恢复后检查双方文档、待审及权限 |
| B 文档与 PDF | 先实现原排版读取和提取损失报告，再补批量命名、取消、重试。按嵌套对象、表单、页面、OCR 区域和签名逐项推进 | 由外部阅读器复核原排版和导出的 PDF。签名影响、字体溢出和写入失败均有明确结果 |
| C 创作 | 在 Rust 图像文档中实现图层、蒙版、压感笔和可编辑 SVG，随后复用到教学、章节和手稿流程 | 从暂存到保存、重开、撤销和失败逐项核对，验证共享引用、原图及历史资源 |
| D 数学与出版 | 补齐可编辑公式往返、CSL、TeX 资源、脚注与分节、科研图表原数据和书稿结构 | 按 Word 可编辑 OMML、PDF 矢量、EPUB MathML 和实际外部应用分别核验 |
| E 发行 | 冻结代码、boot、二进制和安装包摘要，逐平台跑回归、安装、冷启动、恢复与回退 | 区分 Apple Silicon、Rosetta、实体 Intel、Windows、Linux 及其他系统。按现有目标复测输入、取消和启动性能，复核 46 语言语义及官网两处入口 |

每个切片先保存首次失败和独立预期，完成后再更新 [75 项验收账本](capability-upgrade-acceptance.json)。版本发布时用同一冻结候选构建全平台包，完成实际匿名下载和 SHA-256 复核后清理替换备份。
