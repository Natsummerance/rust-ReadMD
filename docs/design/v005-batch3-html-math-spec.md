# 第三批：HTML 新公式 DSL 真实渲染

修复已在真实导出文件确认的 DSL 原样显示问题。复用 Rust 数学树和原生矢量布局，不增加编辑器或数学库。

- 按 Markdown 解析器的实际源范围替换行内及块 DSL，包括列表、引用中的围栏；代码示例、原始 HTML、链接及普通 LaTeX 保持兼容。不按字符串全局替换。
- 输出自带字形的矢量 SVG，保留 Office 属性，使用可访问的数学语义标签；缺字不能静默写出空图，明确报告降级。
- 编译失败、未知版本和预算超限发生在写目标之前；输入及原有目标保留。
- 默认深色配色同时作用于现有 HTML 小预览和真实输出，覆盖标题、表格、引文、代码等；非默认自定义色保留，其他格式不套用 HTML 调色规则。
- 数学语法及属性错误使用可本地化错误封装；前端兼容旧接口错误字段，语法和预算提示复用既有 46 语言译文。真实中文／英文切换验证错误信息，不能直接显示内部错误码。
- 本机真实 HTML 生成、实际捆绑 Markdown 引擎及独立浏览器检查嵌套结构、重复公式、字形间距、颜色、打印、代码示例和无输入目录污染；与原生数学／出版回归绑定同一构建。
- 不以此认证所有 HTML／Office 属性、独立阅读器或完整第三批。
