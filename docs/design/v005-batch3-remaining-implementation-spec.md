## 2. 公式：确切补齐什么

### 2.1 标准范围先变成可执行账本

沿用 [固定 schema 覆盖表](office-math-coverage.json) 中的提交与 SHA，不在实施中无记录地追随上游。共 **133 个 schema 条目，其中 9 个抽象类型、124 个具体元素；12 类枚举共 43 个值；19 类核心对象**。抽象类型验继承规则，不当作用户可插入对象。现有 `sourcePresence` 仅是代码导航；`certifiedFullPropertyRoundTrip: false` 不能改成“所有元素没实现”，也不能自动改成通过。

新增逐条索引见 [语义验收索引](v005-batch3-semantic-audit.json)。它列全标准条目及枚举值，记录下述工作项、测试模板和待认证状态，避免只补常见公式。实现阶段每个条目补上：规范默认值、允许父节点、单位、可读写法、编辑入口、源范围、有效渲染、各格式能力、实际 Office 夹具和失败夹具。

每个叶属性至少测试：省略元素、空元素（仅 schema 允许时）、显式默认、显式非默认、显式关闭（开关）、边界、非法值。保留“作者显式设置”与“有效默认”的区别；二者画面可能相同，源码状态不能被合并。枚举 43 个值分别编译／反编译及消费，不能只检查 XML 接受。单位分别检查 twip、pt、半点、em、半 em、半行，不统一粗暴换算成 px。

### 3.2 参数测试统一方法

每个参数做 A/B 实际输出：只改该参数，检查目标部件／几何变化，同时对不应变化的内容做语义比较。全局→节→局部三级覆盖、清除恢复、旧预设缺键、非法值、极值、单位换算都要测。默认设置不附带无用标记，打开／预览不写源目录，明确保存才物化必要资源。

至少固定三套端到端材料：论文（双语摘要、双栏、公式、CSL、图表、脚注和横向附录）；书稿（前置页、三级目录、插图、跨章引用、尾注及封面）；工作报告（层级列表、数据表、统计图、链接及自定义局部样式）。长度由测试所需分页决定，不能用大片空白替代复杂内容。

## 7. 执行顺序与每次出口

保留原七包归属，拆成以下可独立复核的实施段。不是新开五个版本，也不将难项从第三批移除。

| 顺序 | 内容与前置 | 当段可验收的结果 |
| --- | --- | --- |
| 0 固定清单 | 本规划及 schema 索引；建立 Office／阅读器夹具和参数能力表；盘点实际应用启动条件 | 每个标准条目有归属；不会再用“全 OMML／全参数”一个大标题循环开发；环境问题先分类 |
| 1 明确语义缺口 | M03/M05/M06→M04；M01/M02 独立推进；已有 kern／伸展／主题回归 | 矩阵宽度、微分／透明间距、方程分布和字体几何在真实编辑／输出中正确。每个小项有退出条件，遇到外部应用阻塞转做不依赖它的项 |
| 2 出版日常闭环 | P01/P02/P07→P03/P04/P05/P06/P08；接口参数同源 | 完整论文／书稿／报告实际文件与用户预设保存重开；节、引用、注释和编号不是静态文字 |

每小项先必要单测／原生专项，修复后完整相关回归；通过后无变更不反复重跑。每轮保留初始失败、修改原因及新证据。最终统一候选再跑全相关 Rust／前端／集成／仓库门禁，避免跨不同构建凑通过数。

第三批专项压力：千公式、复杂多级嵌套、有界非法输入、百万字书稿、万交叉链接、长表／长注释／多节、多格式批量输出、引擎并发与重复请求。记录输入响应 P95、峰值／稳态内存、临时资源增长、取消反馈和工作进程停止；按现有 P95≤50ms、取消≤200ms、停止≤2s、启动／普通阅读内存退化≤15% 判定。八小时混合压力保留总项目门槛，短测不能替代。

每个流程覆盖：操作→撤销／重做→Ctrl+S→关页／退出→重开；过期修订、外部修改、文件锁、独立小卷磁盘满、安装中取消、重复请求均不能破坏原文或旧输出。46 语言键检查与人工语义审校分开，补动态切语后的既有错误提示刷新、RTL、1024×680、1160×820、高 DPI、真实 IME 和 Narrator。

当前只有 Windows。macOS／Linux／国产 Linux 的实现适配可继续，但没有原生证据不能通过其验收；鸿蒙保持独立状态。Word 环境修复、独立阅读器配置和许可证材料不是降低标准的理由，也不应阻塞可独立完成的 Rust／Windows 实现。
