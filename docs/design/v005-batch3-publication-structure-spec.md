# 第三批：出版分节与复杂引用布局实施规格

日期：2026-10-15。承接第三批完整清单及 P01/P07 已冻结的限定证据。本单元补齐 P03 和 P07 的结构缺口，不覆盖 2026-10-14 报告，不将第三批或发布标为通过。

## 共用模型与职责

出版元信息继续使用 `publication_metadata`；引用继续使用锁定的 Hayagriva 0.10.1 和 `publication_rich`。本单元不增加第二套引擎、运行时依赖或常驻界面。

分节用独立的、可手写的顶层声明保存稳定身份及稀疏参数。例如：

```markdown
<!-- readmd-section:v1 {"id":"main","break":"nextPage","page":{"size":"A4","orientation":"portrait","columns":2,"columnGap":8},"numbering":{"format":"decimal","start":1},"header":{"linkPrevious":false,"text":"研究正文"}} -->
```

声明作用于其后正文。无声明时保留旧行为。参数依次继承全局及前节，页码起始值只在显式指定时重置；每节身份唯一。独立页眉、页脚必须显式断开前节，空文本代表独立空白；链接前节保留真实链接语义。连续节只允许在同一纸张、方向和页边距内调整内容布局，不静默改成分页。未知属性、无效几何、重复身份、超预算及不合法的嵌套声明必须在创建输出前失败。

`publication_sections::resolve` 返回原 AST 的块范围及完整节样式，不复制正文、不按显示文字定位。各出口消费同一个解析结果。DOCX 使用原生节属性和独立 header/footer 部件；Typst 和 TeX 使用实际页面、栏及编号命令。流式 HTML/EPUB 保留稳定节锚点和可表达的内容布局，明确报告纸张、固定分页及运行页眉的投影限制。基础 PDF 的不支持能力必须明确报告或拒绝，不能将配置 JSON 视为版式生效。

复杂 CSL 布局从已有 `RichNode` 动态投影为 `RichLayoutNode`：普通 inline、块、缩进、两列、身份分组及链接。原树及源码范围保留；不向每个旧文献条目增加必填字段。单一左标记／右正文继续兼容既有最宽标记列，复杂条目允许多组列、前后独立段及嵌套。块边界和普通可见内容阻止跨段误配；透明身份分组不丢失作者、条目或链接归属。各 writer 输出真实结构，不以全局拒绝复杂样式结项。

## 实施分工与顺序

1. 6.1 Sol max 子代理分别负责分节模型及 DOCX、复杂 CSL 领域投影、独立 EPUB 阅读器互操作；单文件只保留一个写入者。
2. root 串行接通入口预检、其他格式、正式预览、错误与 46 语言、共用 API/MCP；源冻结后统一执行 Cargo，使用既有唯一 target 并坚持离线锁版。
3. 失败保留原件，修复后形成新候选。既有成功夹具继续回归；不能修改独立 RESULT 或放宽断言来取得通过。

## 可观察验收

| 范围 | 输入与操作 | 必须核验的结果 |
| --- | --- | --- |
| 分节模型 | 罗马数字前置页→双栏正文→横向宽表→附录；连续／下一页／奇数页／偶数页；显式空白页眉、编号续排及重置 | 稳定身份、稀疏继承、原块范围、无泄漏、局部修改；无声明输出不退化 |
| DOCX | 实际生成并检查 document.xml、relationships、header/footer | 正确的前节末尾及末节 sectPr、纸张方向、栏、页码和链接前节；实际 Word 打开、更新字段、编辑保存另行提供证据 |
| 分页输出 | 同一文稿实际 Typst/XeLaTeX 编译，重新用 PDFium 打开 | 页数、页面尺寸、奇偶空页、真实页码、页眉及栏的文本坐标；错误或取消不替换旧文件 |
| 复杂引用 | 官方固定 CSL display 原件及独立手写嵌套结构预期；多个列组、block、indent、链接、富格式 | 模型不降维、所有文本与身份保留，浏览器真实几何与各格式结构；实际 PDF 检查换行、缩进及无遮挡 |
| 持久化 | 原生正式 CSP；编辑、撤销重做、保存、关闭重开、重复请求、过期修订 | 原始内容和 BOM/EOL 保留；引用的源码定位与文献资源不被导出投影回写 |
| 独立 EPUB | 专用丰富书稿、两个独立引擎，隔离 profile | 封面、三级目录、公式、注脚、跨章跳转、主题重排与重开；EPUBCheck 和 ReadMD 自读不替代阅读器证据 |
| 故障与资源 | 非法声明、未知字段、超量、窄栏、锁文件、取消及插件缺失 | 提前定位、旧输出保护、临时资产有界；不访问用户私人阅读器会话或目录 |

完整 CSL、真实 Office/独立阅读器、正式 TeX 包、冷启动性能、长注分页及长期压力仍分别验收。尚无 macOS/Linux 原生环境时保持未验收。

规范依据：[CSL display](https://docs.citationstyles.org/en/stable/specification.html#display)、[Typst 页面](https://typst.app/docs/reference/layout/page/)、[Typst 分页与奇偶页](https://typst.app/docs/reference/layout/pagebreak/)、仓库固定 Open XML schema。在线资料用于审查；实际编译只使用仓库已锁定资源。
