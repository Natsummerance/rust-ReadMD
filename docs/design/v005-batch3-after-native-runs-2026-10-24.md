# 第三批后续：公式来源收束与实际出版参数

2026-10-24。实施规格，下面的后续能力尚未验收。公式局部字符样式以[当前单元规格](v005-batch3-m07-native-run-styles-2026-10-24.md)及其最终证据为准；本文件不提前认证 M07、P04 或第三批。

## 先收束已经可以真实使用的公式链路

有限入口为已有 Word `b/i/sz/RGB` 叶节点的源属性编辑、段落／显式字符样式链及真实原生引用。继续保留简单公式填槽、源码按需展开，不增加常驻控件。

- 前端沿原高级属性面板及 `richPatch`，保持源节点、全文上下文、修订、撤销与取消。空 `b/i` 的 `val` 表示隐式开启，在样式中是 toggle，在直接格式中是 absolute；不能把它解释为删除声明或恢复继承。
- 后端只编辑合法原位置的四轴叶，不通过覆盖父结构修复非法来源。临时校验副本可以规范命名空间键；作者树、别名、注释和非目标源范围保持原合同。
- 非空源 `rPrDefault` 的后续原生重导出仍单列资格。当前模板引入默认值后，要保留“同一未改 native 基线”，再比较用户改动；不能以源文件到目标模板的变化冒充用户修改效果。
- 下一项来源证明优先检查实际源默认、目标模板及已用主题的相容性。只在实际上下文可证明兼容时复用目标既有默认；禁止修改 Normal、普通正文、全局默认，或将原默认偷偷改成局部数学样式以声称全局来源未变。
- 多来源全局属性不能同时成立时，保留准确消费、原来源与损失说明。这是格式表达限制，不能删掉 guard、伪造默认值或宣称任意来源包原生无损往返。其它 Word 属性与未知扩展仍逐项证明。

## 接下来优先打通 Typst 普通正文非零基线

目标是用户已有的局部出版参数能在实际分页预览和独立导出中生效；不增加 UI。第一组正向材料包含普通正文、字号变化、普通链接、局部零复位、默认／固定行距及跨页。复杂保护对象必须有来源证据，不能凭文字或字体猜测。

### 复用现有实现

| 文件／函数 | 已有职责与应保留部分 |
| --- | --- |
| `publication_pagination_baseline.rs::prove` | 源 wrapper、逻辑链接和实际注释分片归属；不以 URI、复制文字或顺序认领链接。 |
| `publication_pagination_baseline_graph.rs::check_link_fragments` | OBJR、ParentTree、MCID 图与页绑定。图合法不等于实际绘制完整。 |
| `publication_pagination_baseline.rs` 的清理及 Rect-only 链 | 清理内部证据、重新读取，再仅修正已证明的注释矩形；保持其余注释键与目标。 |
| `typst_compile.rs` 公共 consumer、worker 及 raw-artifact guard | 保留，直到实际产物的墨迹安全证明接入；只删一个 guard 会绕过其它入口。 |
| `pdf_text::validate_generated_glyphs` | 现有缺字检查可复用，但 CID/GID 非零不能替代字体轮廓、坐标和绘制覆盖证明。 |

### 新增一个有界的实际绘制检查模块

1. 从实际编译产物读取内容流，跟踪 `BDC/BMC/EMC`，与现有源绑定 MCID 图做双向核对。缺失、重复、错页、未归属绘制与多余分片都拒绝；零链接段也不能跳过。
2. 复用现有 PDF、嵌入字体及字形解析能力。检查 CID→GID、字体程序、字号、文字矩阵、CTM、advance 和实际字形墨迹；支持范围明确列举，不另建文本猜测器，不依赖复制层或注释 Rect 作为墨迹。
3. 计算移动后的墨迹与纸边、相邻行／段、固定行距和保护对象的关系。原生 Rect 含 leading，不能把 Rect 或 Typst `measure` 直接当成可见墨迹。
4. 所有源归属与墨迹检查完成后，才进入既有清理和链接矩形修正；清理后再次读回，验证内部标记消失、文字／字体／路径不受污染。
5. 公共 API、分页预览、独立导出和受管理 worker 共用同一资格判断。失败发生在最终目标提交之前，保留原文件、预设及待审状态。

### 同一候选的实际验证矩阵

| 正向流程 | 独立核对与反例 |
| --- | --- |
| 0、+3、−2.5、+3.25pt；大／小字号及 descender | 实际 GID、字体程序、字号、x advance 不变，glyph y 按参数移动；移动出纸边或碰撞时明确失败。 |
| 默认／固定行距、长段跨页、局部零复位与删除覆盖 | 相邻行／段墨迹和分页，不能只比较首行或测试字。过小固定行距不放行。 |
| 同 URI 重复段、跨行／跨页链接、内部跳转、零链接段 | 全部 OBJR／MCID 分片和实际 glyph 归属；继续拒绝“字移框不移”、缺分片、错页及重复归属。 |
| 分页预览与独立导出、保存后新 PID 重开 | 同一固定内容／资源／参数，完整实际 PDF 对照；不以另一轮编译的 URI 或文字推断来源。 |
| 旧修订、取消、坏字体、未知过滤器及错误映射 | 既有输出字节、目录、预设不变；保留首次失败；禁止跳过不识别的绘制后返回成功。 |

初次开放先限定有实际资格的字体、行距及顶层普通文本／普通链接。Strong／Em 的分片需单独证明；Code／Math 的保护来源要增加可清理的独立 witness 后再开放混排，不能依据相邻字形猜测。JPEG／未知过滤器、linked Code／Math、旋转、UserUnit、QuadPoints 保留明确边界，后续补真实正向能力，不能只有拒绝测试。

## 保留的第三批完整欠项

完整 Word 默认值／主题／样式与复杂公式来源编辑、完整 CSL 组合和剩余出版参数、实际 Word／WPS／LibreOffice／电子书阅读器互操作、正式离线资源与 TeX 材料闭包、受控冷态、完整故障及八小时混合压力仍独立在账。

本机只有 Windows，且当前要求不使用 computer use。CLI／MCP、真实文件和离线引擎继续执行；没有原生 GUI 或其它系统证据的项目保持未验收。不能为了凑齐清单把 ZIP/XML 合法、前端动态控制或交叉编译写成实际应用验收，也不能让这些环境缺口阻塞可实现的 Windows 功能。

每个后续单元均采用同一顺序：固定输入、源映射、失败与持久化合同 → 真实实现 → 一次统一离线编译及完整回归 → 新候选实际流程 → 有界归档读回 → 更新有限里程碑。保留 toolbar／首绘／4K 修复；不替换安装程序，不在第三批完成前发布。
