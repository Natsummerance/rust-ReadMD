# V0.0.7 延续清单

V0.0.6 按[发布闭环范围](v006-release-closure-2026-10-30.md)交付现有迁移成果和已验证的收尾修复。[75 条能力合同](capability-upgrade-acceptance.json)的整项状态继续保留，不能把一次限定发布自动转成全部验收。本清单仅安排后续工作，不宣称以下项目完成。

- **跨平台事务**：非 Windows 的多文件引用重命名、强身份租约、完整回滚及新进程恢复；保持现有平台拒绝保护。真断电、磁盘满及不明外部占位继续独立验收。
- **程序员与集成**：复杂 OpenAPI 长尾、代码运行环境与取消/撤销、真实 Extension Host、跨预览与导出的一致性长尾。
- **办公与协作**：可视单元格、排序/合并/扩展属性、报告流程；多人审阅、结构冲突、权限变更、TLS 和长期真实多人操作。原生 PPTX 与外部 PowerPoint 往返不由离线 HTML 幻灯片代替。
- **外部文档与 PDF**：原排版优先阅读、复杂导入保留/损失报告、批处理完整生命周期；嵌套 PDF 对象、表单/签名/加密、扫描区域校订与字体溢出。
- **媒体与创作**：受管跨平台 FFmpeg/whisper、轨道与选段、字幕/回放/续作；非破坏图像文档、图层/蒙版、压感笔、可编辑 SVG、教学与章节组织。
- **数学与出版**：19 类对象与 133 个 schema 条目的分消费者证据，完整 CSL/TeX 闭包、复杂版式及 Word/WPS/LibreOffice/EPUB 阅读器往返。浏览器参考页不能作为办公软件分页认证。
- **AI 和性能**：更多供应商错误矩阵、长文/多模态、完整流式补全；输入延迟、取消/worker 停止、绘画帧率及阅读退化的实际分位测量。
- **平台与国际化**：实体 Intel、旧版 macOS、其他 Linux/国产 Linux/鸿蒙分别验收；菜单/托盘、Finder 关联、真实 IME/键盘、46 语言语义审校。构建、Rosetta 和 headless 证据分开记录。
- **分发**：当前 Mac 免费 ad-hoc 分发保留首次逐应用授权说明；正式 Developer ID/公证仅在将来具备用户凭据后推进。

每项继续按入口→真实服务→持久结果→重开→撤销/失败组织纵向切片，复用已有 Rust 业务边界和固定测试输入。新候选绑定新摘要；不得删除历史首败、覆盖旧证据或降低数据保护以凑完成。
