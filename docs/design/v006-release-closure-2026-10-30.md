用户于 2026-10-30 授权发布 V0.0.6；本指令取代此前“迁移不代表发布”的时间点限制。源码从已核对的迁移分支 0d941dea85d4efff9764e80b0a3b12205c04e7b9 延续，保留现有审阅、任务、快照和恢复实现。

## 本轮输入与独立预期

- 中文路径下的合成 Markdown，包含标题、正文、重复段落、表格、公式、图片与明确的幻灯片分隔。打开、编辑、保存、关闭、重开后正文和资源一致；未改动不标脏；外部修订不可覆盖。
- 导出面板逐一切换 PDF、DOCX、EPUB、HTML、TeX、演示文稿。等待对应内容就绪，不能把上一格式的旧页或空白当成功。PDF 使用实际 PDF 字节；DOCX 必须明确标注共享布局参考，不冒充 Word 分页。TeX 预览为源码，不冒充 TeX 排版。
- PPTX 预览与真实可编辑 PresentationML 文件共用 Rust 分页布局，按 16:9 横向自适应展示、翻页，文字与表格保持原生对象，长内容续页；图片、公式图片及备注保留。原有 Reveal 全屏演讲与显式离线 HTML API 继续可用。验证边界见 [PPTX 修正规格](v006-pptx-export-closure-2026-10-30.md)。
- 导出保存到本轮工作区内新目标后，独立读取产物验证正文、图片、页/章/幻灯片；失败、取消、过期结果不能清除待审修改、覆盖原目标或留下假成功。
- Mac PDF/DOCX 预览必须有实际页面图像；不能因仅有 Windows 渲染器而显示一个文字占位。成熟系统框架优先，不引入依赖 PATH 的渲染工具。
- 真实 Cocoa/WKWebView 验证基础保存恢复及导出链路，正式 CSP 和真实鉴权保持不变。Chromium 录制用于素材与跨格式界面检查，单独记录，不能代替原生宿主认证。
- Mac 最顶栏使用真实系统红黄绿窗口按钮，左侧保留窗口操作，其余控件反转靠右且 LOGO 最右；不改变下一行阅读/编辑工具栏。尺寸、RTL、禅模式、全屏和关闭保护按[原生窗口规格](v006-macos-window-chrome-2026-10-30.md)分别验证。

## 预览速度与录制就绪门禁

用户追加反馈后，在本机实际 release 二进制、受管中文字体与中文图文材料下，首次／切换预览测得 2.4–3.2 秒；原录制的固定间隔短于该耗时，不能作为可用素材。

优化边界：已具备运行资源的冻结快照不重复提交前端 runtime 绑定请求，后端预览及提交的完整校验保留；正式构建单独优化 SHA-2 的 CPU 代码，继续逐字节校验。已生成的预览仅在同一 document_id、generation、review_revision、格式和完整参数键内复用。停放输入与页面缓存合计有 16 MiB 预算，最多五个停放快照加一个当前快照；大输入直接释放，不因缓存淘汰审阅原文或未知输出意图。关闭导出面板释放本面板的未提交快照，延迟响应不能替换当前格式。

补录必须等页面实际可见、图片解码、字体及有限切换动画完成，再保留足够阅读时间；不能仅验证选中的格式字段或请求成功。性能实测和素材就绪证据各自绑定实际二进制／boot 摘要，首次速度与返回已看格式的速度分开记录。

实际编码画面复查另外发现 HTML 投影使用相对图片路径导致破图。修复后 HTML 预览改读同一个 Rust 冻结快照，图像、字体与公式就绪前保留加载状态；解码失败明确提供重试。独立真实服务验证了预览原字节、外部改图后仍导出旧快照、重新打开面板取得新资源、切换格式清理加载状态，原 Markdown 不变。重复 HTML 图片展开也在分配前执行快照字节预算；不能为了预览读取未经授权的上级目录。
