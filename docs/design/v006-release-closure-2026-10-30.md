用户于 2026-10-30 授权发布 V0.0.6；本指令取代此前“迁移不代表发布”的时间点限制。源码从已核对的迁移分支 0d941dea85d4efff9764e80b0a3b12205c04e7b9 延续，保留现有审阅、任务、快照和恢复实现。

## 本轮输入与独立预期

- 中文路径下的合成 Markdown，包含标题、正文、重复段落、表格、公式、图片与明确的幻灯片分隔。打开、编辑、保存、关闭、重开后正文和资源一致；未改动不标脏；外部修订不可覆盖。
- 导出面板逐一切换 PDF、DOCX、EPUB、HTML、TeX、演示文稿。等待对应内容就绪，不能把上一格式的旧页或空白当成功。PDF 使用实际 PDF 字节；DOCX 必须明确标注共享布局参考，不冒充 Word 分页。TeX 预览为源码，不冒充 TeX 排版。
- 演示文稿使用与实际离线 HTML 产物相同的 Reveal 幻灯片编译器、主题与分隔规则；以横向幻灯片呈现，可翻页。此格式不是 PPTX，不把网页文件改后缀冒充 PowerPoint。
- 导出保存到本轮工作区内新目标后，独立读取产物验证正文、图片、页/章/幻灯片；失败、取消、过期结果不能清除待审修改、覆盖原目标或留下假成功。
- Mac PDF/DOCX 预览必须有实际页面图像；不能因仅有 Windows 渲染器而显示一个文字占位。成熟系统框架优先，不引入依赖 PATH 的渲染工具。
- 真实 Cocoa/WKWebView 验证基础保存恢复及导出链路，正式 CSP 和真实鉴权保持不变。Chromium 录制用于素材与跨格式界面检查，单独记录，不能代替原生宿主认证。
