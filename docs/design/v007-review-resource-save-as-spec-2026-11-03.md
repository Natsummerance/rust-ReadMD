# 待审资源另存切片

沿用现有 Rust 保存锁、文件身份复核、资源内容去重、SaveIntent 和 SQLite 完成预算；不增加前端文件写入实现，也不改受保护编辑器字节。

## 输入与预期

中文路径 Markdown，包含重复正文、相对图片、BOM/CRLF 和待审修改。修改可替换整幅图片，也可只改图片地址的一部分。另存到另一个目录时，原文件和原图片不变；目标只在明确保存后产生必要资源，并统一进入 `readmd-assets`。重新打开目标后仍可定位、同意和撤回对应修改，撤回后的图片必须可读。

资源路径改写可能扩大一个只覆盖文件名片段的审阅范围。不能把旧的原文片段直接插入扩大的新范围，否则会丢掉图片地址其余部分。对每个可撤回块，后端先在其确定的 UTF-16 范围构造独立的撤回正文，再用同一资源服务暂存该正文需要的图片；分别映射当前正文与撤回正文的范围，验证范围外前后正文完全相同，才取得新目录中的撤回片段。这里使用已知块范围和源映射，不按字符串第一次出现的位置定位，也不使用跨越未修改段落的差分。

不可变 `original` 继续保留必要原文。新的可选恢复投影只记录因资源搬迁而实际需要插入的片段。投影和资源意图随同现有 SaveIntent 持久化、预算和恢复；提交失败或取消不能清空审阅。对无法证明范围一致、被用户接管或结构有歧义的情况保持明确拒绝，不假成功。

恢复投影是业务格式变化，即使无需新增 SQL 列也必须提升数据库版本至 6。迁移与完整表结构验证共用事务；旧版内核必须在读取/写回前拒绝较新格式，不能忽略字段后覆盖。普通原文件不因此改变，日常旧版不会接触本次隔离配置。另用实际 V0.0.6 二进制验证拒绝，不只用“版本号大于 5”的单测代替旧消费者。

本切片的跨目录支持边界是可用当前审阅块证明的图片修改及普通正文历史。无法从当前审阅块投影的手工图片修改、图片重做历史继续安全拒绝跨目录另存，原处正文和历史保留；不能宣称任意图片历史都已搬迁。没有实际资源上下文的旧 `/save` 调用也不能绕过资源写入者迁移可见图片。已物化资源的原处日常保存不产生同值路径改写，也不触发这条搬迁限制。

## 独立验收

- 整幅图片被 AI 换成正文，跨目录另存、重开、撤回后图片实际字节一致。
- 只改图片地址片段，资源改写扩大范围后，撤回与一次撤销/重做均得到有效完整地址，重复图片不串块。
- 先同意再另存仍保留必要原文；继续另存到第三个目录不依赖第二个目录中的资源。
- 缺失隐藏图片、目标被占用/锁定、编码拒绝、受控磁盘满与原生选择器取消：原文件、当前正文、待审原文及恢复依据保留，只清理由本次事务创建且身份仍相同的资源。
- 原始审阅版本和源图片不被资源搬迁覆盖。最终证据分别记录真实后端、原生选择器、普通服务重开和独立进程重开，不互相替代。
