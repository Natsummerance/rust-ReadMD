## 1. 已知不支持输入的准确提示

现状：`convert.rs` 的已知 `docx_note_settings_unsupported` 会进入 `legacy_markitdown_failure`，追加“文件可能已损坏”，MCP／HTTP／批任务再包装为 `conversion_failed`。原件保护有效，但用户无法清楚区分能力边界与文件损坏。

实施：

- 在共享转换错误边界识别已注册的注释／编号原生错误，使用严格码表及有界结构化详情，不按任意字符串前缀猜类型。
- 核验 JSON 形状、字段类型和长度；`part/path` 仅为定位信息，不能被作为文件路径执行。畸形载荷及未知错误保持通用错误处理。
- 已知语义错误直接返回原错误码及详情，不进入损坏提示或只提取正文的降级路径。MCP、HTTP、批处理／任务使用相同适配器。
- 复用现有 46 语言 `error.docx_note_settings_unsupported` 等提示；技术详情按纯文本展示，不能注入 HTML 或暴露宿主敏感信息。
- 批处理沿用已有失败行，悬停和键盘聚焦提供准确摘要及已注册、有界的原生定位信息；不新增常驻详情栏。未知代码、任意对象、控制字符及超预算详情不能混入提示。

验收：实际不支持材料分别走 MCP、HTTP 和批任务；得到正确错误码、本地化提示、原件及旧目标摘要不变、无旁文件。另测畸形 JSON、伪前缀、过大详情、真实损坏 DOCX 与未知错误，不能误分类。新候选中更新相应 QA 合同，旧 candidate-31 的原始报告保持不动。

## 2. M07-A：公式默认状态与跨来源隔离

已实现的 15 个非字体 `mathPr` 消费项继续保留，不重新标记为全部缺失。实际缺口是 DOCX 合并：除上下限外按原始 XML signature 比较并采用首份设置，会把其他来源的默认带给裸公式，也会对语义等价的缺省／显式默认误报冲突。

### 合同与实施

1. 对每项记录“缺省／空元素／显式值”，并单独计算有效语义；源码往返不能丢失三态。沿用当前解析器的已支持枚举、范围及准确单位，再与固定 schema 逐值核对。
2. 优先级固定为对象局部属性→本公式片段默认→内核默认。裸 UnicodeMath／LaTeX 不继承相邻导入公式的设置。
3. 重点矩阵：`smallFrac/wrapRight` 的缺省、空元素、显式开关；`dispDef` 显式关闭及局部 `jc` 优先；`lMargin/rMargin` 的元素缺省、空值和显式 0；`wrapIndent` 的空值与 0。不能只比较 XML 字符串。
4. DOCX 合并先比较有效值；可准确局部化的差异生成真实原生局部属性。尚无等价映射的冲突在提交前明确拒绝，保留原目标，不能仅警告后共用首份默认。
5. 当前原生手改优先，隐藏来源只保留身份／恢复，不用旧默认覆盖新设置。交换公式来源顺序不得改变有效结果。

### 真实验收

原生 DOCX 三态夹具→实际转换→公式定点编辑／正文事务→明确保存→正常退出→新进程重开→空 options 再输出→再回导，逐对象检查结构与有效值。加入双来源相反设置、裸公式、等价设置、顺序交换、当前原生设置变更及过期修改保护；几何检查验证小分式尺寸、对齐／间距和窄宽换行。失败时已有文件字节保持不变。

原生转换目前兼容返回 LaTeX 加原生保真载荷；测试先保留真实转换原文，再调用共享数学迁移服务得到可读 DSL。验证基础修订、实际编辑及逆事务、幂等性和迁移前后原生属性；编辑范围必须来自当前这一份源码，不能拿迁移后范围修改迁移前文本。回导采用同一显式流程，不能用正则替换围栏冒充编译或迁移。MCP 原文编辑保存与桌面自动迁移保存分别记录证据。

本单元不认证可替换 MATH 字体和 TeX 原生 OfficeMath 排版。非 STIX 字体的实际回退及 TeX 的 LaTeX 投影继续明确列缺口；真实 Word 编辑认证独立保留。

### 实施审查补充（仍须以冻结候选实测）

- `dispDef=false` 只关闭文档的对齐、左右边距及折行默认覆盖，不能一并清零四项公式间距；矢量尺寸、实际字形位置和 DOCX 有效值分别校验。依据 [Microsoft 的 Word 实现说明](https://learn.microsoft.com/en-us/openspecs/office_standards/ms-oe376/f5f7b70e-9d07-40f0-b78f-4701a036eef5)。
- 行内载体不能夹带真实 `oMathPara` 来绕过显示公式默认比较；DOCX 必须在提交前准确拒绝。旧胶囊也覆盖同一校验，不只检查新 DSL。
- `mathPr` 和其标准叶子按命名空间 URI 与固定 schema 校验；真实别名可用，未限定或伪 URI 的 `val`、语义重复属性及未知标准属性不能作为合法默认写出。未知扩展的保留和可编辑支持继续分别记录。
- 复用现有 particle 验证器，检查顺序及 `wrapIndent/wrapRight` 互斥。独立夹具将两支拆开，不能用违反 schema 的 XML 当正例。
- 仅针对官方明确的空元素默认扩展共享兼容表：[defJc](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.math.defaultjustification?view=openxml-3.0.1)、[intLim](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.math.integrallimitlocation?view=openxml-3.0.1)、[naryLim](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.math.narylimitlocation?view=openxml-3.0.1)、[brkBinSub](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.math.breakbinarysubtraction?view=openxml-3.0.1)。可读源码保留三态，输出副本补齐原生 required 值；不修改固定 schema，不放宽其他 required 属性。
- `mathPr` 只能出现在数学片段的文档设置位置，不能嵌入 `oMath`、`oMathPara` 或分式槽位规避校验。旧原生载荷与新 DSL 使用相同的输出边界；合法设置根节点及真实命名空间别名不受影响。
- 正文修改使旧胶囊摘要失配时，当前 `$...$`／`$$...$$` 决定行内／显示模式；旧属性留作恢复，不参与有效值。覆盖同段、隔段、正文混排和保存迁移，不能只检查旧值没有复活。
