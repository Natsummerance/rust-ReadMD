# 第三批：原生公式字形轮廓间距

补 B3-55，默认界面不增加控件。原生矢量布局读取实际数学字体的 OpenType MATH 四角 kern 表，按上下标与基底的实际高度计算间距；对齐属性覆盖自然间距。复杂表达或没有该表的字体采用标准允许的零角修正，不猜测字形。

按 [OpenType MATH](https://learn.microsoft.com/en-us/typography/opentype/spec/math) 的两次角值求和取较小值；修正高度等于阈值时进入下一区间，保留负值及字号／基线变换。复用缓存字体，不新增运行依赖。

独立 FontTools 提取捆绑 STIX 字体的测试 oracle，逐覆盖字符、四角及阈值边界验证，再核对真实上下标坐标、属性开关、精准源码修改、撤销和保存重开、矢量 PDF。FontTools 仅是开发期取证工具，不进入产品。保留已知浏览器 MathML 兼容提示，不以原生改进宣称其他阅读器自动修复。

本增量不认证所有 MATH 常量、全部 Office 语义或实际 Word 应用往返。完整第三批保持开放。
