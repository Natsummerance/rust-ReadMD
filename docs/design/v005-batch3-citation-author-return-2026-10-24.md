# 第三批：带作者格式的生成型脚注引用回流

本单元处理已有 P07 的有限、可证明语义域，不声明完整 CSL、任意 Word 字符属性或外部应用互操作完成。实现及冻结候选的真实回流、独立检查全部通过后，才登记本单元证据。

## 保留当前内容与可编辑引用

导入时以实际脚注／尾注 story、引用 ID、当前内容控件及当前模板为准。仅当整个签名家族完整、未改写、逐项一一对应，且所有引用均为 Normal、单控件、单段落、明确标记和允许间隔时，恢复可编辑引用。作者字符格式必须在允许的字号、粗体、斜体等轴上均匀；省略、显式 false 与显式值分别保留。

资格判断读取解析后的 CSL：仅接受 citation layout 明确拥有 `(`、`)` 的等价范围。可达的术语、标签、日期、不能解析的宏及其它上下文变化拒绝恢复；宏遍历有深度和工作量上限。未使用宏不改变现有语义。坏签名、重复引用、额外正文、混合格式或不支持属性导致整个家族维持既有字面回退，不能恢复一半而吞掉另一半。

满足资格后保留真实 authored note、正文引用、当前 locator 和稳定 citation key；外层仅包一次作者格式。`generated=false` 与 `context.in_note=true` 是不同状态：前者不伪造原生成来源，后者令 CSL 按当前真实注释上下文输出。当前模板字号改变必须反映到下一次输出，不能沿用隐藏载荷中的旧字号。

## 去除重复括号的边界

真实 BibliographyDriver 已按精确解析的 layout 输出括号时，Normal／SuppressAuthor 的 authored-note 不再额外包一层；半边括号、方括号、带空格的不同 affix 和标题正文中的括号不构成相同资格。Prose／AuthorOnly 等其它分支保持既有规则。

缺 DOI 的独立调查已确认该实际 driver 即使字段为空也提供 layout 括号；不能用另一个 standalone helper 的行为推断本 API 缺陷。对应新增测试核对真实 API 的 text 与 rich，保留错误假设的首次红测，生产函数不因该误报再加条件。

## 真实验证合同

使用专用合成资料及私有预设，不读用户文档、不调用 Office GUI：

1. 两种 note story 分别生成带重复引用、作者格式和中间文献表的真实 DOCX；仅将当前 note 模板两轴由20改为40 half-point（10→20pt），隐藏来源和注释内容保持不动。20pt处于既有非DOCX 6～24pt合同内，作者10／11.5pt仍与模板明确不同；本单元不认证超过该范围的注释字号。
2. 经实际 stdio 导入并保存；另用 CRLF 与非 BMP 字符验证真实 UTF-16 定位。修改第二个 locator 及字号，执行反向修改、重做、过期修订拒绝和保存。
3. 第二个新进程重开，导出第一代 DOCX，再真实导入和保存；第三个新进程重开，导出第二代 DOCX、HTML、EPUB、原生 PDF 和 Typst PDF。
4. 独立 ZIP/XML 检查当前语义、两代格式及负例；四份另行创作的人工注释对照 PDF 检查完整字体程序、GID、字形位置、路径和链接，误差上限 0.002pt，不以自比较过关。

合同为18个输出、3个正常退出的新 PID、8个家族回退负例、22组检查及24次独立核对。字体由实际导出预设或EPUB明确options控制，不向只支持size的源typography v1写入font；EPUB真实接口没有style_preset，报告必须明确其预设未消费。真实报告不满足合同就保留首败，不改写为通过。HTML／EPUB只认证实际输出的语义标记，不等同于外部浏览器计算样式或电子书阅读器验收。

人工PDF对照由原始素材及固定原生转换规则独立构造：使用`word-<story>-1/2/3`的既定注释身份，保留正文空格、标点和段落顺序，并显式声明当前模板的注释字号、编号、位置、分隔线、续注和1.2倍行距。不能用不同注释标识或省略影响布局的参数来比较整页绘制，也不能从实际PDF字形生成预期稿。这个对照只证明同一引擎中本单元引用恢复未改变相同内容的绘制，不证明不同引擎的注释标号和分页完全一致。

已确认的独立剩余项：Rust PDF目前把注释身份直接绘成`[word-footnote-n]`或`[word-endnote-n]`，尚未在正文标注和注释定义中消费显示编号；Typst使用计数器。必须保留结构化注释身份，接入统一编号策略、重复引用及回链，再取得真实输出证据，不能事后替换普通文字。本单元的同标识对照不能计作Rust注释编号通过。

EPUB检查按实际OPF声明的正文和导航分区。依[EPUB3.3 §7.5](https://www.w3.org/TR/2026/REC-epub-33-20260113/#sec-nav-spine)，标准辅助landmarks导航可以隐藏；正文、脚注及其祖先仍须可见，不能将任意隐藏内容当作成功输出。引用文字可能分成多个CSL primitive，应依实际引用目标和所属ID定位完整有序字符，逐字符检查原始字号及链接，不要求恰好落在一个文本记录中。
