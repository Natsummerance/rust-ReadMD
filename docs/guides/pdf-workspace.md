# PDF 页面编辑、离线安装与恢复

PDF 编辑引擎按需加载，不增加基础阅读的启动依赖。在现有插件面板安装对应平台的 `.readmd-pack`，安装器核对资源清单、摘要和许可证，并运行实际引擎操作；探测成功后才显示可用。当前提供并原生验证的是 Windows x64 PDFium 7881 包。其他平台未认证。

维护者可完全离线构建包：

```powershell
cargo build --offline --locked --manifest-path rust/Cargo.toml -p readmd-kernel --features pdfium-worker --bin readmd-pdf-worker
node tools/build-pdf-pack.mjs <已校验的PDFium资源目录> <工作进程路径> <输出.readmd-pack>
```

工具要求锁定版本的 PDFium 动态库及对应许可证目录；构建器还需通过 `READMD_PDFIUM_CRATE`、`READMD_REGISTRY_SRC` 指定本地依赖及许可证来源。不会在线下载资源。运行时再次核对实际文件，损坏或不匹配则拒绝加载，可用同一已验证包修复。正在编辑 PDF 时不能卸载；卸载只移除清单内资源，不删用户文件或未知文件。

从现有导入菜单或命令面板打开 PDF 编辑。点击页面上的文字、图片或基础表单再修改；文本批注、页旋转和删除在上下文或高级操作中。修改首先进入草稿，原文件保持不变。撤销和重做操作草稿；保存执行源文件修订检查和原子替换。检测到外部修改或文件被占用会停止保存，保留可重试草稿。

页面内链接可直接点击跳转；链接覆盖文字时，按住 Alt 点击可编辑下面的文字。Alt+左方向键返回上一个阅读位置，导航不标记文档已修改。仅处理内部目标和受支持的外部网址，不执行 PDF 中的 JavaScript 或启动命令。

内置 Rust PDF 导出的目录、标题书签和正文锚点链接使用实际页面坐标，重复标题有独立目标。正文、编辑预览、分析和输出共用标题身份规则，支持显式标题 ID、中文和包含公式的标题。找不到目标时报告缺失锚点，不生成假跳转。旧版重复标题的后缀曾使用不同规则；含糊的旧引用不会自动猜改，迁移时应通过链接检查报告确认目标。

关闭有修改的 PDF 时会提示保存、丢弃或取消关闭。集中草稿用于异常退出后的恢复，重启后在高级菜单的草稿列表中选择；同一草稿不能被重复占用。草稿保存一份基础文件和操作日志，图片资源按需保留，避免每次改字复制整份 PDF。保存历史集中管理，最多 32 项、512 MiB、30 天；恢复前关闭同一文件的活动会话，校验当前修订，并保留恢复前状态，避免盲目覆盖。

加密 PDF 需要正确密码；密码只留在当前内存并通过匿名管道传给工作进程，不写入命令行、草稿、恢复元数据或日志。内容编辑、批注、填表和页面操作分别检查原文件权限。修改字形或字体、溢出及签名影响须先确认；当前签名路径仍缺有效签名样本的完整验收。

当前支持基础页面对象和表单，不代表嵌套 XObject、所有表单控件、扫描区域校订、压感手写或安全涂黑已经完成。未修改页面的像素保持、编辑区范围、中文字体、加密保存、跨解析器批注、锁文件、外部冲突、重启草稿、历史及取消不提交已有 Windows 原生证据。完整矩阵见逐需求验收账本。
