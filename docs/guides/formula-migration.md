# 旧公式迁移与恢复

ReadMD 继续支持 LaTeX。旧文档里附在公式后的 `readmd:math:v1` 注释保存了 Office 数学属性；打开、阅读和进入编辑不会改写原文件。编辑区以“数学属性”控件代替内部载荷，点击或按 Enter 进入对应公式的可视编辑。

明确保存 Markdown 时，能够无损表达的标准属性迁移为可读 Math DSL：行内为 `:math[...]`，独立公式为 `readmd-math v1` 围栏。分式样式、矩阵对齐等保留为结构函数和具名属性；引用块、列表中的公式保持原来的内容层级。文件的编码和换行沿用原稿。保存后的源码回写和原编辑共用撤销链路，可以用 Ctrl+Z 撤销、Ctrl+Y 重做。

如果外部编辑已改变 LaTeX，原文优先，旧 Office 属性不会覆盖它。保存前，旧属性先写入集中恢复存储，成功后才从正文分离。在“更多 → 互动 → 恢复与版本历史”选择“打开副本”，可以查看未保存的可读恢复内容，核对后自行采用；这一操作不覆盖当前文件，也不创建旁文件。恢复记录保留来源修订和精确位置，相同属性出现在多个公式时分别记录。

未审阅的公式恢复与未完成草稿一样受保护，不按普通历史的期限自动删除。单条最多 512 KiB，每文档最多 32 条，另受集中存储总容量限制；达到容量时拒绝新增，保留旧记录并停止相关保存，不能先删除恢复依据再继续写盘。可在恢复面板明确删除不再需要的记录。

遇到未知扩展、非法 XML 或不能无损表达的属性时，ReadMD 保留原有源码和载荷，提示迁移未完成，普通保存仍可继续。当前还未交付未知扩展的最小隐藏载荷协议，因此不能把保留旧载荷称为已完成迁移。不支持的 DSL 版本可以阅读和保存，但正式导出会停止，已有输出不会被替换。

开发者可调用只读 `POST /api/math/migrate`，传入 `content` 和可选 `expected_revision`，获得候选内容、UTF-16 编辑范围、恢复项和诊断；该接口不写文件。MCP 的 `readmd_math` 使用 `operation: "migrate"` 调用同一服务。最终写盘必须经过文档保存服务的外部修订比较、恢复持久化和原子写入。

代码、缩进代码、HTML、链接目标及 frontmatter 中的示例不参与迁移。格式细节见 [Math DSL v1](../design/math-dsl-v1.md)。实际 Word 编辑往返及完整 Office 语义兼容仍需单独验收，XML 检查不替代 Word 实测。
