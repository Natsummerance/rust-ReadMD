# 科研图表与三线表

科研输出从数据与原始图形描述生成，不截取阅读器画面。默认界面不增加工具栏：在编辑的“插入图表”中选择 Vega-Lite，再选择科研模板；印刷参数在导出面板原有的折叠自定义区域。

五种可编辑模板分别覆盖预计算 95% 置信区间、散点与最小二乘回归、箱线分布、零中心热力图、数学函数曲线。模板数据仅作演示。置信区间使用明确给出的上下界；箱线图注明 1.5 倍四分位距；回归线不冒充置信带。修改配色、字体和尺寸不会重新解释测量值、坐标轴范围或统计定义。实际研究应替换成自己的数据与统计结果。

选择学术预设会同时启用三线表及科研图样式。三线表只保留顶部、表头下方、底部横线，去除竖线和色块，保留数值对齐；可切回网格表，并保存为用户预设。DOCX 生成原生表格和重复表头，PDF、EPUB、HTML 使用各自引擎的真实规则。

科研图默认 89mm 宽、7pt 字号，白底黑字、标准字体、细轴线、去除多余网格，颜色与形状或线型共同区分系列。宽度和字号均可修改，例如双栏整幅图可设置 183mm。这里参考 [Nature 图形制作说明](https://research-figure-guide.nature.com/figures/building-and-exporting-figure-panels/) 的尺寸与可读性建议，以及 [APA 表格规则](https://apastyle.apa.org/style-grammar-guidelines/tables-figures/tables) 的边框原则；这是可编辑配置，不是全期刊认证。

| 引擎 | 适合内容 | 当前导出行为 |
| --- | --- | --- |
| Vega / Vega-Lite | 统计、误差线、回归、分布、热力图、分面 | Rust 管理离线渲染，使用原始数据，保留 SVG 文字及路径 |
| TikZ | 数学与几何图 | 浏览器离线编译并提供 SVG；作者负责 TeX 内容、字体及版面；复杂 PGFPlots 模板仍需逐项验证 |
| Graphviz | 流程、网络、依赖关系 | 浏览器及 Rust 侧均可离线输出矢量，作者的显式属性优先 |
| Mermaid | 流程与结构图 | 桌面导出重新生成静态 SVG 文字，去除动画与外部资源样式 |
| Chart.js | 常用统计图 | Canvas 位图；科研配置下 89mm 达到约 600dpi，上限 4096px，不冒充矢量 |
| WaveDrom / BitField | 波形、寄存器 | 沿用各自原生描述，桌面可提供 SVG 快照；原生标签缩放、复杂内容尚未逐项科研验收 |
| PlantUML / D2 / ditaa / WSD | 结构和架构示意 | 沿用已有离线能力与语法范围；不把基础渲染等同于完整科研排版 |

Vega 的科研样式同时用于阅读与输出，作者的显式样式优先于默认值。复合图或作者指定的大画布缩小后仍可能产生过小文字，应检查最终印刷尺寸。一般 HTML/阅读主题可以深色，科研图保留白底黑字，避免深色模式反转后失读。

Word 保留原始 SVG 和高分辨率 PNG 兼容预览，并写入印刷尺寸。学术 PDF 选择 Typst 引擎：实际检测的图形保持矢量与可选择文字、嵌入字体；内置 Rust PDF 对 SVG 使用高分辨率位图。EPUB、HTML 保留自包含 SVG。Chart.js 在各格式中保持位图身份。

导出快照绑定图形源码及排版参数，切换宽度、字体或编辑源码后不会错误复用旧图。外部数据加载失败不能输出成功的空白图，也不会覆盖旧结果；使用内嵌数据可离线重复生成。浏览器引擎由桌面提供快照，纯 MCP/后端调用当前可直接渲染 Vega、Graphviz 及已有后端引擎；其他引擎的科研输出缺少快照时明确报错。普通旧模式的兼容行为不代表这些后端引擎已经完整交付。

打开、预览和导出均不往原稿目录创建图表资源副本。DOCX 的实际 Word 打开与往返、独立 EPUB 阅读器、所有引擎的复杂模板、其他平台原生验证仍分别保留未验收状态。
