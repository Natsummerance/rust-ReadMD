# 书籍、学术与通用导出预设

导出面板复用同一份参数目录，不为不同写作场景增加工作台。先选择输出格式，再选预设；完整列表按“通用、书籍、学术”分组，首页只显示少量推荐和当前选择。

| 分类 | 预设 | 适用内容 |
| --- | --- | --- |
| 通用 | 极简、经典、商务 | 普通笔记、阅读材料、项目与办公文档 |
| 书籍 | 小说与文学 | A5、衬线正文、首行缩进、低段距、居中章标题 |
| 书籍 | 非虚构与随笔 | A5、较舒展段落、分级标题与柔和配色 |
| 书籍 | 教材与讲义 | B5、清晰标题、表格、公式及教学引用 |
| 书籍 | 图文作品 | A4、较宽插图、较大标题与图文间距 |
| 书籍 | 技术手册 | A4、代码与表格、较紧凑正文、按二级标题拆分 EPUB |
| 学术 | 课程论文、研究论文、审阅稿、学位论文、技术报告 | 对应字体、页边距、段落、标题与表格起点 |

通用及书籍预设用于 PDF、DOCX、EPUB、HTML；学术预设用于 PDF、DOCX、HTML。它们是可以编辑的起点，不代表某家出版社、期刊或学校的格式认证。EPUB 是可重排电子书，阅读器仍可调整字号，不承诺与打印页码相同。

选择预设后，展开“自定义”修改参数，再通过“保存预设”命名保存。参数保存后重开仍然可用；修改预设不会改动原稿。切换到不适用的输出格式时保留当前参数并显示为自定义，不暗中替换成另一套格式。

EPUB 可调整正文与代码字体、首行缩进、段距、对齐、标题、表格、引用和链接配色；EPUB 字号与行距单独设置。封面可以自动生成，或者选择 PNG、JPEG、GIF、自包含 SVG。自动封面为 2400×3200 矢量 SVG，优先使用文档中的书名与作者；必要信息也可在导出面板指定。

EPUB 预览读取实际打包所用的章节、样式、图片和 MathML，而非另一套网页稿。目录、跨章链接、重复脚注及返回链接均可点击。预览不创建资源目录；导出只写明确选择的结果文件。封面无效或缺失时导出失败，已有文件保持不变。

实际 Word 排版往返、独立电子书阅读器兼容、完整论文版式与其他平台原生验收各自保留证据状态，不由预设数量或 XML 合法性代替。

学术预设现采用科研三线表，并提供可编辑科研图参数。Typst 可通过锁定的 Windows 离线能力包安装，预览使用实际分页结果；Word 的共享 PDF 投影仍不是 Word 真实版式证明。图表类型、印刷尺寸、矢量与位图边界见 [科研图表说明](scientific-figures.md)。
