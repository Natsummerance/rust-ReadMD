# Word 与学术 PDF 版式

更新：2026-10-12。对应 V0.0.5 开发实现，尚未正式发布。

## 操作

打开文档，进入导出，选择 DOCX 或使用 Typst 的 PDF。先选择学术、书籍或通用预设，再展开需要修改的设置；高级标题参数放在各级标题的小折叠项中，不增加常驻工具栏。修改后可以保存为自己的预设，下次打开继续使用。

基础 Word 导出由 Rust 直接生成 DOCX，不需要安装 Word、WPS、Office、Python 或 TeX。Word 预览是明确标注的共享版式投影：有已安装并通过探测的 Typst 时采用 Typst，否则使用内置 PDF 引擎。此前在 PDF 页选择 XeLaTeX 等引擎，不会影响 Word 生成和预览。投影不能代替 Word、WPS 或 LibreOffice 的真实分页检查。

Typst 是可选能力包。选择它时如未安装，可在当前操作内查看用途、下载量、安装后空间和许可证，安装后继续；网络不通可在同一窗口导入离线包。PDF 预览与导出复用同一固定产物，内容、资源或设置变化后重新生成。详见[能力包说明](offline-capabilities.md)。

## 本次可调参数

| 设置 | DOCX | Typst PDF | 含义 |
| --- | --- | --- | --- |
| 分栏数、栏间距 | 原生节属性 | 实际分栏 | 1–3 栏；封面及目录保持全宽，正文再分栏 |
| 装订预留、镜像页边距 | 原生页边距及文档设置 | 按实际纸张奇偶页交替 | 不使用自定义页码的奇偶数决定左右页 |
| 页眉/页脚距离、字号、对齐 | 原生页眉页脚 | 距纸张边缘定位 | 显式设置超出页边距时拒绝生成，保留已有文件 |
| 首页不同 | 原生首页设置 | 首张纸不显示页眉页脚 | 缺省跟随封面；可明确覆盖 |
| 页码格式、起始值、总页数 | PAGE / NUMPAGES 字段 | 实际页计数 | 阿拉伯数字、大小写罗马数字、大小写字母；总数为物理页数 |
| 孤行控制、段中不分页 | 原生段落属性 | 分页代价/段落约束 | 对正文生效；不能把所有内容硬塞到一页 |
| 标题前后间距、与下段同页、段中不分页、段前分页 | 原生标题样式 | 实际标题布局 | 每级标题独立配置 |
| 注释位置、字号、行距、编号格式 | 原生脚注或文末尾注 | 页面脚注或文末集中注释 | 作者注释及脚注型文献共用既有引用链路 |

栏间距为 1–30mm，装订预留为 0–40mm。扣除页边距、装订和栏间距后，每栏至少 20mm；太窄时返回可读错误，而不是生成溢出文件。图与表使用当前栏宽，避免按整页宽度插入双栏正文。

正文可以多次使用同一 `[^note]`，不必复制 `[^note]:` 定义。Word、EPUB 与 Typst PDF 输出复用同一注释；Word 脚注中的外链和图片有独立关系，正文和脚注使用相同图片时共用资源。脚注中的引用段落、编号列表、表格、代码和公式保留各自结构；普通预览同样显示完整内容。Word 标准禁止脚注里再放脚注引用，此类输入明确拒绝 Word 导出，保留原文及已有输出；EPUB 不受这条 Word 限制。实际 Office 应用往返认证继续单列，详见[脚注内容验收范围](../design/v005-batch3-note-content-spec.md)。

在“正文排版”的“注释位置”选择文末尾注，无需改写 Markdown。DOCX 使用原生尾注，Typst PDF 在正文之后分页集中排版；EPUB 在全书末尾生成导航章节，跨章重复引用共用定义并分别保留返回链接。PDF／EPUB 可自定义注释标题，缺省随当前界面语言；编号、字号及行距也可存入自己的预设。切换注释位置保留当前展开区及键盘焦点。基础 PDF 及 TeX 不显示尚未支持的位置选项，通过 API 传入时返回版式损失提示。Word 文件导入注释与实际 Office 应用往返仍未认证，不能由原生 DOCX 输出推定导入无损。

缺省参数只在引擎读取时取值，不强行写进旧预设。已有预设的名称与身份不会因为新增控件而无故改变；明确修改的参数才进入用户预设。

## 输出能力差异

界面只在支持的格式和引擎中显示这些高级参数。通过 MCP/API 传入跨格式预设时，未支持的分栏/页码、段落、脚注及标题属性返回损失提示，不能静默宣称生效。EPUB 使用流式阅读排版，不以打印页码和纸张分栏冒充电子书分页。

## 局部排版

编辑时把光标放在段落、标题、公式或题注中，在现有“文本”菜单选择“局部排版”。字号、颜色、对齐直接可调；缩进、前后间距和分页约束在高级设置中。空白或“使用预设”表示继承，清除局部排版可回到原文；应用后一次撤销即可恢复，保存前不会写盘。

Word 使用原生段落和文本属性，Typst PDF 使用实际分页与向量输出，EPUB 使用对应内容的样式。内置基础 PDF、HTML 和 TeX 当前保留正文并返回明确的局部版式损失提示。公式只显示当前可执行的字号、颜色、对齐、间距及分页属性，不提供无效的字体和字形按钮。

需要共享的局部属性保存为可读注释，例如 `<!-- readmd:layout v1 {"id":"block-…","text":{"size":16},"paragraph":{"align":"right"}} -->`，紧邻对应内容。普通文档不添加它；编辑器将本软件生成的标记收成可点击“局部排版”，不会把它计入字数。代码块中的语法示例不会折叠。已有标识在移动内容后保持，未标记内容按源范围定位；重复段落不采用全局字符串替换。

支持顶层段落、标题、块公式和题注，也支持引用与列表内的段落及标题。列表中的局部属性只改变选中的正文，不改变子列表、任务勾选、起始编号或标题锚点；标记放在该段内容末尾，避免插入空行拆散紧凑列表。编辑器折叠真实标记，代码中的同名示例仍可阅读。Word 保留原生编号及未指定的列表缩进，分页预览也可直接定位这些内容。

注释段落也可使用同一局部排版菜单，继承注释预设的字号和行距；重复段落只改变选中的那一处。属性应用、清除、撤销、保存重开和三格式输出复用同一流程。嵌套块公式、任意节、每节尾注及全部 Office 属性继续实施。未知版本、孤立标记、重复标识和无效值保留源码并阻止生成错误输出。实际 Word 往返、其他平台、干净环境和所有语言人工语义审校继续分别记录。共享参数证据见[实施记录](../reviews/readmd-v005-batch3-layout-2026-10-10.md)，嵌套内容的范围见[增量验收合同](../design/v005-batch3-nested-layout-spec.md)。

## 在真实分页中修改

编辑时开启预览，在同一预览菜单勾选“生成文档页面”。页面采用当前导出设置的 Typst 实际输出，可以翻页，点击对应段落、公式或题注打开局部排版；Tab 可聚焦内容，Enter 打开。应用后可撤销，Ctrl+S 才保存；重启后仍能编辑相同内容。

缺少 Typst 时直接显示能力包说明和“安装并继续”，也可在同一窗口离线导入。默认预览仍为轻量 Markdown；取消勾选恢复普通预览并停止分页任务。连续编辑只显示当前修订的结果，旧页面不能修改新的正文。

预览和相同设置导出共用实际 PDF，临时定位标记不写入文档或导出动作。Word 共享投影不代表真实 Word 排版。已验证范围与剩余组合见[分页交互记录](../reviews/readmd-v005-batch3-pagination-2026-10-10.md)。
