# ReadMD V0.0.6

本版包含 V0.0.6 迁移分支的完整更新和本轮 Mac／导出收尾，延续原有简洁阅读与编辑界面。

- **正文审阅与恢复**：AI 修改进入工作正文并逐块审阅；审阅、保存和任务状态分开，保存与重启保留必要原文，保护手工修改及过期修订。
- **快照导出**：冻结正文、资源字节、参数及运行资源；成功提交产物后才确认与该快照匹配的待审修改。失败、取消和后续新修改不会被顺带同意。HTML、PDF、DOCX、EPUB、TeX、PPTX 及原有离线 HTML 演讲共用这一流程。
- **任务与第三批增量**：持久任务检查点、幂等与恢复边界；OpenAPI 本地引用、表格粘贴／对齐、转换预览和媒体时间位置等限定流程。Windows 支持范围内的引用重命名保留全组复核和恢复保护。
- **Mac 收尾**：保留中文路径、图片和文档链接修复；Mac PDF／DOCX 参考预览使用系统 Quartz 绘制真实页面，不再只显示占位文字。修复未使用的本地化提示框标题误触发字体安装的问题。
- **真实导出预览**：PPTX 预览与原生可编辑文件共用 16:9 分页布局；文字、列表、代码与表格可编辑，图片和备注保留，长内容自动续页。预览随窗口铺开，切回已看格式复用同一修订的受限缓存。原有离线 HTML 全屏演讲继续保留。TeX 显示实际生成源码。切换格式、取消和过期结果分别处理，保留正式 CSP 与真实鉴权。

## 安装与集成

Windows x64 提供安装包与完整便携 ZIP，Linux x64 提供 DEB／tar.gz，macOS Apple Silicon 和 Intel 分别提供 ZIP／DMG；VSIX 和 MCP 包与桌面版本同步。下载后按 SHA256SUMS.txt 核对完整性。中文出版字体等较大的能力继续通过已锁定的受管包按需安装或离线导入，不依赖宿主 Office／Python。

Mac 使用免费 ad-hoc 签名，没有 Developer ID 或 Apple 公证。首次打开按[安装说明](release/macos-install.md)在系统设置中仅对 ReadMD 允许打开；这不等于默认 Gatekeeper 放行。Linux 仍需要系统 GTK／WebKitGTK 运行库。

## 范围与后续

这是有边界的功能发布，不是完整 75 条能力合同的整项认证。非 Windows 多文件引用重命名仍在持久意图写入前明确拒绝；没有降级成有竞态的普通 rename。DOCX 预览是明确标注的共享布局参考，不是 Word 实际分页；PPTX 公式保留为图片并在备注保存源码，不冒充可编辑 Office 公式；完整 PowerPoint／WPS／Keynote 互操作矩阵仍待验。

复杂办公／PDF／媒体／数学出版长尾、真实多人长期运行、完整供应商故障矩阵及各平台完整原生认证延续到 V0.0.7。原生、headless、构建和外部应用证据分别记录。具体范围见[本轮发布规格](docs/design/v006-release-closure-2026-10-30.md)和[V0.0.7 延续清单](docs/design/v007-carryover-2026-10-30.md)。
