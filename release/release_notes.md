# ReadMD V0.0.5

本次围绕本地阅读、编辑和出版工作流升级，保留简洁界面。它交付已经实现并验收的增量，不表示完整 Office、所有科研排版组合或全部平台原生认证已经完成。

- **更顺畅的编辑与阅读**：单行自适应编辑工具栏、底部字数、统一控件、LOGO回主页；修复切入编辑后的首屏刷新与4K阅读内容宽度，完善禅模式与全屏联动。
- **公式可以直接编辑**：在渲染结果选择符号或结构槽位，使用可读 Math DSL；未完成输入集中恢复，保存正文与公式草稿分离。支持的公式可导出为 Word 可编辑 OMML、PDF 矢量公式或 EPUB MathML。
- **论文、书籍与通用输出**：共享元信息、引用和稳定编号，学术／书籍／通用预设与格式适配，科研图表与三线表，以及多个实际版式参数。文献、注释及复杂格式仍按各输出路径的支持范围处理。
- **能力按需安装**：小型核心能力直接提供，较大的排版、字体、OCR和PDF引擎通过用途、大小及许可明确的受管理包安装或离线导入。修复 Windows 长路径下的安装空间查询失败。
- **结果与限制更透明**：数学字体替换准确提示；不能保留的公式 Word 格式修订记录明确报告，源文档保持；段落底纹与边框的阅读处理不再破坏整篇出版投影。新增提示补齐46语言译文。
- **开发者集成**：文档诊断、工作区检索及受修订保护的文件操作复用 Rust 服务，VS Code 与 MCP 随桌面版本一起交付。

## 安装与更新

Windows x64 提供安装包和完整便携ZIP；便携版必须完整解压，不能只移动主程序。VS Code 提供 VSIX，MCP 使用同一主程序的 stdio 入口，不需要 Python。正式资产附 SHA256SUMS.txt。

macOS Intel／Apple Silicon及Linux x64由既有CI管线构建；构建结果与完整原生交互验收分别记录。Windows是本次本机主要实测平台；其他系统没有被冒称全面实测。macOS包未作Apple公证，Linux桌面仍需要其系统GTK／WebKitGTK运行库；重型离线能力包仅在实际提供并验证的平台开放。

## 已知边界与下一版本

完整数学字体换入、theme／修订、任意OMML／CSL／复杂分页、正式TeX能力包、跨应用互操作和全部平台认证仍在验收清单。第四批持久正文审阅、多轮AI Harness、协作及其他深化场景进入V0.0.6。不支持的输出明确报告并保护原文和旧目标，不能把“生成文件”当成跨应用认证。
