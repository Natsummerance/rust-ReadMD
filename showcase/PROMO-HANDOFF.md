# ReadMD 宣传片素材交接

素材目录为本文件所在的 `showcase/`。`videos/` 包含 F001–F104 的功能短片；`promo-clips.json` 按功能分类列出文件、时长、步骤时间点、媒体哈希和等待剪辑区间。

这一批全部按最新 UI 和原有 LOGO 重录，录制模式为 `immersive-v2`。可将本文件、`promo-clips.json` 和 `videos/` 一起交给 Claude；编号用于查找素材，不需要放进宣传片。

MP4 为沉浸式软件画面：没有烧入的字幕、录制编号、说明框、等待加速标签、额外光标圆圈或底部浮动通知。系统桌面、个人文件夹、文件选择器及其他应用窗口不进入画面。视频无声，后期可以自行配音、配乐及编排标题。LOGO 使用软件原有蓝紫渐变图标。

- 使用 `videos/` 的原 MP4 作剪辑源；`posters/` 是真实画面封面。
- 普通界面为 1280×800，原生界面为 1300×850，均为 H.264、20 fps；每段具体尺寸见索引。制作时等比缩放，不裁掉顶栏 LOGO 或关键操作结果。
- 操作说明在 `promo-clips.json` 和 `captions/` 的独立 VTT 中，未写进视频画面。网页播放器默认关闭字幕。
- `wait_edit` 如存在，表示真实网络或模型等待被加速；动作和结果来自实际软件运行。宣传片不要把被加速的等待当作性能测试结果。
- F016 包含主页深色、护眼、自动、浅色主题切换；F062–F065 包含插件查看、安装、开关保存和卸载；F093–F095 包含原生桌宠操作；F104 包含退出前保护未保存内容。
- 文件夹、选择器、打印及授权操作由真实宿主执行，镜头只保留软件自身界面。需要展示这些能力时结合侧边文件树、转换结果、导出状态等实际软件结果。
- 更新片段展示真实版本检查；没有构造新的正式版本或虚假的安装成功。

每项原始断言、接口反馈、隐私批准和录制时间见 `manifest.json`；总体播放验收、隐私抽检与清理结果见 `checks/`。素材均使用原创演示文档，私人书籍未进入发布内容。

浮动提示只在隔离录制页面临时隐藏，录制结束后已恢复。功能面板、保存确认和主动桌宠互动仍按实际操作呈现；软件的正常通知功能与用户设置保持可用。

不必复制网站的重复路径：网站媒体与这里的文件使用硬链接复用。将本目录交给后期工具时，`videos/` 和 `promo-clips.json` 已包含主要素材与对应关系；独立字幕和封面可按需使用。
