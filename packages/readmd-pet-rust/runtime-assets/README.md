# Offline pet renderer libraries

These four chunks come from the existing ReadMD runtime (PIXI 6.5.10, pixi-live2d-display 0.4.0 and the Rolldown runtime). Their SHA-256 hashes are pinned in `manifest.json`; original licenses are retained in `licenses/`. ReadMD presentation code is compiled from tracked TypeScript at package time with Node 22.13+. No npm install is needed.

Cubism Core is proprietary and is excluded from source. Prepare the existing, hash-pinned runtime cache separately with `READMD_PET_CUBISM_CORE` before running the offline package command. The publication record and rights notice are in `../readmd-hermes-pet-adapter/assets/NOTICE.md`.
