次のひらめきを、Tab でつなぐ。

書いている文章のすぐ横に候補を表示。Tab で確定、Esc で破棄。挿入した文は元に戻せます。

ReadMD の自動補完は任意で有効にします。接続とモデルは AI 設定で選択します。この操作イメージはそれらに接続しません。

同じ Rust エンジンを二つのエディターで

デスクトップと VS Code は補完のコンテキスト制限と出力フィルターを共有します。MCP も同じ補完エンジンを呼び出せます。

検証に基づくプラットフォーム対応

ビルドとネイティブ環境での受け入れ確認は別です。Windows はローカルで確認済みですが、macOS、Linux、中国の Linux 環境はそれぞれ検証が必要です。HarmonyOS はソース統合済みの候補です。
